## <a href="https://github.com/equwal/posix-pipes" class="external-link">posix-pipes</a>

Portably run a command with input/output to/from CL.

From <a href="https://github.com/Sharp-CLOCC/Newport" class="external-link">Newport</a> which  
is the Sharp-CLOCC's maintenance and reduction of <a href="https://clocc.sourceforge.net/dist/port.html" class="external-link">CLOCC's port<br />
module</a> for modern lisps.

## clone
