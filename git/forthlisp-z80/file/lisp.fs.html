1 \ lisp.fs -- layer 4: a small Scheme written in Forth words, loaded through the Z80 Forth.
2 \ Values are 16-bit. A heap object is one 4-byte cell (car, cdr) plus a type byte:
3 \ 1 pair  2 symbol (car: counted name, cdr: global value)  3 closure ((params . body) . env)
4 \ 4 primitive (car: xt)  5 number (32-bit: car low, cdr high)  6 string (car: char list)
5 \ 7 vector (car: element list)  8 macro (car: transformer closure).  Bit 7: GC mark.
6 \ Immediates: () = 0, #f = 2, #t = 4, unspecified = 6, unbound = 8.
