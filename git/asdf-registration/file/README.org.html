4 Register you directories in the ASDF subsystem. [[https://common-lisp.net/project/asdf/asdf.html#Configuration-DSL][ASDF has a better way to do it]], but this one works too. Also, [[https://github.com/roswell/roswell][roswell can do better]], so I have archived this repository.
5 
6 * Install
7 Run the install script. If it complains, set =$CL_INIT= and =$ASDF_REPO=.
8 #+begin_src shell
9 git clone git@github.com:equwal/asdf-registration.git
10 export CL_INIT="$HOME/.sbclrc" # for some SBCLs only.
11 export ASDF_REPO="$HOME/common-lisp" # This is where mine is.
12 sh asdf-registration/install.sh
13 #+end_src
14 * Advanced install
15 ** More than one repository
16   Add =asdf-registration:add-repo= lines to your init file. The subdirectories
17   will be added to the ASDF registry.
18 ** Directories not in a repository
19    For an ASDF project not inside of a repository directory, use
20    =asdf-registration:add-to-registry=.
21 * Guts
22   ASDF-registration is a wrapper around the  =*central-registry*=. If you need something more complex, use the [[https://common-lisp.net/project/asdf/asdf.html#Configuration-DSL][configuration DSL]].
