Fix two faults found on a phone

URLDecoder.decode(String, Charset) is Java 10 and Android 13: the app
crashed on Android 11 at the first link. The charset now goes by name.
The core module is plain JVM, so its tests and lint do not see the API
level of Android: keep it to Java 8 APIs.

With a release and a debug SubRead Overlay side by side, the client took
the first authority and got no line. It now takes the overlay that shows
a line, then the one that sees a player. The dictionary client tries the
debug authority too.
