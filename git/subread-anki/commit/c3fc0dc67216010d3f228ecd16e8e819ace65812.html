Fix the pop-up faults that a test in Brave found

A test on a phone (Android 11) shared a sentence from Brave to the
pop-up. The test found four faults:

- The pop-up was a narrow box in the middle of the screen.
  setContentView sets a floating window to WRAP_CONTENT. The pop-up now
  sets its width, height and gravity after setContentView.
- The text had quotes and the link of the page. Brave shares
  "selection" and the URL. SharedText.clean removes the link, and then
  the quotes around the rest. A text without a link stays as it is.
- The first scan looked up the quote. Scans.firstLetter moves the first
  scan to the next letter or digit.
- The pop-up said "No dictionary" with the debug build of SubRead
  Dictionary. Android 11 hides a provider of a package that the manifest
  does not name. The manifest now names the providers of the
  dictionary and the overlay, release and debug.

The label of the pop-up is now "SubRead Anki". "Anki card" was too
near to the "Anki Card" entry of AnkiDroid in the same menu. The
activity takes the label of the app.

The README says to use Share in a browser that shows only some of the
apps in its text selection menu.

+package space.subread.anki.core
+
+/** The text that an app shares. A browser adds the link of the page to the selection. */
+object SharedText {
+
+    private val LINK = Regex("""https?://\S+""")
+
+    /** Quotes that a browser puts around the selection that it shares. */
+    private val QUOTES = listOf('"' to '"', '“' to '”')
+
+    /**
+     * The selection in a shared text. Chrome and Brave share `"selection"` and the link of the
+     * page: the link goes, and then the quotes around the rest. A text without a link stays as
+     * it is, quotes and all: the user selected them.
+     */
+    fun clean(text: String): String {
+        if (!LINK.containsMatchIn(text)) return text.trim()
+        val rest = LINK.replace(text, "").trim()
+        for ((open, close) in QUOTES) {
+            if (rest.length >= 2 && rest.first() == open && rest.last() == close) return rest.substring(1, rest.length - 1).trim()
+        }
+        return rest
+    }
+}
