Talk to AnkiDroid without the JitPack library, and turn on R8

F-Droid builds from Maven Central and source only, and the AnkiDroid API library is on JitPack only. AnkiClient now uses the content provider of AnkiDroid (the FlashCardsContract) directly, with the same calls as the library, and keeps its own methods, so the callers do not change. A duplicate check is an Anki search on the first field. R8 removes unused code; F-Droid asks for it.
