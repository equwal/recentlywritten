12 * Description
13 This layer provides Spacemacs keybindings to Emacs' brilliant but unkeybound rectangle manipulation functions
14

37 * Install
38 To use this configuration layer, add it to your =~/.spacemacs=. You will need to
39 add =rectangle= to the existing =dotspacemacs-configuration-layers= list in this
40 file.
41 
42 * Issues
43 This code does not play nice with Emacs Lisp or Spacemacs conventions. Pull
44 requests appreciated. If you write your own skeleton, and it is decently
45 conservative for that language/file type, send it!
