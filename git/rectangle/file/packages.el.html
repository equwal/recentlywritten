20 ;; Briefly, each package to be installed or configured by this layer should be

23 ;; - If PACKAGE is not referenced by any other Spacemacs layer, define a
24 ;;   function `rectangle/init-PACKAGE' to load and initialize the package.

32 (defconst rectangle-packages
33   '()
34   "The list of Lisp packages required by the rectangle layer.
35 
36 Each entry is either:
37 
38 1. A symbol, which is interpreted as a package to be installed, or
39 
40 2. A list of the form (PACKAGE KEYS...), where PACKAGE is the
41     name of the package to be installed or loaded, and KEYS are
42     any number of keyword-value-pairs.
43 
44     The following keys are accepted:
45 
46     - :excluded (t or nil): Prevent the package from being loaded
47       if value is non-nil
48 
49     - :location: Specify a custom installation location.
50       The following values are legal:
51 
52       - The symbol `elpa' (default) means PACKAGE will be
53         installed using the Emacs package manager.
54 
55       - The symbol `local' directs Spacemacs to load the file at
56         `./local/PACKAGE/PACKAGE.el'
57 
58       - A list beginning with the symbol `recipe' is a melpa
59         recipe.  See: https://github.com/milkypostman/melpa#recipe-format")
