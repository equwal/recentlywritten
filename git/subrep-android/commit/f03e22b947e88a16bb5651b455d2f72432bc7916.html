Correct the account part of the privacy policy

The app asks subread.space for the hours each time that the main screen opens. MainActivity.onResume calls refreshCloud, which calls Cloud.state. subread.space makes a new account for each request without the device cookie. So subread.space makes the account at the first start, also when the user uses only the captions on the phone. The old text said that the account was for the cloud captions.

The Data safety form on Google Play declares the device IDs as collected and required. The privacy policy must agree with the form.

Also correct the comment on the INTERNET permission. The cloud captions send the sound to subread.space, so the old comment was wrong. The app behavior does not change.
