Compile the speech library without the compiler version line, and set the version to 0.2.2

The clang of the Windows NDK adds its own version line to the .comment section, and the clang of the Linux NDK does not, so the F-Droid build of the library would differ from the signed APK. With -fno-ident, the Windows and Linux builds are the same (checked on SubRead, which has the same build).
