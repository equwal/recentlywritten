Add cloud captions with hours from subread.space

The captions on the phone stay free. A new first step chooses where the
captions are made: on this phone, or in the cloud (Whisper large-v3
turbo on Groq, through subread.space). The cloud needs no model, gives
better captions and uses less battery.

- Cloud.kt: the client of /api/captions. The first answer of the server
  sets the device cookie; the app keeps it in Store.device, and the
  hours belong to that account. It reads the balance and the packs,
  opens the Stripe payment page in the browser, and posts each piece
  of speech as 16-bit PCM.
- Recognizer: one interface for Whisper and CloudRecognizer.
  LocalEngine is now Engine, because it runs both. A lost piece shows
  an error and the next piece can work. No hours left stops the worker.
- The screen shows the hours left, the account id, the three packs
  (20 h $4.99, 80 h $16.99, 200 h $39), and says where the sound goes.
  It reads the balance again when the user comes back from the payment.
- Pcm.toBytes: the reverse of Pcm.toFloat.
- Version 0.2.0 (3). README: prices, account, what goes where.

Tests: CloudTest (11) against a local HTTP server of the JDK, with a
property test for the PCM round trip, and a test that the engine stops
when the hours are gone. 30 unit tests pass. Lint: 0 errors.

+            val text = response.body!!.string()

+        }

+    fun transcribe(pcm: ByteArray, language: String): Answer {
+        val request = Request.Builder()
+            .url("$base/api/captions/transcribe".toHttpUrl().newBuilder().addQueryParameter("lang", language.ifEmpty { "auto" }).build())
+            .post(pcm.toRequestBody(PCM))
+            .build()
+        val response = try {
+            call(request)
+        } catch (e: IOException) {
+            throw PieceFailed("Cloud: no connection (${e.message}).")
+        }
+        return response.use {
+            val text = it.body!!.string()
+            when (it.code) {
+                200 -> JSONObject(text).let { json -> Answer(json.getString("text"), json.getLong("seconds_left")) }
+                402 -> throw OutOfHours()
+                else -> throw PieceFailed("Cloud: ${detail(text) ?: "the server answered ${it.code}"}.")
+            }
+        }
+    }

+    private fun call(request: Request): Response {
+        val device = readDevice()
+        val response = http.newCall(

+        ).execute()
+        deviceFrom(response.headers("Set-Cookie"))?.let { if (it != device) writeDevice(it) }
+        return response
+    }

+                available = json.getBoolean("available"),
+                packs = (0 until packs.length()).map { i ->

+    fun toBytes(samples: FloatArray): ByteArray {
+        val out = ByteArray(samples.size * 2)
