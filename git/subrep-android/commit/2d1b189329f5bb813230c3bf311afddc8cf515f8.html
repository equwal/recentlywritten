Run Whisper on the phone, and drop the computer engine

Subrep for Android makes the captions on the device. whisper.cpp v1.9.4
is a submodule, built for ARMv8.2 with the JNI bridge of SubRead. The
model (tiny, base or small, 8-bit) is downloaded once from the
ggerganov/whisper.cpp repository on Hugging Face.

The Segmenter cuts the sound at pauses with the rules of the desktop
app. LocalEngine gives each piece to Whisper on one thread, with the
encoder window cut to the length of the piece, caps the tokens, and
collapses the loops that Whisper falls into on singing. The list of
invented lines is that of the desktop app.

The captions go to the relay as before. With the language "auto", the
relay gets a status with the language that Whisper found.

The stream of sound to a computer is gone: no sound leaves the phone.
