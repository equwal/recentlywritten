Keep one sound source checked, and show the state in dumpsys

Each radio button gets an id before it joins the group, and the group
selects one. Without the ids, a tap on the microphone left both buttons
checked, and the app captured the apps again.

The level meter redraws only when its bar count changes, at most twice a
second, for e-ink screens. The service prints its state for
'adb shell dumpsys activity service', for a bug report.
