1 # proxyverif

4 # Install (any operating system)
5 Need to have git installed. Command line:
6 ``` shell
7 git clone git@github.com:equwal/proxyverif.git
8 cd proxyverif
9 ```
10 Now the necessary package must be installed from cpan
11 
12 ``` shell
13 cpan -i LWP::UserAgent
14 cpan -i LWP::Protocol::socks
15 ```
16 
17 # Install (Linux)
18 
19 ``` shell
20 chmod 755 checker
21 cat example.txt | checker -v
22 ```
23 For a more friendly but harder to monitor output:
24 ``` shell
25 cat example.txt | checker | tee success.txt
26 ```
27 # Install (Windows)
28 Install strawberry perl
29 http://strawberryperl.com/
30 Run the checker
31 ``` shell
