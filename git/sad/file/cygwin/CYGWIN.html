1 sad on Cygwin
2 =============
3 
4 Cygwin has no sndio or ALSA. It emulates OSS /dev/dsp on top of
5 Windows audio, so sad uses the oss backend there.
6 
7 Packages: gcc-core make socat libsndfile-devel libmpg123-devel
8 libvorbis-devel libsoxr-devel
9 
10 Build and install to /usr/local/bin (sad, sacc):
11 
12 	make install-cygwin
13 
14 Optional Windows wrappers: copy cygwin/sad.cmd and cygwin/sacc.cmd to
15 a folder on the Windows PATH. They assume Cygwin in C:\cygwin64.
16 
17 Use (Cygwin shell, PowerShell or cmd):
18 
19 	sad                    start the daemon (foreground)
20 	sacc add FILE          queue a file; Windows paths are converted
21 	sacc play
22 	sacc status playback
23 	sacc kill
24 
25 SAD_SOCK sets the socket path for both; default /tmp/sad-sock.
