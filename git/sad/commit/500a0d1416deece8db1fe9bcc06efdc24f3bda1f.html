Add Cygwin install target, sacc client and Windows wrappers

make install-cygwin builds with the OSS backend and installs sad
and sacc to /usr/local/bin. sacc sends one command over the socket
with socat and converts Windows paths for "add". sad.cmd and
sacc.cmd run both from PowerShell or cmd. SAD_SOCK picks the
socket; default /tmp/sad-sock. Docs in cygwin/CYGWIN.

.gitignore keeps objects, the binary and config.h out of git.

+sad on Cygwin
+=============
+
+Cygwin has no sndio or ALSA. It emulates OSS /dev/dsp on top of
+Windows audio, so sad uses the oss backend there.
+
+Packages: gcc-core make socat libsndfile-devel libmpg123-devel
+libvorbis-devel libsoxr-devel
+
+Build and install to /usr/local/bin (sad, sacc):
+
+	make install-cygwin
+
+Optional Windows wrappers: copy cygwin/sad.cmd and cygwin/sacc.cmd to
+a folder on the Windows PATH. They assume Cygwin in C:\cygwin64.
+
+Use (Cygwin shell, PowerShell or cmd):
+
+	sad                    start the daemon (foreground)
+	sacc add FILE          queue a file; Windows paths are converted
+	sacc play
+	sacc status playback
+	sacc kill
+
+SAD_SOCK sets the socket path for both; default /tmp/sad-sock.

+#!/bin/sh
+# sacc: send one sad command, e.g. "sacc add FILE", "sacc status playback".
+# Windows paths in "add" are converted with cygpath.
+PATH=/usr/local/bin:/usr/bin:$PATH
+sock=${SAD_SOCK:-/tmp/sad-sock}
+[ $# -eq 0 ] && { echo "usage: sacc command [args]" >&2; exit 1; }
+if [ "$1" = add ] && [ $# -ge 2 ]; then
+	shift
+	for p in "$@"; do printf 'add %s\n' "$(cygpath -ua "$p")"; done
+else
+	printf '%s\n' "$*"
+fi | socat - UNIX-CONNECT:"$sock"
