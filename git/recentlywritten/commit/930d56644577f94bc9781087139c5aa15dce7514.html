+<span class="a">+# ideamine</span>
+<span class="a">+</span>
+<span class="a">+**An idea inbox for Claude Code.** Save ideas as fast as you have them. Claude sorts them out later.</span>
+<span class="a">+</span>
+<span class="a">+```</span>
+<span class="a">+&gt; /idea let the scroller pause when the mouse hovers over a link</span>
+<span class="a">+  💡 Saved #43 · let the scroller pause when the mouse hovers over a link  (6 in inbox)</span>
+<span class="a">+```</span>
+<span class="a">+</span>
+<span class="a">+That line did not call the model. A hook answers `/idea` on your machine before any request goes to Claude, so saving an idea:</span>
+<span class="a">+</span>
+<span class="a">+- **costs 0 tokens.** `claude -p &quot;/idea …&quot;` reports 0 turns, 0 input tokens, 0 output tokens, $0.</span>
+<span class="a">+- **does not interrupt the current task.** Claude never sees the idea, so it cannot get distracted by it.</span>
+<span class="a">+- **works on any model, in any session, and when you are out of usage.** Nothing is sent, so there is nothing to rate-limit.</span>
+<span class="a">+</span>
+<span class="a">+Every session writes to one archive, `~/.ideamine/ideas.json`, whatever project or model it uses. When you are ready, Claude triages the pile. It decides which ideas are worth doing and picks the **cheapest model that can build each one**: Haiku for a typo, Sonnet for a feature, Opus for a redesign. Fable is only for the hardest problems.</span>
+<span class="a">+</span>
+<span class="a">+## Install</span>
+<span class="a">+</span>
+<span class="a">+In Claude Code (CLI, desktop, or IDE):</span>
+<span class="a">+</span>
+<span class="a">+```bash</span>
+<span class="a">+claude plugin marketplace add equwal/ideamine</span>
+<span class="a">+```</span>
+<span class="a">+</span>
+<span class="a">+```bash</span>
+<span class="a">+claude plugin install ideamine@ideamine</span>
+<span class="a">+```</span>
+<span class="a">+</span>
+<span class="a">+Or from inside a session: `/plugin marketplace add equwal/ideamine`, then `/plugin install ideamine@ideamine`. Start a new session to load it. Requires Node.js 18 or later. There are no dependencies to install. Tested on Claude Code 2.1.224 (CLI) and 2.1.275 (desktop app) on Windows.</span>
+<span class="a">+</span>
+<span class="a">+Marketplaces you add yourself do not auto-update. To upgrade, run `claude plugin marketplace update ideamine`, then `claude plugin update ideamine@ideamine`.</span>
+<span class="a">+</span>
+<span class="a">+## Commands</span>
+<span class="a">+</span>
+<span class="a">+| Command | What it does | Calls the model? |</span>
+<span class="a">+|---|---|---|</span>
+<span class="a">+| `/idea &lt;text&gt;` | Save an idea. A pasted bulleted list saves one idea per bullet. `#tags` are recorded. | **No** |</span>
+<span class="a">+| `/ideas` | Show the board: doing, do (best first), maybe, inbox | **No** |</span>
+<span class="a">+| `/ideas #12` | Show one idea in full: brief, model, notes | **No** |</span>
+<span class="a">+| `/ideas done 12 shipped it` | Quick edit. Also `drop`, `start`, `reopen` | **No** |</span>
+<span class="a">+| `/ideas inbox` · `do` · `maybe` · `skip` · `done` · `all` · `here` | Filter the board. `here` = this project only | **No** |</span>
+<span class="a">+| `/ideas &lt;question&gt;` | Ask about your ideas, e.g. &quot;which ones fit in an hour?&quot; | Yes, briefly |</span>
+<span class="a">+| `/idea-triage` | Score the inbox and choose a model for each idea | Yes, briefly |</span>
+<span class="a">+| `/idea-go [id]` | Build the top idea (or `#id`) with its recommended model | Yes, this is the build |</span>
+<span class="a">+</span>
+<span class="a">+In the plugin menu the commands also appear as `/ideamine:idea` and so on. Both forms work.</span>
+<span class="a">+</span>
+<span class="a">+Claude can also save ideas by itself. If you write &quot;idea: dark mode for the popup&quot; or &quot;save that for later&quot;, it calls the `idea_add` tool and continues the current task.</span>
+<span class="a">+</span>
+<span class="a">+## Model routing</span>
+<span class="a">+</span>
+<span class="a">+`/idea-triage` gives each idea a verdict (`do`, `maybe`, `skip`), an impact from 1 to 5, a size from `xs` to `xl`, a one-line reason, and a short brief that an agent can act on without the original chat. It also picks the cheapest model that is likely to finish the idea in one pass. If a weaker model fails and has to retry, that costs more than using the right model once.</span>
+<span class="a">+</span>
+<span class="a">+| Model | $ in / out per 1M tokens | Gets ideas like |</span>
+<span class="a">+|---|---|---|</span>
+<span class="a">+| `haiku` (Haiku 4.5) | $1 / $5 | mechanical, fully specified, local work: typos, renames, config tweaks, boilerplate, small scripts |</span>
+<span class="a">+| `sonnet` (Sonnet 5) | $2 / $10 | the default: ordinary features, bug fixes with a clear repro, tests, docs, contained refactors |</span>
+<span class="a">+| `opus` (Opus 5) | $5 / $25 | ambiguous or cross-cutting work: architecture, hard debugging, performance, security |</span>
+<span class="a">+| `fable` (Fable 5.1) | $10 / $50 | only the hardest long-horizon or research-grade problems |</span>
+<span class="a">+</span>
+<span class="a">+The triage does not run on your session&#x27;s model. `/idea-triage` makes one tool call, and the MCP server hands the work to a separate, minimal `claude -p` run on Sonnet (see below). A session on Opus or Fable therefore pays the same few cents as a session on Haiku. If that CLI is not available, Claude does the triage itself.</span>
+<span class="a">+</span>

+<span class="a">+## Headless triage</span>
+<span class="a">+</span>
+<span class="a">+```bash</span>

+<span class="a">+```</span>
+<span class="a">+</span>
+<span class="a">+`/idea-triage` uses this same engine. +<span class="a">+## Where your ideas live</span>
+<span class="a">+</span>
+<span class="a">+`~/.ideamine/ideas.json` is plain, readable JSON. Set `IDEAMINE_HOME` to move it, for example into a synced folder. Each write takes a lock and then replaces the file in one step, so many sessions can write at the same time without losing an idea. The previous version is kept as `ideas.json.bak`. If the file becomes damaged, ideamine stops and does not overwrite it. Nothing leaves your machine, except when you run triage or a build, which go through Claude as usual.</span>
+<span class="a">+</span>
+<span class="a">+| Variable | Default | Purpose |</span>
+<span class="a">+|---|---|---|</span>
+<span class="a">+| `IDEAMINE_HOME` | `~/.ideamine` | archive location |</span>
+<span class="a">+| `IDEAMINE_TRIAGE_MODEL` | `sonnet` | model for `ideamine triage` |</span>
+<span class="a">+| `IDEAMINE_CLAUDE_BIN` | `claude` | Claude Code executable |</span>
+<span class="a">+| `IDEAMINE_SETTING_SOURCES` | *(empty)* | set to `user` if your login needs `settings.json` (e.g. `apiKeyHelper`) |</span>
+<span class="a">+</span>
+<span class="a">+## How it works</span>
+<span class="a">+</span>
+<span class="a">+```</span>
+<span class="a">+/idea …       ──► UserPromptSubmit hook ──► ~/.ideamine/ideas.json ──► &quot;💡 Saved #43&quot;   (model never called)</span>
+<span class="a">+/ideas        ──► same hook, renders the board locally</span>
+<span class="a">+</span>
+<span class="a">+/idea-triage  ──► Claude ──► MCP idea_triage ──► claude -p (Sonnet, minimal context)</span>
+<span class="a">+                                              ──► verdict · impact · size · cheapest capable model · brief</span>
+<span class="a">+/idea-go      ──► Claude ──► subagent on that model ──► builds it ──► idea_update: done</span>
+<span class="a">+```</span>
+<span class="a">+</span>
+<span class="a">+The plugin contains a Node MCP server with no dependencies, four skills (the slash commands), and one hook. The hook ignores every prompt except `/idea` and `/ideas`, and those end before any API call. The hook runs directly, not through a shell, and takes about 130 ms per prompt on Windows. The skills are user-only, so their descriptions add no tokens to your sessions. If the archive cannot be read, the hook lets the prompt through, so the `/idea` skill can still save it with the MCP tool. Your text is never dropped.</span>
