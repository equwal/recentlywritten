+<p>for routine tagging.</p>
+<p>tags.conf needs to contain this kind of format:</p>
+<pre><code>&quot;/path/to/ctags/program&quot;
+
+((&quot;&lt;directory&gt;&quot; (&quot;&lt;ext&gt;&quot;...))
+  ...)</code></pre>
+<p>The tags program reads the file extensions to infer what language to
+do tags for. Specify the directories you want to use tag browsing
+programs on.</p>
+<p>See examples in config-examples. Configuration is
+<strong>mandatory</strong> for the program to work. The format is just
+read with the lisp reader and is very simple.</p>
