+Viwoods: inside the AI screen or the crop screen, the AI key goes back
+
+The key filter now reads window changes to know which app was in use before an
+AI screen opened. It keeps the latest package name only, in memory only. When
+the AI key is pressed inside the Viwoods AI assistant, or inside the crop and
+screenshot-edit screens, the app brings that earlier app back with the same
+intent a launcher sends. If the earlier app was a home screen, it goes Home.
+
+The firmware reacts to the AI key by itself and can open its AI screen again,
+so the return waits 350 ms for that to land first. The same rule applies when
+the firmware hook points at AiKeyActivity.
+
+A switch on the AI key screen turns the rule off. It is on by default on
+Viwoods devices and absent on others.
+
+Test on a device: tools/e2e/ai-key-return.sh.
