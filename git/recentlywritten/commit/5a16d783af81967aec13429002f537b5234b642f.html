+Rebind is a tool to make the VIWoods AI Reader phone more usable with key rebindings and hardware hacks like the 5 extra-dim light settings. The VIWoods phone is a very nice piece of hardware, but the stock firmware that it comes with is not amazing. This app and the suite of tools that it spawned are a solution. Made with vibecode.
+

+
+By the time you read this it will probably be on F-Droid and the Google Play store.
+
+## Projects
+
+* [rebind](https://github.com/equwal/rebind): Core app for rebinding and for the hardware hacks.
+* [awesome-rebind](https://github.com/equwal/awesome-rebind): Similar page to this one, but AWESOME!?
+* [ink-recents](https://github.com/equwal/ink-recents): An eink recent apps slider that is way nicer than the one viwoods installs.
+* [ink-dim](https://github.com/equwal/ink-dim): Standalone app to do the dimming hack. Requires shizuku or live ADB
+* [ink-update](https://github.com/equwal/ink-update): App to update these apps. Will be obsolete when F-Droid and Google Play are working.
+
+## Promo video
+
+<https://www.youtube.com/watch?v=SRZi0YgoCJ0>
+
+## How it works
+
+Uses a bunch of hacks to get as much access to the buttons as possible. Most are possible on stock viwoods firmware, although the extra dim light feature does require the shizuku hack.
+

+
+Suckless Bookmark Manager (now sbm Sync)
+
+sbm is a bookmark manager, originally a dmenu script. It is now a multiplatform, cloud synced bookmark manager with support for teams. 
+
+## Promo video
+
+<https://www.youtube.com/watch?v=iKmYWTCkW7c>
+
+## Try it on the web
+
+* [sbmsync.com](https://sbmsync.com)
+
+## Projects
+
+* [sbm](https://github.com/equwal/sbm) multiplatform computer application
+* [sbm-android](https://github.com/equwal/sbm-android) android app
+* [sbm-extension](https://github.com/equwal/sbm-extension) firefox and chrome extensions
+* [sbm-sync](https://github.com/equwal/sbm-sync) the sync server
+* [sbm-suckless](https://github.com/equwal/sbm-suckless) the original POSIX shell script, suckless edition (no vibecode)
+
+## How it works
+
+Fuzzy search bookmarks and quickly add/copy/view bookmarks. Now with syncing through the browser and everything.
+
+## Why
+
+This tool gives you the power to spam links to your friends to the point that it annoys them.
+
+Like many others, I find search engines to be pretty tedious to use. Searching my own bookmarks is much better. With sbm you can be like me and have BASED links at your fingertips.
+
+## Support
+
+Support the work at [ko-fi.com/truex](https://ko-fi.com/truex).

+title: SubRead
+---
+
+SubRead makes it possible to read books with synced subtitles that keep your place. This is very nice for language learning.
+
+Subread is a suite of tools that port forced alignment to a variety of platforms. It is 100% free when used locally, although it is possible to do conversions with my cloud for a fee. It is 100% self-hostable free software. BUY NOW!
+
+## Promo Video
+
+<https://www.youtube.com/watch?v=WRz7UQZwe-Q>
+
+## Try it on the web
+
+* [subread.space](https://subread.space): webpage to do the conversions
+* [honjimaku.com](https://honjimaku.com): website to download or upload srt files for Japanese audiobooks
+* [kikiyomi](https://rtr46.github.io/kikiyomi/): Try reading your audiobook/srt combo on the web
+
+## Projects
+
+* [subplz-web](https://github.com/equwal/subplz-web): subread.space source
+* [subread-android](https://github.com/equwal/subread-android): subread.space android app (local and cloud conversions are possible)
+* [subread-extension](https://github.com/equwal/subread-extension): Extension to use subread on youtube for audiobooks published there.
+* [subread-overlay](https://github.com/equwal/subread-overlay): Android app to show the subtitles as an overlay on the phone. Can be used with the dictionary for a very nice AJATT experience. 
+* [subread-dictionary](https://github.com/equwal/subread-dictionary): Yomitan pop-up dictionary standalone android app. Works really good with the overlay, but can be used anywhere!
+* [subread.koplugin](https://github.com/equwal/subread.koplugin): KOReader plugin that does live highlighting of the book while you listen to it in another app like Voice, VLC, or MPV.
+* [subrep-android](https://github.com/equwal/subrep-android): Live whisper captions. Better than the ones that come with android.
+* [desktop-subtitle-replay](https://github.com/equwal/desktop-subtitle-replay): Whisper on your computer, and broadcast them to your friends. Useful for online language classrooms or bilingual exchanges.
+* [honjimaku](https://github.com/equwal/honjimaku): Book subtitles database for japanese
+* [Hoshi-Reader-Android](https://github.com/equwal/Hoshi-Reader-Android): Fork of hoshi reader that can do the conversion inside hoshi reader. Hopefully gets merged.
+
+## Why
+
+Extremely useful for learning languages by reading books with the audiobook.
+
+## Support
+
+Support the work at [ko-fi.com/truex](https://ko-fi.com/truex).
