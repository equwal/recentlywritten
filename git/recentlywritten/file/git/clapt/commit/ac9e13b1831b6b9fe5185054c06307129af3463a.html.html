129 <span class="a">+#+begin_quote</span>
130 <span class="a">+Clapt, having been clapt into existence, is the apt CL package manager.</span>
131 <span class="a">+#+end_quote</span>
132 <span class="a">+</span>
133 <span class="a">+* Clapt</span>
134 <span class="a">+A package managing /client/. Keep a list of packages efficiently installed.</span>
135 <span class="a">+* Install</span>
136 <span class="a">+We need to know which packages are needed, and whether they are from quicklisp.</span>
137 <span class="a">+1. =(asdf:load-system :clapt)=</span>
138 <span class="a">+2. =(clapt:install)=. SBCL will save and die.</span>
139 <span class="a">+By default clapt will try to overwrite your installed core file. This</span>
140 <span class="a">+may require root access on your system; alternatively, try</span>
141 <span class="a">+=(clapt:install :core &quot;path-to-your-core&quot;)= for a different core.</span>
142 <span class="a">+* Adding packages</span>
143 <span class="a">+Call =clapt:add= with the manager and packages. Current managers are =:asdf= and</span>
144 <span class="a">+=:quicklisp=.</span>
145 <span class="a">+* Updating packages</span>
146 <span class="a">+#+begin_src common-lisp :tangle no</span>
147 <span class="a">+(clapt:update)</span>
148 <span class="a">+#+end_src</span>
149 <span class="a">+</span>
150 <span class="a">+* Rationale</span>
151 <span class="a">+Loading a lot of packages from a script is slow, and having to reload the image</span>
152 <span class="a">+manually on every update is too laborious. A simple package manager</span>
153 <span class="a">+* Alternatives</span>
154 <span class="a">+- Just write an init script for your lisp like:</span>
155 <span class="a">+#+begin_src common-lisp :tangle no</span>
156 <span class="a">+(ql:quickload :petalisp)</span>
157 <span class="a">+(qul:quickload :coleslaw)</span>
158 <span class="a">+;;; ... etc.</span>
159 <span class="a">+#+end_src</span>
160 <span class="a">+This is fine if the number of packages is low. Eventually it can start to take</span>
161 <span class="a">+too long.</span>
162 <span class="a">+- Store your core manually.</span>
163 <span class="a">+  1. Write a script like the one above.</span>
164 <span class="a">+  2. =load= it.</span>
165 <span class="a">+  3. Save your core. SBCL has =sb-ext:save-lisp-and-die= for this.</span>
166 <span class="a">+  4. Start your lisp with =sbcl --core &quot;path/to/core&quot;= or similar.</span>
167 <span class="a">+This is essentially what this script does, but lacks backups and needs to be</span>
168 <span class="a">+done every time the lisp is updated.</span>
169 <span class="a">+- clpm is another attempt at the same, and has the benefit of removing itself</span>
170 <span class="a">+  from the core. It has dependencies, and is a bit involved to use.</span>
171 <span class="a">+</span>
172 <span class="a">+* Supported Systems</span>
173 <span class="a">+Looking to increase the number of items here:</span>
174 <span class="a">+- SBCL</span>
175 <span class="a">+- Clisp</span>
