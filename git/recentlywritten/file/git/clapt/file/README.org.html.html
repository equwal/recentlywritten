22 <a id="l13" href="#l13">13</a> * Clapt
23 <a id="l14" href="#l14">14</a> A package managing /client/. Keep a list of packages efficiently installed.
24 <a id="l15" href="#l15">15</a> * Install
25 <a id="l16" href="#l16">16</a> We need to know which packages are needed, and whether they are from quicklisp.
26 <a id="l17" href="#l17">17</a> 1. =(asdf:load-system :clapt)=
27 <a id="l18" href="#l18">18</a> 2. =(clapt:install)=. SBCL will save and die.
28 <a id="l19" href="#l19">19</a> By default clapt will try to overwrite your installed core file. This
29 <a id="l20" href="#l20">20</a> may require root access on your system; alternatively, try
30 <a id="l21" href="#l21">21</a> =(clapt:install :core &quot;path-to-your-core&quot;)= for a different core.
31 <a id="l22" href="#l22">22</a> * Adding packages
32 <a id="l23" href="#l23">23</a> Call =clapt:add= with the manager and packages. Current managers are =:asdf= and
33 <a id="l24" href="#l24">24</a> =:quicklisp=.
34 <a id="l25" href="#l25">25</a> * Updating packages
35 <a id="l26" href="#l26">26</a> #+begin_src common-lisp :tangle no
36 <a id="l27" href="#l27">27</a> (clapt:update)
37 <a id="l28" href="#l28">28</a> #+end_src
38 <a id="l29" href="#l29">29</a> 
39 <a id="l30" href="#l30">30</a> * Rationale
40 <a id="l31" href="#l31">31</a> Loading a lot of packages from a script is slow, and having to reload the image
41 <a id="l32" href="#l32">32</a> manually on every update is too laborious. A simple package manager should be able to do all of that.
42 <a id="l33" href="#l33">33</a> * Alternatives
43 <a id="l34" href="#l34">34</a> - Just write an init script for your lisp like:
44 <a id="l35" href="#l35">35</a> #+begin_src common-lisp :tangle no
45 <a id="l36" href="#l36">36</a> (ql:quickload :petalisp)
46 <a id="l37" href="#l37">37</a> (ql:quickload :coleslaw)
47 <a id="l38" href="#l38">38</a> ;;; ... etc.
48 <a id="l39" href="#l39">39</a> #+end_src
49 <a id="l40" href="#l40">40</a> This is fine if the number of packages is low. Eventually it can start to take
50 <a id="l41" href="#l41">41</a> too long.
51 <a id="l42" href="#l42">42</a> - Store your core manually.
52 <a id="l43" href="#l43">43</a>   1. Write a script like the one above.
53 <a id="l44" href="#l44">44</a>   2. =load= it.
54 <a id="l45" href="#l45">45</a>   3. Save your core. SBCL has =sb-ext:save-lisp-and-die= for this.
55 <a id="l46" href="#l46">46</a>   4. Start your lisp with =sbcl --core &quot;path/to/core&quot;= or similar.
56 <a id="l47" href="#l47">47</a> This is essentially what this script does, but lacks backups and needs to be
57 <a id="l48" href="#l48">48</a> done every time the lisp is updated.
58 <a id="l49" href="#l49">49</a> - clpm is another attempt at the same, and has the benefit of removing itself
59 <a id="l50" href="#l50">50</a>   from the core. It has dependencies, and is a bit involved to use.
