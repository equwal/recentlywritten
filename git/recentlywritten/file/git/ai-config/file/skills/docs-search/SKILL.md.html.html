23 <a id="l14" href="#l14">14</a> # Docs Search
24 <a id="l15" href="#l15">15</a> 
25 <a id="l16" href="#l16">16</a> Search the local Grounded Docs index for library documentation. These commands
26 <a id="l17" href="#l17">17</a> return structured data (JSON by default in non-interactive sessions) and never
27 <a id="l18" href="#l18">18</a> modify the index.
28 <a id="l19" href="#l19">19</a> 
29 <a id="l20" href="#l20">20</a> ## When to use
30 <a id="l21" href="#l21">21</a> 
31 <a id="l22" href="#l22">22</a> - You need to answer a question about a library&#x27;s API or behaviour.
32 <a id="l23" href="#l23">23</a> - You want to check which libraries and versions are already indexed.
33 <a id="l24" href="#l24">24</a> - You need to resolve which documentation version best matches a constraint.
34 <a id="l25" href="#l25">25</a> 
35 <a id="l26" href="#l26">26</a> Always run `list` first if you are unsure whether a library has been indexed.
36 <a id="l27" href="#l27">27</a> If nothing is indexed yet, use the **docs-manage** skill to scrape documentation
37 <a id="l28" href="#l28">28</a> before searching.
38 <a id="l29" href="#l29">29</a> 
39 <a id="l30" href="#l30">30</a> ## Commands
40 <a id="l31" href="#l31">31</a> 
41 <a id="l32" href="#l32">32</a> ### list
42 <a id="l33" href="#l33">33</a> 
43 <a id="l34" href="#l34">34</a> List every indexed library and its available versions.
44 <a id="l35" href="#l35">35</a> 
45 <a id="l36" href="#l36">36</a> ```bash
46 <a id="l37" href="#l37">37</a> docs-mcp list [--output yaml]
47 <a id="l38" href="#l38">38</a> ```
48 <a id="l39" href="#l39">39</a> 
49 <a id="l40" href="#l40">40</a> | Flag | Description |
50 <a id="l41" href="#l41">41</a> |------|-------------|
51 <a id="l42" href="#l42">42</a> | `--output json\|yaml\|toon` | Structured output format (default: JSON in non-interactive) |
52 <a id="l43" href="#l43">43</a> | `--server-url &lt;url&gt;` | Connect to a remote pipeline worker instead of the local store |
53 <a id="l44" href="#l44">44</a> | `--quiet` | Suppress non-error diagnostics |
54 <a id="l45" href="#l45">45</a> | `--verbose` | Enable debug logging |
55 <a id="l46" href="#l46">46</a> 
56 <a id="l47" href="#l47">47</a> Example output (YAML):

68 <a id="l59" href="#l59">59</a> ### search
69 <a id="l60" href="#l60">60</a> 
70 <a id="l61" href="#l61">61</a> Search documents in an indexed library by natural-language query.
71 <a id="l62" href="#l62">62</a> 
72 <a id="l63" href="#l63">63</a> ```bash
73 <a id="l64" href="#l64">64</a> docs-mcp search &lt;library&gt; &quot;&lt;query&gt;&quot; [options]
74 <a id="l65" href="#l65">65</a> ```
75 <a id="l66" href="#l66">66</a> 
76 <a id="l67" href="#l67">67</a> | Flag | Alias | Default | Description |
77 <a id="l68" href="#l68">68</a> |------|-------|---------|-------------|
78 <a id="l69" href="#l69">69</a> | `--version &lt;ver&gt;` | `-v` | latest | Version constraint (exact or range, e.g. `18.x`, `5.2.x`) |
79 <a id="l70" href="#l70">70</a> | `--limit &lt;n&gt;` | `-l` | `5` | Maximum number of results |
80 <a id="l71" href="#l71">71</a> | `--exact-match` | `-e` | `false` | Only match the exact version, no fallback |
81 <a id="l72" href="#l72">72</a> | `--embedding-model &lt;model&gt;` | | | Embedding model (e.g. `openai:text-embedding-3-small`) |
82 <a id="l73" href="#l73">73</a> | `--server-url &lt;url&gt;` | | | Remote pipeline worker URL |
83 <a id="l74" href="#l74">74</a> | `--output json\|yaml\|toon` | | JSON | Structured output format |
84 <a id="l75" href="#l75">75</a> | `--quiet` | | | Suppress non-error diagnostics |
85 <a id="l76" href="#l76">76</a> | `--verbose` | | | Enable debug logging |
86 <a id="l77" href="#l77">77</a> 
87 <a id="l78" href="#l78">78</a> Example:
88 <a id="l79" href="#l79">79</a> 
89 <a id="l80" href="#l80">80</a> ```bash
90 <a id="l81" href="#l81">81</a> docs-mcp search react &quot;useEffect cleanup&quot; --version 18.x --limit 3 --output yaml
91 <a id="l82" href="#l82">82</a> ```
92 <a id="l83" href="#l83">83</a> 
93 <a id="l84" href="#l84">84</a> Each result contains a content snippet, source URL, and relevance score.
94 <a id="l85" href="#l85">85</a> 
95 <a id="l86" href="#l86">86</a> ### find-version
96 <a id="l87" href="#l87">87</a> 
97 <a id="l88" href="#l88">88</a> Resolve the best matching documentation version for a library.
98 <a id="l89" href="#l89">89</a> 
99 <a id="l90" href="#l90">90</a> ```bash
100 <a id="l91" href="#l91">91</a> docs-mcp find-version &lt;library&gt; [--version &lt;pattern&gt;]
101 <a id="l92" href="#l92">92</a> ```
102 <a id="l93" href="#l93">93</a> 
103 <a id="l94" href="#l94">94</a> | Flag | Alias | Description |
104 <a id="l95" href="#l95">95</a> |------|-------|-------------|
105 <a id="l96" href="#l96">96</a> | `--version &lt;pattern&gt;` | `-v` | Version pattern to match (supports ranges) |
106 <a id="l97" href="#l97">97</a> | `--server-url &lt;url&gt;` | | Remote pipeline worker URL |
107 <a id="l98" href="#l98">98</a> | `--output json\|yaml\|toon` | | Structured output format |
108 <a id="l99" href="#l99">99</a> | `--quiet` | | Suppress non-error diagnostics |
109 <a id="l100" href="#l100">100</a> | `--verbose` | | Enable debug logging |
110 <a id="l101" href="#l101">101</a> 
111 <a id="l102" href="#l102">102</a> Example:
112 <a id="l103" href="#l103">103</a> 
113 <a id="l104" href="#l104">104</a> ```bash
114 <a id="l105" href="#l105">105</a> docs-mcp find-version react --version &quot;18.x&quot; --output yaml
115 <a id="l106" href="#l106">106</a> ```
116 <a id="l107" href="#l107">107</a> 
117 <a id="l108" href="#l108">108</a> Returns the resolved version string and library metadata.
118 <a id="l109" href="#l109">109</a> 
119 <a id="l110" href="#l110">110</a> ## Interpreting output
120 <a id="l111" href="#l111">111</a> 
121 <a id="l112" href="#l112">112</a> All three commands emit structured data to **stdout**. Diagnostics and progress
122 <a id="l113" href="#l113">113</a> messages go to **stderr** and are suppressed by default in non-interactive
123 <a id="l114" href="#l114">114</a> sessions. Use `--verbose` (or set `LOG_LEVEL=INFO`) to re-enable them.
124 <a id="l115" href="#l115">115</a> Use `--quiet` to suppress all non-error diagnostics regardless of session type.
125 <a id="l116" href="#l116">116</a> 
126 <a id="l117" href="#l117">117</a> To capture results programmatically, parse stdout as JSON (the default) or
127 <a id="l118" href="#l118">118</a> request `--output yaml` for a more readable format.
128 <a id="l119" href="#l119">119</a> 
129 <a id="l120" href="#l120">120</a> ## Typical workflow
130 <a id="l121" href="#l121">121</a> 
131 <a id="l122" href="#l122">122</a> ```bash
132 <a id="l123" href="#l123">123</a> # 1. Check what is indexed
133 <a id="l124" href="#l124">124</a> docs-mcp list --output yaml
134 <a id="l125" href="#l125">125</a> 
135 <a id="l126" href="#l126">126</a> # 2. Search for relevant docs
136 <a id="l127" href="#l127">127</a> docs-mcp search react &quot;server components&quot; --version 19.x --output yaml
137 <a id="l128" href="#l128">128</a> 
138 <a id="l129" href="#l129">129</a> # 3. If no results, index the docs first (see docs-manage skill), then retry
139 <a id="l130" href="#l130">130</a> ```</pre>
