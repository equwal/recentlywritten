22 <a id="l13" href="#l13">13</a> ## Chrome DevTools Protocol (CDP)
23 <a id="l14" href="#l14">14</a> 
24 <a id="l15" href="#l15">15</a> **Get tab WebSocket URL first**: Never connect to `ws://localhost:9222/devtools/browser` directly. Fetch `http://localhost:9222/json/list` and use `webSocketDebuggerUrl` from the active tab.
25 <a id="l16" href="#l16">16</a> 
26 <a id="l17" href="#l17">17</a> **Enable domains before use**: `Runtime.enable` and `Page.enable` must be called before any `Runtime.evaluate` or `Page.navigate` commands.
27 <a id="l18" href="#l18">18</a> 
28 <a id="l19" href="#l19">19</a> **CDP is async**: Wait for response before sending next command. Use Promise-based wrapper with response ID tracking.
29 <a id="l20" href="#l20">20</a> 
30 <a id="l21" href="#l21">21</a> **Screenshot on high-DPI**: Include `fromSurface: true` and `scale: 2` in `Page.captureScreenshot` params for Retina displays.
31 <a id="l22" href="#l22">22</a> 
32 <a id="l23" href="#l23">23</a> **Get response body separately**: `Network.responseReceived` doesn&#x27;t include body. Call `Network.getResponseBody` with requestId after response completes.
33 <a id="l24" href="#l24">24</a> 
34 <a id="l25" href="#l25">25</a> ## Chrome Extension Manifest V3
35 <a id="l26" href="#l26">26</a> 
36 <a id="l27" href="#l27">27</a> **Permissions split**: Use `permissions` for APIs, `host_permissions` for URLs. Never use `http://*/*` in permissions.
37 <a id="l28" href="#l28">28</a> 
38 <a id="l29" href="#l29">29</a> **Service workers terminate**: No persistent state. Use `chrome.storage.local` instead of global variables. Use `chrome.alarms` instead of `setInterval`.
39 <a id="l30" href="#l30">30</a> 
40 <a id="l31" href="#l31">31</a> **Content script isolation**: Can&#x27;t access page globals. Use `chrome.scripting.executeScript` with `func` for page context. Use `window.postMessage` for content↔page communication.
41 <a id="l32" href="#l32">32</a> 
42 <a id="l33" href="#l33">33</a> **Storage is async**: `chrome.storage.local.get()` returns Promise, not data. Always await. Handle `QUOTA_EXCEEDED` errors.
43 <a id="l34" href="#l34">34</a> 
44 <a id="l35" href="#l35">35</a> ## Context Detection
45 <a id="l36" href="#l36">36</a> 
46 <a id="l37" href="#l37">37</a> **Detect actual Chrome** (not Edge/Brave): Check `window.chrome &amp;&amp; navigator.vendor === &quot;Google Inc.&quot;` and exclude Opera/Edge.
47 <a id="l38" href="#l38">38</a> 
48 <a id="l39" href="#l39">39</a> **Extension context types**:
49 <a id="l40" href="#l40">40</a> - `chrome.runtime.id` exists → content script
50 <a id="l41" href="#l41">41</a> - `chrome.runtime.getManifest` exists → popup/background/options
51 <a id="l42" href="#l42">42</a> - `chrome.loadTimes` exists but no runtime → regular Chrome web page
52 <a id="l43" href="#l43">43</a> 
53 <a id="l44" href="#l44">44</a> **Manifest version check**: Wrap `chrome.runtime.getManifest()` in try-catch. Use `chrome.action` for V3, `chrome.browserAction` for V2.
54 <a id="l45" href="#l45">45</a> 
55 <a id="l46" href="#l46">46</a> ## Performance Debugging
56 <a id="l47" href="#l47">47</a> 
57 <a id="l48" href="#l48">48</a> **Memory API conditional**: Check `&#x27;memory&#x27; in performance` before accessing `performance.memory.usedJSHeapSize`.
58 <a id="l49" href="#l49">49</a> 
59 <a id="l50" href="#l50">50</a> **Use performance marks**: `performance.mark()` and `performance.measure()` for sub-frame timing. Clear marks to prevent memory leaks.
60 <a id="l51" href="#l51">51</a> 
61 <a id="l52" href="#l52">52</a> **Layout thrash detection**: PerformanceObserver with `entryTypes: [&#x27;measure&#x27;, &#x27;paint&#x27;, &#x27;largest-contentful-paint&#x27;]`. Flag entries &gt;16.67ms.
62 <a id="l53" href="#l53">53</a> 
63 <a id="l54" href="#l54">54</a> ## Network Debugging
64 <a id="l55" href="#l55">55</a> 
65 <a id="l56" href="#l56">56</a> **Block before navigate**: Call `Network.setBlockedURLs` before `Page.navigate`, not after.
66 <a id="l57" href="#l57">57</a> 
67 <a id="l58" href="#l58">58</a> **Request interception**: Use `Network.setRequestInterception` with `requestStage: &#x27;Request&#x27;` for granular control. Return `errorReason: &#x27;BlockedByClient&#x27;` to block.

69 <a id="l60" href="#l60">60</a> ## Security Contexts
70 <a id="l61" href="#l61">61</a> 
71 <a id="l62" href="#l62">62</a> **Mixed content**: HTTPS pages can&#x27;t load HTTP resources. Check `location.protocol` vs resource URL.
72 <a id="l63" href="#l63">63</a> 
73 <a id="l64" href="#l64">64</a> **CORS errors**: `TypeError` on cross-origin fetch usually means CORS. Check DevTools Network tab for specific error.
74 <a id="l65" href="#l65">65</a> 
75 <a id="l66" href="#l66">66</a> **Secure context required**: File System Access API, Clipboard API require `window.isSecureContext === true` and user gesture.</pre>
