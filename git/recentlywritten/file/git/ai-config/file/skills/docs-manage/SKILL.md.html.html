22 <a id="l13" href="#l13">13</a> # Docs Manage
23 <a id="l14" href="#l14">14</a> 
24 <a id="l15" href="#l15">15</a> Index, refresh, and remove library documentation in the local Grounded Docs
25 <a id="l16" href="#l16">16</a> store. These commands modify the index and produce plain-text status messages
26 <a id="l17" href="#l17">17</a> on stdout.
27 <a id="l18" href="#l18">18</a> 
28 <a id="l19" href="#l19">19</a> ## When to use
29 <a id="l20" href="#l20">20</a> 
30 <a id="l21" href="#l21">21</a> - A library is not yet indexed and you need its docs available for search.
31 <a id="l22" href="#l22">22</a> - Documentation may be stale and you want to pull in updated pages.
32 <a id="l23" href="#l23">23</a> - You want to remove a library or version from the index to free space.
33 <a id="l24" href="#l24">24</a> 
34 <a id="l25" href="#l25">25</a> ## Commands
35 <a id="l26" href="#l26">26</a> 
36 <a id="l27" href="#l27">27</a> ### scrape
37 <a id="l28" href="#l28">28</a> 
38 <a id="l29" href="#l29">29</a> Download and index documentation from a URL or local directory.
39 <a id="l30" href="#l30">30</a> 
40 <a id="l31" href="#l31">31</a> ```bash
41 <a id="l32" href="#l32">32</a> docs-mcp scrape &lt;library&gt; &lt;url&gt; [options]
42 <a id="l33" href="#l33">33</a> ```

47 <a id="l38" href="#l38">38</a> | `--max-pages &lt;n&gt;` | `-p` | config default | Maximum pages to scrape |
48 <a id="l39" href="#l39">39</a> | `--max-depth &lt;n&gt;` | `-d` | config default | Maximum navigation depth |
49 <a id="l40" href="#l40">40</a> | `--max-concurrency &lt;n&gt;` | `-c` | config default | Concurrent page requests |
50 <a id="l41" href="#l41">41</a> | `--ignore-errors` | | `true` | Continue on individual page errors |
51 <a id="l42" href="#l42">42</a> | `--scope subpages\|hostname\|domain` | | `subpages` | Crawling boundary |
52 <a id="l43" href="#l43">43</a> | `--follow-redirects` | | `true` | Follow HTTP redirects |
53 <a id="l44" href="#l44">44</a> | `--no-follow-redirects` | | | Disable following redirects |
54 <a id="l45" href="#l45">45</a> | `--scrape-mode auto\|fetch\|playwright` | | `auto` | HTML processing strategy |

60 <a id="l51" href="#l51">51</a> | `--clean` | | `true` | Clear existing documents before scraping |
61 <a id="l52" href="#l52">52</a> | `--quiet` | | | Suppress non-error diagnostics |

65 <a id="l56" href="#l56">56</a>

68 <a id="l59" href="#l59">59</a> docs-mcp scrape react https://react.dev/reference/react --version 19.0.0
69 <a id="l60" href="#l60">60</a> 
70 <a id="l61" href="#l61">61</a> # Scrape local files

72 <a id="l63" href="#l63">63</a> 
73 <a id="l64" href="#l64">64</a> # Scrape with depth and page limits

75 <a id="l66" href="#l66">66</a> 
76 <a id="l67" href="#l67">67</a> # Scrape with custom headers (e.g. authentication)
77 <a id="l68" href="#l68">68</a> docs-mcp scrape internal-api https://docs.internal.com \
78 <a id="l69" href="#l69">69</a>   --header &quot;Authorization: Bearer tok_xxx&quot;
79 <a id="l70" href="#l70">70</a> 
80 <a id="l71" href="#l71">71</a> # Exclude changelog pages
81 <a id="l72" href="#l72">72</a> docs-mcp scrape react https://react.dev/reference/react \
82 <a id="l73" href="#l73">73</a>   --exclude-pattern &quot;**/changelog*&quot;
83 <a id="l74" href="#l74">74</a> ```
84 <a id="l75" href="#l75">75</a> 
85 <a id="l76" href="#l76">76</a> Output is a plain-text status line, e.g. `Successfully scraped 42 pages`.
86 <a id="l77" href="#l77">77</a> Progress updates appear on stderr during the run.

89 <a id="l80" href="#l80">80</a>

100 <a id="l91" href="#l91">91</a> | `--server-url &lt;url&gt;` | | Remote pipeline worker URL |
101 <a id="l92" href="#l92">92</a> | `--quiet` | | Suppress non-error diagnostics |

118 <a id="l109" href="#l109">109</a> docs-mcp remove &lt;library&gt; [options]

124 <a id="l115" href="#l115">115</a> | `--server-url &lt;url&gt;` | | Remote pipeline worker URL |
125 <a id="l116" href="#l116">116</a> | `--quiet` | | Suppress non-error diagnostics |
126 <a id="l117" href="#l117">117</a> | `--verbose` | | Enable debug logging |

136 <a id="l127" href="#l127">127</a> ### export
137 <a id="l128" href="#l128">128</a> 
138 <a id="l129" href="#l129">129</a> Write indexed pages to Markdown files. Each page becomes
139 <a id="l130" href="#l130">130</a> `&lt;out&gt;/&lt;library&gt;/&lt;version&gt;/&lt;url-path&gt;.md` with front matter (source URL, title).
140 <a id="l131" href="#l131">131</a> 
141 <a id="l132" href="#l132">132</a> ```bash
142 <a id="l133" href="#l133">133</a> docs-mcp export [library] [options]
143 <a id="l134" href="#l134">134</a> ```
144 <a id="l135" href="#l135">135</a> 
145 <a id="l136" href="#l136">136</a> | Flag | Alias | Description |
146 <a id="l137" href="#l137">137</a> |------|-------|-------------|
147 <a id="l138" href="#l138">138</a> | `--version &lt;ver&gt;` | `-v` | Version to export (requires a library; omit for all versions) |
148 <a id="l139" href="#l139">139</a> | `--out &lt;dir&gt;` | | Output directory (defaults to `app.exportDir` config) |
149 <a id="l140" href="#l140">140</a> | `--server-url &lt;url&gt;` | | Remote pipeline worker URL |
150 <a id="l141" href="#l141">141</a> | `--quiet` | | Suppress non-error diagnostics |
151 <a id="l142" href="#l142">142</a> | `--verbose` | | Enable debug logging |
152 <a id="l143" href="#l143">143</a> 
153 <a id="l144" href="#l144">144</a> Example:
154 <a id="l145" href="#l145">145</a> 
155 <a id="l146" href="#l146">146</a> ```bash
156 <a id="l147" href="#l147">147</a> docs-mcp export react --out ~/docs
157 <a id="l148" href="#l148">148</a> ```
158 <a id="l149" href="#l149">149</a> 
159 <a id="l150" href="#l150">150</a> The version directory is replaced on each export. Do not scrape the export
160 <a id="l151" href="#l151">151</a> directory back into the index.
161 <a id="l152" href="#l152">152</a> 
162 <a id="l153" href="#l153">153</a> ## Output behaviour
163 <a id="l154" href="#l154">154</a> 
164 <a id="l155" href="#l155">155</a> The `scrape`, `refresh`, and `remove` commands write plain-text status messages to **stdout** and
165 <a id="l156" href="#l156">156</a> diagnostics to **stderr**. The global `--output` flag is accepted but has no
166 <a id="l157" href="#l157">157</a> effect because the output is plain text, not structured data.
167 <a id="l158" href="#l158">158</a> 
168 <a id="l159" href="#l159">159</a> In non-interactive sessions, diagnostics are suppressed by default. Use
169 <a id="l160" href="#l160">160</a> `--verbose` (or set `LOG_LEVEL=INFO`) to re-enable them. Use `--quiet` to
170 <a id="l161" href="#l161">161</a> suppress all non-error diagnostics regardless of session type.
171 <a id="l162" href="#l162">162</a> 
172 <a id="l163" href="#l163">163</a> ## Typical workflow
173 <a id="l164" href="#l164">164</a> 
174 <a id="l165" href="#l165">165</a> ```bash
175 <a id="l166" href="#l166">166</a> # 1. Index documentation for the first time
176 <a id="l167" href="#l167">167</a> docs-mcp scrape react https://react.dev/reference/react --version 19.0.0
177 <a id="l168" href="#l168">168</a> 
178 <a id="l169" href="#l169">169</a> # 2. Later, refresh to pick up any changes
179 <a id="l170" href="#l170">170</a> docs-mcp refresh react --version 19.0.0
180 <a id="l171" href="#l171">171</a> 
181 <a id="l172" href="#l172">172</a> # 3. Clean up old versions
182 <a id="l173" href="#l173">173</a> docs-mcp remove react --version 18.3.1
183 <a id="l174" href="#l174">174</a> ```
184 <a id="l175" href="#l175">175</a> 
185 <a id="l176" href="#l176">176</a> ## Important notes
186 <a id="l177" href="#l177">177</a> 
187 <a id="l178" href="#l178">178</a> - **Scraping can take time.** Large documentation sites with hundreds of pages
188 <a id="l179" href="#l179">179</a>   may run for several minutes. Use `--max-pages` and `--max-depth` to limit
189 <a id="l180" href="#l180">180</a>   scope when you only need a subset.
190 <a id="l181" href="#l181">181</a> - **Local files** must use the `file://` URL scheme
191 <a id="l182" href="#l182">182</a>   (e.g. `file:///absolute/path/to/docs`).
192 <a id="l183" href="#l183">183</a> - **`--clean` is on by default** for `scrape`, meaning existing documents for
193 <a id="l184" href="#l184">184</a>   the same library+version are removed before re-indexing. Pass `--no-clean` to
194 <a id="l185" href="#l185">185</a>   append instead.
195 <a id="l186" href="#l186">186</a> - **`refresh`** only works on previously indexed content. It uses HTTP ETags to
196 <a id="l187" href="#l187">187</a>   skip pages that have not changed, making it much faster than a full re-scrape.</pre>
