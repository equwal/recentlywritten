15 <a id="l6" href="#l6">6</a> # sshp: parallel SSH runner
16 <a id="l7" href="#l7">7</a> 
17 <a id="l8" href="#l8">8</a> `sshp` (https://github.com/bahamas10/sshp) runs one command on many hosts at once and prefixes each output line with `[host]`. Prefer it over a shell loop of `ssh` calls.
18 <a id="l9" href="#l9">9</a> 
19 <a id="l10" href="#l10">10</a> If the `sshp_run` MCP tool is available, use it: it enforces the host allowlist and returns JSON per host. If the operator left `allow_write` off, it refuses commands outside a read-only verb list. Otherwise call the `sshp` binary as below.
20 <a id="l11" href="#l11">11</a> 
21 <a id="l12" href="#l12">12</a> ## Rules
22 <a id="l13" href="#l13">13</a> 
23 <a id="l14" href="#l14">14</a> 1. **Probe first.** Commands that change nothing are a good start: `uptime`, `df -h`, `systemctl is-active X`, `journalctl -u X -n 50`, `cat /etc/os-release`.
24 <a id="l15" href="#l15">15</a> 2. **Dry run risky commands.** Run with `-n` to list what would run. For a destructive command (delete, reboot, mass restart), show the user the host list and command and get a yes first.
25 <a id="l16" href="#l16">16</a> 3. **Never let it hang.** Always pass `-o BatchMode=yes -o ConnectTimeout=10`. A password prompt or host-key prompt then fails fast instead of blocking.
26 <a id="l17" href="#l17">17</a> 4. **Limit concurrency for heavy work.** Default `-m 50`. Use `-m 1` for rolling changes (one host at a time), `-m 5` for anything that loads the hosts.
27 <a id="l18" href="#l18">18</a> 5. **Read exit codes per host.** Always pass `-e`. sshp prints `[host] exited: N (T ms)`. Report the hosts that failed, not only the overall status. sshp itself exits non-zero if any host failed.
28 <a id="l19" href="#l19">19</a> 6. **Use a hosts file.** `-f hosts` reads one host per line (`user@host` works). Do not invent hosts; use the ones the user gives or the configured file (`~/.config/sshp-ai/hosts`).
29 <a id="l20" href="#l20">20</a> 
30 <a id="l21" href="#l21">21</a> ## Commands
31 <a id="l22" href="#l22">22</a> 
32 <a id="l23" href="#l23">23</a> ```sh
33 <a id="l24" href="#l24">24</a> # Run: one line per host, exit codes, no prompts
34 <a id="l25" href="#l25">25</a> sshp -e -c off -o BatchMode=yes -o ConnectTimeout=10 -f hosts uptime
35 <a id="l26" href="#l26">26</a> 
36 <a id="l27" href="#l27">27</a> # Group output by host (multi-line output stays together)
37 <a id="l28" href="#l28">28</a> sshp -g -e -f hosts -- df -h /
38 <a id="l29" href="#l29">29</a> 
39 <a id="l30" href="#l30">30</a> # Join mode: group hosts that produced identical output (spot the odd one out)
40 <a id="l31" href="#l31">31</a> sshp -j -f hosts -- uname -r
41 <a id="l32" href="#l32">32</a> 
42 <a id="l33" href="#l33">33</a> # Dry run: show what would run, start nothing
43 <a id="l34" href="#l34">34</a> sshp -n -f hosts -- systemctl restart nginx
44 <a id="l35" href="#l35">35</a> 
45 <a id="l36" href="#l36">36</a> # Rolling change after the user said yes: one host at a time, login as root
46 <a id="l37" href="#l37">37</a> sshp -m 1 -g -e -l root -f hosts -- systemctl restart nginx
47 <a id="l38" href="#l38">38</a> ```
48 <a id="l39" href="#l39">39</a> 
49 <a id="l40" href="#l40">40</a> Put `--` before the remote command so sshp does not parse its flags. Quote a remote pipeline as one argument: `sshp -f hosts -- &#x27;ps aux | grep nginx&#x27;`.
50 <a id="l41" href="#l41">41</a> 
51 <a id="l42" href="#l42">42</a> ## Exit codes
52 <a id="l43" href="#l43">43</a> 
53 <a id="l44" href="#l44">44</a> | sshp exit | Meaning |
54 <a id="l45" href="#l45">45</a> |---|---|
55 <a id="l46" href="#l46">46</a> | 0 | Every host exited 0 |
56 <a id="l47" href="#l47">47</a> | 1 | At least one host exited non-zero (see `[host] exited:` lines) |
57 <a id="l48" href="#l48">48</a> | 2 | Bad sshp arguments |
58 <a id="l49" href="#l49">49</a> | 4 | Interrupted (SIGINT or SIGTERM) |
59 <a id="l50" href="#l50">50</a> 
60 <a id="l51" href="#l51">51</a> Per host, `255` means ssh itself failed (DNS, refused, auth, host key). Any other code is the remote command&#x27;s own exit code.</pre>
