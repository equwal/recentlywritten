24 <a id="l15" href="#l15">15</a> ## Eye-Tracking and Reading Patterns
25 <a id="l16" href="#l16">16</a> 
26 <a id="l17" href="#l17">17</a> ### The F-Pattern (Nielsen Norman Group, 2006-2017)
27 <a id="l18" href="#l18">18</a> 
28 <a id="l19" href="#l19">19</a> **Study details**: 232 users across thousands of web pages, tracked over 11 years
29 <a id="l20" href="#l20">20</a> 
30 <a id="l21" href="#l21">21</a> **Three movements of the F-pattern:**
31 <a id="l22" href="#l22">22</a> 1. **Horizontal movement** across upper content (F&#x27;s top bar)
32 <a id="l23" href="#l23">23</a> 2. **Second horizontal movement** lower down, typically shorter (F&#x27;s lower bar)
33 <a id="l24" href="#l24">24</a> 3. **Vertical scan** down the left side (F&#x27;s stem)
34 <a id="l25" href="#l25">25</a> 
35 <a id="l26" href="#l26">26</a> **Key findings:**
36 <a id="l27" href="#l27">27</a> - First two paragraphs receive most attention
37 <a id="l28" href="#l28">28</a> - Left-aligned text gets 69% more visual attention
38 <a id="l29" href="#l29">29</a> - Content on right side often ignored
39 <a id="l30" href="#l30">30</a> - Users rarely read word-for-word; scanning is default
40 <a id="l31" href="#l31">31</a> 
41 <a id="l32" href="#l32">32</a> ### Four Main Scanning Patterns (2019 Update)
42 <a id="l33" href="#l33">33</a> 
43 <a id="l34" href="#l34">34</a> 1. **F-Pattern**: Traditional horizontal-vertical scanning (least effective for content absorption)
44 <a id="l35" href="#l35">35</a> 
45 <a id="l36" href="#l36">36</a> 2. **Spotted Pattern**: Skipping to visually distinct elements
46 <a id="l37" href="#l37">37</a>    - Users focus on: links, bold text, bullets, numbers
47 <a id="l38" href="#l38">38</a>    - Effectiveness depends on highlighting key terms
48 <a id="l39" href="#l39">39</a> 
49 <a id="l40" href="#l40">40</a> 3. **Layer-Cake Pattern**: Scanning headings only (highly effective)
50 <a id="l41" href="#l41">41</a>    - Readers scan headings until finding relevant section
51 <a id="l42" href="#l42">42</a>    - Creates horizontal stripe pattern in heat maps
52 <a id="l43" href="#l43">43</a>    - &quot;Aside from reading every word, the most effective scanning pattern&quot;
53 <a id="l44" href="#l44">44</a> 
54 <a id="l45" href="#l45">45</a> 4. **Commitment Pattern**: Traditional reading (rare, 10-20% of users)
55 <a id="l46" href="#l46">46</a>    - Occurs when users highly motivated
56 <a id="l47" href="#l47">47</a>    - Most comprehensive but time-consuming
57 <a id="l48" href="#l48">48</a> 
58 <a id="l49" href="#l49">49</a> ### Design Implications
59 <a id="l50" href="#l50">50</a> 
60 <a id="l51" href="#l51">51</a> - **Most users read very little**: Assume scanning
61 <a id="l52" href="#l52">52</a> - **Support scanning through**:
62 <a id="l53" href="#l53">53</a>   - Meaningful subheadings
63 <a id="l54" href="#l54">54</a>   - Bulleted lists
64 <a id="l55" href="#l55">55</a>   - Visual styling for keywords
65 <a id="l56" href="#l56">56</a>   - Chunked sections
66 <a id="l57" href="#l57">57</a> - **79% of web visitors skim** rather than read every word
67 <a id="l58" href="#l58">58</a> - **Average time on page: 15 seconds**

69 <a id="l60" href="#l60">60</a> ## The Inverted Pyramid
70 <a id="l61" href="#l61">61</a> 
71 <a id="l62" href="#l62">62</a> ### Origin and Validation
72 <a id="l63" href="#l63">63</a> 
73 <a id="l64" href="#l64">64</a> Journalism best practice validated by Nielsen Norman Group (2018).
74 <a id="l65" href="#l65">65</a> 
75 <a id="l66" href="#l66">66</a> **Core principle**: Most important information first, followed by supporting details in descending order of importance.
76 <a id="l67" href="#l67">67</a> 
77 <a id="l68" href="#l68">68</a> ### Benefits Measured
78 <a id="l69" href="#l69">69</a> 
79 <a id="l70" href="#l70">70</a> - **Improved comprehension**: Users form mental models faster
80 <a id="l71" href="#l71">71</a> - **Decreased interaction cost**: Main point understood without deep reading
81 <a id="l72" href="#l72">72</a> - **Encourages scrolling**: 71% more likely to scroll when engaged by opening
82 <a id="l73" href="#l73">73</a> - **Supports skimmers**: Users can stop at any point with understanding
83 <a id="l74" href="#l74">74</a> 
84 <a id="l75" href="#l75">75</a> ### Structure
85 <a id="l76" href="#l76">76</a> 
86 <a id="l77" href="#l77">77</a> | Section | Reader Reach | Content |
87 <a id="l78" href="#l78">78</a> |---------|-------------|---------|
88 <a id="l79" href="#l79">79</a> | First paragraph | 100% | The conclusion/main point |
89 <a id="l80" href="#l80">80</a> | Second paragraph | 50-80% | Critical supporting details |
90 <a id="l81" href="#l81">81</a> | Subsequent | 20% | Decreasing importance |
91 <a id="l82" href="#l82">82</a> 
92 <a id="l83" href="#l83">83</a> ### Effectiveness Data
93 <a id="l84" href="#l84">84</a> 
94 <a id="l85" href="#l85">85</a> - 20% higher comprehension scores
95 <a id="l86" href="#l86">86</a> - 35% faster task completion
96 <a id="l87" href="#l87">87</a> - 40% reduction in bounce rate
97 <a id="l88" href="#l88">88</a> 
98 <a id="l89" href="#l89">89</a> ### Application
99 <a id="l90" href="#l90">90</a> 
100 <a id="l91" href="#l91">91</a> ```
101 <a id="l92" href="#l92">92</a> Traditional (avoid):
102 <a id="l93" href="#l93">93</a> Background → Context → Details → Conclusion
103 <a id="l94" href="#l94">94</a> 
104 <a id="l95" href="#l95">95</a> Inverted Pyramid (prefer):
105 <a id="l96" href="#l96">96</a> Conclusion → Key Evidence → Supporting Details → Background
106 <a id="l97" href="#l97">97</a> ```

150 <a id="l141" href="#l141">141</a> 
151 <a id="l142" href="#l142">142</a> ### Eye-Tracking Evidence
152 <a id="l143" href="#l143">143</a> 
153 <a id="l144" href="#l144">144</a> **Research findings** (Hyöna &amp; Lorch, 2004-2006):
154 <a id="l145" href="#l145">145</a> - Headings receive disproportionate attention
155 <a id="l146" href="#l146">146</a> - Users spend 2-3x longer on headings than body text
156 <a id="l147" href="#l147">147</a> - Layer-cake scanning: Many users read headings only
157 <a id="l148" href="#l148">148</a> 
158 <a id="l149" href="#l149">149</a> ### Meta-Analysis on Text Structure
159 <a id="l150" href="#l150">150</a> 
160 <a id="l151" href="#l151">151</a> **Bogaerds-Hazenberg et al. (2021):**
161 <a id="l152" href="#l152">152</a> - Text structure instruction improves comprehension by 0.35 standard deviations
162 <a id="l153" href="#l153">153</a> - Descriptive headings improve recall by 28%
163 <a id="l154" href="#l154">154</a> - Hierarchical structure reduces cognitive load
164 <a id="l155" href="#l155">155</a> 
165 <a id="l156" href="#l156">156</a> ### Best Practices
166 <a id="l157" href="#l157">157</a> 
167 <a id="l158" href="#l158">158</a> **Effective headings are:**
168 <a id="l159" href="#l159">159</a> 1. **Descriptive**: Communicate content, not clever wordplay
169 <a id="l160" href="#l160">160</a> 2. **Front-loaded**: Key words at beginning
170 <a id="l161" href="#l161">161</a> 3. **Hierarchical**: Clear H1 → H2 → H3 structure
171 <a id="l162" href="#l162">162</a> 4. **Scannable**: Stand alone without context
172 <a id="l163" href="#l163">163</a> 5. **Specific**: 6-8 words optimal
173 <a id="l164" href="#l164">164</a> 
174 <a id="l165" href="#l165">165</a> **Heading frequency:**
175 <a id="l166" href="#l166">166</a> - Every 3-4 paragraphs for long-form content
176 <a id="l167" href="#l167">167</a> - Every 300-500 words as rough guide

186 <a id="l177" href="#l177">177</a> 
187 <a id="l178" href="#l178">178</a> ### When Lists Win
188 <a id="l179" href="#l179">179</a> 
189 <a id="l180" href="#l180">180</a> **Research findings (multiple studies):**
190 <a id="l181" href="#l181">181</a> - 3x better recall of individual items in lists vs paragraphs
191 <a id="l182" href="#l182">182</a> - Lists highlight key points more effectively
192 <a id="l183" href="#l183">183</a> - Processing advantage for item-specific information
193 <a id="l184" href="#l184">184</a> - 40% faster information retrieval
194 <a id="l185" href="#l185">185</a> 
195 <a id="l186" href="#l186">186</a> **Lists excel for:**
196 <a id="l187" href="#l187">187</a> - Enumerating features or steps
197 <a id="l188" href="#l188">188</a> - Presenting options or choices
198 <a id="l189" href="#l189">189</a> - Highlighting key takeaways
199 <a id="l190" href="#l190">190</a> - Mobile interfaces (critical for scanability)
200 <a id="l191" href="#l191">191</a> 
201 <a id="l192" href="#l192">192</a> ### When Paragraphs Work Better
202 <a id="l193" href="#l193">193</a> 
203 <a id="l194" href="#l194">194</a> **Research caveats:**
204 <a id="l195" href="#l195">195</a> - **Heterogeneous content**: Mixed information types work better in paragraphs
205 <a id="l196" href="#l196">196</a> - **Context retention**: Lists can decrease recall of surrounding content by 15%
206 <a id="l197" href="#l197">197</a> - **Narrative flow**: Complex arguments need paragraph structure
207 <a id="l198" href="#l198">198</a> - **Relationships**: When items are interconnected

209 <a id="l200" href="#l200">200</a> ### Optimal List Implementation
210 <a id="l201" href="#l201">201</a> 
211 <a id="l202" href="#l202">202</a> **Best practices from studies:**
212 <a id="l203" href="#l203">203</a> - Lead-in sentence to frame the list
213 <a id="l204" href="#l204">204</a> - Parallel structure (consistent grammar)
214 <a id="l205" href="#l205">205</a> - Appropriate punctuation based on content
215 <a id="l206" href="#l206">206</a> - One level deep maximum (nested lists -23% comprehension)
216 <a id="l207" href="#l207">207</a> - 2 sentences maximum per bullet point
217 <a id="l208" href="#l208">208</a> 
218 <a id="l209" href="#l209">209</a> **Nielsen Norman Guideline**: Use lists when you have 3+ related items; use paragraphs for narrative or complex relationships.

220 <a id="l211" href="#l211">211</a> ## Chunking and Cognitive Load
221 <a id="l212" href="#l212">212</a> 
222 <a id="l213" href="#l213">213</a> ### The Science
223 <a id="l214" href="#l214">214</a> 
224 <a id="l215" href="#l215">215</a> **George Miller (1956)**: Working memory holds 5-9 &quot;chunks&quot; of information.

226 <a id="l217" href="#l217">217</a> **Modern application** (Nielsen Norman Group, 2016):
227 <a id="l218" href="#l218">218</a> - Breaking content into chunks improves processing
228 <a id="l219" href="#l219">219</a> - Chunks should represent meaningful units
229 <a id="l220" href="#l220">220</a> - Optimal chunk size: 3-5 related items
230 <a id="l221" href="#l221">221</a> 
231 <a id="l222" href="#l222">222</a> ### Chunking Strategies
232 <a id="l223" href="#l223">223</a> 
233 <a id="l224" href="#l224">224</a> 1. **Paragraph breaks**: Visual breathing room
234 <a id="l225" href="#l225">225</a> 2. **Subheadings**: Topic boundaries
235 <a id="l226" href="#l226">226</a> 3. **Lists**: Related items grouped
236 <a id="l227" href="#l227">227</a> 4. **Visual separators**: Borders, spacing, color blocks

334 <a id="l325" href="#l325">325</a> ## Gestalt Principles for Content
335 <a id="l326" href="#l326">326</a> 
336 <a id="l327" href="#l327">327</a> ### Key Principles
337 <a id="l328" href="#l328">328</a> 
338 <a id="l329" href="#l329">329</a> **1. Proximity**: Related items should be close together
339 <a id="l330" href="#l330">330</a> - Reduces cognitive effort by 19%
340 <a id="l331" href="#l331">331</a> - Creates implicit groupings
341 <a id="l332" href="#l332">332</a> - Users process grouped items as single units
342 <a id="l333" href="#l333">333</a> 
343 <a id="l334" href="#l334">334</a> **2. Similarity**: Similar items perceived as related
344 <a id="l335" href="#l335">335</a> - Consistent formatting creates patterns
345 <a id="l336" href="#l336">336</a> - Users scan 23% faster
346 <a id="l337" href="#l337">337</a> - Reduces learning curve
347 <a id="l338" href="#l338">338</a> 
348 <a id="l339" href="#l339">339</a> **3. Continuity**: Eyes follow continuous lines/patterns
349 <a id="l340" href="#l340">340</a> - Guides reading flow
350 <a id="l341" href="#l341">341</a> - Creates visual hierarchy
351 <a id="l342" href="#l342">342</a> - Improves navigation by 35%
352 <a id="l343" href="#l343">343</a> 
353 <a id="l344" href="#l344">344</a> **4. Figure/Ground**: Content vs background separation
354 <a id="l345" href="#l345">345</a> - Essential for readability
355 <a id="l346" href="#l346">346</a> - 4.5:1 contrast ratio minimum (WCAG AA)
356 <a id="l347" href="#l347">347</a> - Proper contrast reduces strain
357 <a id="l348" href="#l348">348</a> 
358 <a id="l349" href="#l349">349</a> ### Application to Content
