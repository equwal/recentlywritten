23 <a id="l14" href="#l14">14</a> ## The Four-Level Editing System
24 <a id="l15" href="#l15">15</a> 
25 <a id="l16" href="#l16">16</a> ### Overview
26 <a id="l17" href="#l17">17</a> 
27 <a id="l18" href="#l18">18</a> Professional editors work through four distinct levels, never mixing concerns:
28 <a id="l19" href="#l19">19</a> 
29 <a id="l20" href="#l20">20</a> | Level | Focus | Time Investment |
30 <a id="l21" href="#l21">21</a> |-------|-------|-----------------|
31 <a id="l22" href="#l22">22</a> | 1. Developmental | Structure, content, argument | 30-50% |
32 <a id="l23" href="#l23">23</a> | 2. Line | Style, clarity, flow | 25-35% |
33 <a id="l24" href="#l24">24</a> | 3. Copy | Grammar, consistency, facts | 20-30% |
34 <a id="l25" href="#l25">25</a> | 4. Proofreading | Typos, formatting | 10-15% |
35 <a id="l26" href="#l26">26</a> 
36 <a id="l27" href="#l27">27</a> **Critical principle**: Work through levels sequentially. Fixing typos before addressing structure wastes time.
37 <a id="l28" href="#l28">28</a> 
38 <a id="l29" href="#l29">29</a> ### Level 1: Developmental Editing
39 <a id="l30" href="#l30">30</a> 
40 <a id="l31" href="#l31">31</a> **Focus**: Big-picture organization, narrative flow, argument structure
41 <a id="l32" href="#l32">32</a> 
42 <a id="l33" href="#l33">33</a> **Questions to ask:**
43 <a id="l34" href="#l34">34</a> - What is the core message? (Write it in one sentence)
44 <a id="l35" href="#l35">35</a> - Does every section advance this message?
45 <a id="l36" href="#l36">36</a> - Is information in logical order?
46 <a id="l37" href="#l37">37</a> - Are there gaps in logic or evidence?
47 <a id="l38" href="#l38">38</a> 
48 <a id="l39" href="#l39">39</a> **Technique**: Reverse outline
49 <a id="l40" href="#l40">40</a> - After drafting, outline what you wrote
50 <a id="l41" href="#l41">41</a> - Each paragraph = one bullet
51 <a id="l42" href="#l42">42</a> - Gaps and redundancies become visible
52 <a id="l43" href="#l43">43</a> 
53 <a id="l44" href="#l44">44</a> ### Level 2: Line Editing
54 <a id="l45" href="#l45">45</a> 
55 <a id="l46" href="#l46">46</a> **Focus**: Sentence-level improvements, paragraph flow, voice consistency
56 <a id="l47" href="#l47">47</a> 
57 <a id="l48" href="#l48">48</a> **Questions to ask:**
58 <a id="l49" href="#l49">49</a> - Is this the clearest way to say this?
59 <a id="l50" href="#l50">50</a> - Can I say this in fewer words?
60 <a id="l51" href="#l51">51</a> - Does each paragraph have one clear focus?
61 <a id="l52" href="#l52">52</a> - Are transitions smooth?
62 <a id="l53" href="#l53">53</a> 
63 <a id="l54" href="#l54">54</a> **Technique**: Read aloud
64 <a id="l55" href="#l55">55</a> - Unclear passages trip your tongue
65 <a id="l56" href="#l56">56</a> - Run-on sentences make you gasp for breath
66 <a id="l57" href="#l57">57</a> - Awkward phrasing becomes obvious
67 <a id="l58" href="#l58">58</a> 
68 <a id="l59" href="#l59">59</a> ### Level 3: Copyediting
69 <a id="l60" href="#l60">60</a> 
70 <a id="l61" href="#l61">61</a> **Focus**: Grammar, punctuation, style guide adherence, fact-checking
71 <a id="l62" href="#l62">62</a> 
72 <a id="l63" href="#l63">63</a> **Questions to ask:**
73 <a id="l64" href="#l64">64</a> - Is this grammatically correct?
74 <a id="l65" href="#l65">65</a> - Is it consistent with prior usage?
75 <a id="l66" href="#l66">66</a> - Are facts and citations accurate?
76 <a id="l67" href="#l67">67</a> 
77 <a id="l68" href="#l68">68</a> **Technique**: Separate passes for different concerns
78 <a id="l69" href="#l69">69</a> - One pass for punctuation
79 <a id="l70" href="#l70">70</a> - One pass for consistency
80 <a id="l71" href="#l71">71</a> - One pass for facts
81 <a id="l72" href="#l72">72</a> 
82 <a id="l73" href="#l73">73</a> ### Level 4: Proofreading
83 <a id="l74" href="#l74">74</a> 
84 <a id="l75" href="#l75">75</a> **Focus**: Typos, formatting, layout issues
85 <a id="l76" href="#l76">76</a> 
86 <a id="l77" href="#l77">77</a> **Questions to ask:**
87 <a id="l78" href="#l78">78</a> - Are there any remaining errors?
88 <a id="l79" href="#l79">79</a> - Is formatting consistent?
89 <a id="l80" href="#l80">80</a> - Do all links work?
90 <a id="l81" href="#l81">81</a> 
91 <a id="l82" href="#l82">82</a> **Technique**: Read backwards
92 <a id="l83" href="#l83">83</a> - Forces focus on individual words
93 <a id="l84" href="#l84">84</a> - Prevents brain from &quot;filling in&quot; expected text
94 <a id="l85" href="#l85">85</a> - Catches typos the eye normally skips

96 <a id="l87" href="#l87">87</a> ## Revision Strategy Research
97 <a id="l88" href="#l88">88</a> 
98 <a id="l89" href="#l89">89</a> ### Graham &amp; Perin Meta-Analysis (2007)
99 <a id="l90" href="#l90">90</a> 
100 <a id="l91" href="#l91">91</a> Analysis of 123 studies with 154 effect sizes:
101 <a id="l92" href="#l92">92</a> 
102 <a id="l93" href="#l93">93</a> | Intervention | Effect Size |
103 <a id="l94" href="#l94">94</a> |--------------|-------------|
104 <a id="l95" href="#l95">95</a> | Strategy instruction | 0.82 (highest) |
105 <a id="l96" href="#l96">96</a> | Sentence combining | 0.50 |
106 <a id="l97" href="#l97">97</a> | Process writing | 0.32 |
107 <a id="l98" href="#l98">98</a> | Grammar instruction | -0.32 (negative) |
108 <a id="l99" href="#l99">99</a> 
109 <a id="l100" href="#l100">100</a> **Key insight**: Teaching explicit revision strategies has nearly triple the impact of teaching grammar rules.
110 <a id="l101" href="#l101">101</a> 
111 <a id="l102" href="#l102">102</a> ### What &quot;Strategy Instruction&quot; Means
112 <a id="l103" href="#l103">103</a> 
113 <a id="l104" href="#l104">104</a> The most effective approach combines:
114 <a id="l105" href="#l105">105</a> 1. **Cognitive strategies**: Planning, organizing, self-regulation
115 <a id="l106" href="#l106">106</a> 2. **Metacognitive strategies**: Self-assessment, reflection
116 <a id="l107" href="#l107">107</a> 3. **Procedural knowledge**: Specific techniques to apply
117 <a id="l108" href="#l108">108</a> 
118 <a id="l109" href="#l109">109</a> **Implication**: Having a revision process matters more than knowing grammar rules.
119 <a id="l110" href="#l110">110</a> 
120 <a id="l111" href="#l111">111</a> ### Timing Research
121 <a id="l112" href="#l112">112</a> 
122 <a id="l113" href="#l113">113</a> Studies show separating drafting from editing improves quality:
123 <a id="l114" href="#l114">114</a> - Self-assessment before and after revision improves both self-efficacy and writing
124 <a id="l115" href="#l115">115</a> - 24-hour gap between drafting and editing recommended (cognitive refresh)
125 <a id="l116" href="#l116">116</a> - &quot;Kill your darlings&quot; easier with time distance

127 <a id="l118" href="#l118">118</a> ## The Conciseness Pass
128 <a id="l119" href="#l119">119</a> 
129 <a id="l120" href="#l120">120</a> ### Scott Hotaling&#x27;s Framework (Limnology and Oceanography Letters, 2020)
130 <a id="l121" href="#l121">121</a> 
131 <a id="l122" href="#l122">122</a> Three types of filler that reduce conciseness:
132 <a id="l123" href="#l123">123</a> 
133 <a id="l124" href="#l124">124</a> **1. Qualifiers (adverbs)**
134 <a id="l125" href="#l125">125</a> - Examples: quickly, extremely, frequently, very, really
135 <a id="l126" href="#l126">126</a> - Impact: Often add zero information
136 <a id="l127" href="#l127">127</a> - Fix: Remove entirely in most cases
137 <a id="l128" href="#l128">128</a> 
138 <a id="l129" href="#l129">129</a> **2. Prepositional phrase chains**
139 <a id="l130" href="#l130">130</a> - Examples: &quot;in this case,&quot; &quot;among other things,&quot; &quot;on the other hand&quot;
140 <a id="l131" href="#l131">131</a> - Impact: Make sentences jumbled and unclear
141 <a id="l132" href="#l132">132</a> - Fix: Replace multi-word phrases with single words
142 <a id="l133" href="#l133">133</a> 
143 <a id="l134" href="#l134">134</a> **3. Overused transitions**
144 <a id="l135" href="#l135">135</a> - Examples: however, meanwhile, thus, furthermore
145 <a id="l136" href="#l136">136</a> - Impact: Create verbal clutter when overused
146 <a id="l137" href="#l137">137</a> - Fix: Remove extraneous transitions, combine sentences
147 <a id="l138" href="#l138">138</a>

195 <a id="l186" href="#l186">186</a> ## Active Voice Conversion
196 <a id="l187" href="#l187">187</a> 
197 <a id="l188" href="#l188">188</a> ### Identification
198 <a id="l189" href="#l189">189</a> 
199 <a id="l190" href="#l190">190</a> Passive voice pattern: form of &quot;to be&quot; + past participle
200 <a id="l191" href="#l191">191</a> 
201 <a id="l192" href="#l192">192</a> | Passive Indicator | Example |
202 <a id="l193" href="#l193">193</a> |-------------------|---------|
203 <a id="l194" href="#l194">194</a> | is/was + past participle | &quot;was written&quot; |
204 <a id="l195" href="#l195">195</a> | are/were + past participle | &quot;were found&quot; |
205 <a id="l196" href="#l196">196</a> | has/have been + past participle | &quot;has been completed&quot; |
206 <a id="l197" href="#l197">197</a> | will be + past participle | &quot;will be reviewed&quot; |
207 <a id="l198" href="#l198">198</a> 
208 <a id="l199" href="#l199">199</a> ### Conversion Process
209 <a id="l200" href="#l200">200</a> 
210 <a id="l201" href="#l201">201</a> 1. Identify the true actor (who/what performs the action)
211 <a id="l202" href="#l202">202</a> 2. Make the actor the subject
212 <a id="l203" href="#l203">203</a> 3. Use active verb form
213 <a id="l204" href="#l204">204</a> 
214 <a id="l205" href="#l205">205</a> **Examples:**
215 <a id="l206" href="#l206">206</a> 
216 <a id="l207" href="#l207">207</a> | Passive | Active |
217 <a id="l208" href="#l208">208</a> |---------|--------|
218 <a id="l209" href="#l209">209</a> | The report was written by the team | The team wrote the report |
219 <a id="l210" href="#l210">210</a> | Errors were found in the code | We found errors in the code |
220 <a id="l211" href="#l211">211</a> | The meeting was scheduled for 3pm | I scheduled the meeting for 3pm |
221 <a id="l212" href="#l212">212</a> | A decision was made to proceed | The board decided to proceed |
222 <a id="l213" href="#l213">213</a> | The feature has been implemented | We implemented the feature |
223 <a id="l214" href="#l214">214</a> | Concerns were raised about costs | Stakeholders raised concerns about costs |
224 <a id="l215" href="#l215">215</a> 
225 <a id="l216" href="#l216">216</a> ### When to Keep Passive
226 <a id="l217" href="#l217">217</a> 
227 <a id="l218" href="#l218">218</a> Keep passive voice only when:
228 <a id="l219" href="#l219">219</a> - **Actor unknown**: &quot;The window was broken&quot; (no one knows by whom)
229 <a id="l220" href="#l220">220</a> - **Actor irrelevant**: &quot;The samples were collected&quot; (focus on samples, not collector)
230 <a id="l221" href="#l221">221</a> - **Object emphasis**: &quot;Three bugs were fixed&quot; (emphasis on bugs)
231 <a id="l222" href="#l222">222</a> - **Hedging appropriate**: &quot;Mistakes were made&quot; (deliberately vague)
232 <a id="l223" href="#l223">223</a> 
233 <a id="l224" href="#l224">224</a> **Default**: Convert to active unless specific reason to keep passive.

300 <a id="l291" href="#l291">291</a> **Improvement:**
301 <a id="l292" href="#l292">292</a> - 70% fewer words
302 <a id="l293" href="#l293">293</a> - Clear action requested
303 <a id="l294" href="#l294">294</a> - Specific timeline
304 <a id="l295" href="#l295">295</a> 
305 <a id="l296" href="#l296">296</a> ## Self-Editing Techniques
306 <a id="l297" href="#l297">297</a> 
307 <a id="l298" href="#l298">298</a> ### Technique 1: The &quot;So What?&quot; Test
308 <a id="l299" href="#l299">299</a> 
309 <a id="l300" href="#l300">300</a> **Application**: After each paragraph, ask &quot;So what?&quot;
310 <a id="l301" href="#l301">301</a> 
311 <a id="l302" href="#l302">302</a> If you can&#x27;t answer clearly, the paragraph needs revision.
312 <a id="l303" href="#l303">303</a> 
313 <a id="l304" href="#l304">304</a> **Example:**
314 <a id="l305" href="#l305">305</a> &gt; &quot;The system uses a microservices architecture.&quot;
315 <a id="l306" href="#l306">306</a> 
316 <a id="l307" href="#l307">307</a> So what?
317 <a id="l308" href="#l308">308</a> 
318 <a id="l309" href="#l309">309</a> &gt; &quot;The system uses a microservices architecture, so you can update individual components without redeploying everything.&quot;
319 <a id="l310" href="#l310">310</a> 
320 <a id="l311" href="#l311">311</a> ### Technique 2: One Idea Per Sentence
321 <a id="l312" href="#l312">312</a> 
322 <a id="l313" href="#l313">313</a> **Application**: If sentence contains &quot;and,&quot; &quot;but,&quot; or &quot;however,&quot; consider splitting.
323 <a id="l314" href="#l314">314</a> 
324 <a id="l315" href="#l315">315</a> **Before:**
325 <a id="l316" href="#l316">316</a> &gt; &quot;The API is fast and reliable but requires authentication and uses rate limiting.&quot;
326 <a id="l317" href="#l317">317</a> 
327 <a id="l318" href="#l318">318</a> **After:**
328 <a id="l319" href="#l319">319</a> &gt; &quot;The API is fast and reliable. It requires authentication and uses rate limiting.&quot;
329 <a id="l320" href="#l320">320</a> 
330 <a id="l321" href="#l321">321</a> ### Technique 3: Front-Load Subject and Verb
331 <a id="l322" href="#l322">322</a> 
332 <a id="l323" href="#l323">323</a> **Application**: First 7-8 words should contain subject and main verb.
333 <a id="l324" href="#l324">324</a> 
334 <a id="l325" href="#l325">325</a> **Before:**
335 <a id="l326" href="#l326">326</a> &gt; &quot;In order to understand the implications of the proposed changes to the system architecture, developers need to review the documentation.&quot;
336 <a id="l327" href="#l327">327</a> 
337 <a id="l328" href="#l328">328</a> **After:**
338 <a id="l329" href="#l329">329</a> &gt; &quot;Developers need to review the documentation to understand the proposed changes.&quot;
339 <a id="l330" href="#l330">330</a> 
340 <a id="l331" href="#l331">331</a> ### Technique 4: The Grandmother Test
341 <a id="l332" href="#l332">332</a> 
342 <a id="l333" href="#l333">333</a> **Application**: Would a non-expert understand the main point?
343 <a id="l334" href="#l334">334</a> 
344 <a id="l335" href="#l335">335</a> If not, simplify until they would.
345 <a id="l336" href="#l336">336</a> 
346 <a id="l337" href="#l337">337</a> ### Technique 5: The Cut Test
347 <a id="l338" href="#l338">338</a> 
348 <a id="l339" href="#l339">339</a> **Application**: For each sentence, ask &quot;Can I remove this without losing meaning?&quot;
349 <a id="l340" href="#l340">340</a> 
350 <a id="l341" href="#l341">341</a> If yes, remove it.
351 <a id="l342" href="#l342">342</a> 
352 <a id="l343" href="#l343">343</a> ### Technique 6: Kill Your Darlings
353 <a id="l344" href="#l344">344</a> 
354 <a id="l345" href="#l345">345</a> **Application**: Identify your favorite phrases. Evaluate them critically.
355 <a id="l346" href="#l346">346</a> 
356 <a id="l347" href="#l347">347</a> Writers overvalue their clever phrasing (overconfidence bias). Favorite phrases often serve the writer&#x27;s ego, not the reader&#x27;s understanding.
357 <a id="l348" href="#l348">348</a> 
358 <a id="l349" href="#l349">349</a> ### Technique 7: Convert Nominalizations
359 <a id="l350" href="#l350">350</a> 
360 <a id="l351" href="#l351">351</a> **Application**: Change noun phrases back to verbs.
361 <a id="l352" href="#l352">352</a> 
362 <a id="l353" href="#l353">353</a> | Nominalization | Verb Form |
363 <a id="l354" href="#l354">354</a> |----------------|-----------|
364 <a id="l355" href="#l355">355</a> | made an investigation into | investigated |
365 <a id="l356" href="#l356">356</a> | reached a conclusion about | concluded |
366 <a id="l357" href="#l357">357</a> | gave consideration to | considered |
367 <a id="l358" href="#l358">358</a> | performed an analysis of | analyzed |
368 <a id="l359" href="#l359">359</a> | made a decision to | decided to |
369 <a id="l360" href="#l360">360</a> 
370 <a id="l361" href="#l361">361</a> ### Technique 8: The 24-Hour Rule
371 <a id="l362" href="#l362">362</a> 
372 <a id="l363" href="#l363">363</a> **Application**: Wait 24 hours between drafting and editing.
373 <a id="l364" href="#l364">364</a> 
374 <a id="l365" href="#l365">365</a> Cognitive refresh reveals:
375 <a id="l366" href="#l366">366</a> - Unclear passages you thought were clear
376 <a id="l367" href="#l367">367</a> - Redundancies you missed
377 <a id="l368" href="#l368">368</a> - Missing transitions you assumed were there
378 <a id="l369" href="#l369">369</a> 
379 <a id="l370" href="#l370">370</a> ## Common Revision Mistakes
380 <a id="l371" href="#l371">371</a> 
381 <a id="l372" href="#l372">372</a> ### Mistake 1: Editing While Drafting
382 <a id="l373" href="#l373">373</a> 
383 <a id="l374" href="#l374">374</a> **Problem**: Interrupts creative flow, wastes time on text you&#x27;ll delete
384 <a id="l375" href="#l375">375</a> **Fix**: Draft first, edit later (separate sessions)
385 <a id="l376" href="#l376">376</a> 
386 <a id="l377" href="#l377">377</a> ### Mistake 2: Starting with Grammar
387 <a id="l378" href="#l378">378</a> 
388 <a id="l379" href="#l379">379</a> **Problem**: You&#x27;ll fix sentences you later delete
389 <a id="l380" href="#l380">380</a> **Fix**: Work developmental → line → copy → proof
390 <a id="l381" href="#l381">381</a> 
391 <a id="l382" href="#l382">382</a> ### Mistake 3: Over-Reliance on Tools
392 <a id="l383" href="#l383">383</a> 
393 <a id="l384" href="#l384">384</a> **Problem**: Tools don&#x27;t understand context or meaning
394 <a id="l385" href="#l385">385</a> **Fix**: Use tools for detection, not decision-making
395 <a id="l386" href="#l386">386</a> 
396 <a id="l387" href="#l387">387</a> ### Mistake 4: Accepting All Suggestions
397 <a id="l388" href="#l388">388</a> 
398 <a id="l389" href="#l389">389</a> **Problem**: Not every &quot;issue&quot; is actually a problem
399 <a id="l390" href="#l390">390</a> **Fix**: Evaluate each suggestion against context and purpose
400 <a id="l391" href="#l391">391</a> 
401 <a id="l392" href="#l392">392</a> ### Mistake 5: Ignoring Reader Feedback
402 <a id="l393" href="#l393">393</a> 
403 <a id="l394" href="#l394">394</a> **Problem**: Authors can&#x27;t see their own blind spots
404 <a id="l395" href="#l395">395</a> **Fix**: Seek external feedback; it correlates with improvement
405 <a id="l396" href="#l396">396</a> 
406 <a id="l397" href="#l397">397</a> ### Mistake 6: Single-Pass Revision
407 <a id="l398" href="#l398">398</a> 
408 <a id="l399" href="#l399">399</a> **Problem**: Different issues require different attention
409 <a id="l400" href="#l400">400</a> **Fix**: Multiple passes, each with focused purpose
