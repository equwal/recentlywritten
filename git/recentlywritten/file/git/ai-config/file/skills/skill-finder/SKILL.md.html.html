16 <a id="l7" href="#l7">7</a> 
17 <a id="l8" href="#l8">8</a> You have access to the `skillfish` CLI, which allows you to install and manage AI agent skills from GitHub repositories. Use it whenever the user asks for a capability you don&#x27;t have, or if you need a specific tool.

19 <a id="l10" href="#l10">10</a> ## Usage
20 <a id="l11" href="#l11">11</a> 
21 <a id="l12" href="#l12">12</a> You can run `npx --yes skillfish &lt;command&gt;` via your terminal execution tools.
22 <a id="l13" href="#l13">13</a> 
23 <a id="l14" href="#l14">14</a> Commands:
24 <a id="l15" href="#l15">15</a> - `search &lt;query&gt;`: Search for skills in the registry.
25 <a id="l16" href="#l16">16</a> - `add &lt;owner/repo&gt; [skill-name]`: Install a skill from a GitHub repository. If you don&#x27;t know the specific skill name, run `npx --yes skillfish add &lt;owner/repo&gt;` to see the list of available skills in that repository.
26 <a id="l17" href="#l17">17</a> - `list`: List installed skills across all detected agents.
27 <a id="l18" href="#l18">18</a> - `remove [skill]`: Remove an installed skill.
28 <a id="l19" href="#l19">19</a> - `update`: Check for and apply updates to installed skills.
