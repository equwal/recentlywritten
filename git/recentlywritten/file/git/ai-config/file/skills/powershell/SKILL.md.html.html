29 <a id="l20" href="#l20">20</a> ## Output Behavior
30 <a id="l21" href="#l21">21</a> - Everything not captured goes to output — even without `return` or `Write-Output`
31 <a id="l22" href="#l22">22</a> - `return` doesn&#x27;t stop output — previous uncaptured expressions still output
32 <a id="l23" href="#l23">23</a> - `Write-Host` bypasses pipeline — use for display only, not data
33 <a id="l24" href="#l24">24</a> - Assign to `$null` to suppress — `$null = SomeFunction`
34 <a id="l25" href="#l25">25</a> - `[void]` cast also suppresses — `[void](SomeFunction)`
35 <a id="l26" href="#l26">26</a> 
36 <a id="l27" href="#l27">27</a> ## Array Gotchas
37 <a id="l28" href="#l28">28</a> - Single item result is scalar, not array — `@(Get-Item .)` forces array
38 <a id="l29" href="#l29">29</a> - Empty result is `$null`, not empty array — check with `if ($result)` carefully
39 <a id="l30" href="#l30">30</a> - Array unrolling in pipeline — `@(1,2,3) | ForEach` sends items one by one
40 <a id="l31" href="#l31">31</a> - `+=` on array creates new array — slow in loops, use `[System.Collections.ArrayList]`
41 <a id="l32" href="#l32">32</a> - `,` is array operator — `,$item` wraps single item in array
42 <a id="l33" href="#l33">33</a> 
43 <a id="l34" href="#l34">34</a> ## Comparison Operators
44 <a id="l35" href="#l35">35</a> - `-eq`, `-ne`, `-gt`, `-lt` — not `==`, `!=`, `&gt;`, `&lt;`
45 <a id="l36" href="#l36">36</a> - `-like` with wildcards, `-match` with regex — both return bool
46 <a id="l37" href="#l37">37</a> - `-contains` for array membership — `$arr -contains $item`, not `$item -in $arr` (though `-in` works too)
47 <a id="l38" href="#l38">38</a> - Case-insensitive by default — `-ceq`, `-cmatch` for case-sensitive
48 <a id="l39" href="#l39">39</a> - `$null` on left side — `$null -eq $var` prevents array comparison issues
49 <a id="l40" href="#l40">40</a> 
50 <a id="l41" href="#l41">41</a> ## String Handling
51 <a id="l42" href="#l42">42</a> - Double quotes interpolate — `&quot;Hello $name&quot;` expands variable
52 <a id="l43" href="#l43">43</a> - Single quotes literal — `&#x27;$name&#x27;` stays as literal text
53 <a id="l44" href="#l44">44</a> - Subexpression for complex — `&quot;Count: $($arr.Count)&quot;` for properties/methods
54 <a id="l45" href="#l45">45</a> - Here-strings for multiline — `@&quot; ... &quot;@` or `@&#x27; ... &#x27;@`
55 <a id="l46" href="#l46">46</a> - Backtick escapes — `` `n `` for newline, `` `t `` for tab
56 <a id="l47" href="#l47">47</a> 
57 <a id="l48" href="#l48">48</a> ## Pipeline
58 <a id="l49" href="#l49">49</a> - `$_` or `$PSItem` is current object — same thing, `$_` more common
59 <a id="l50" href="#l50">50</a> - `ForEach-Object` for pipeline — `foreach` statement doesn&#x27;t take pipeline
60 <a id="l51" href="#l51">51</a> - `-PipelineVariable` saves intermediate — `Get-Service -PV svc | Where ...`
61 <a id="l52" href="#l52">52</a> - Pipeline processes one at a time — unless function doesn&#x27;t support streaming
62 <a id="l53" href="#l53">53</a> 
63 <a id="l54" href="#l54">54</a> ## Error Handling
64 <a id="l55" href="#l55">55</a> - `$ErrorActionPreference` sets default — `Stop`, `Continue`, `SilentlyContinue`
65 <a id="l56" href="#l56">56</a> - `-ErrorAction Stop` per command — makes non-terminating errors terminating
66 <a id="l57" href="#l57">57</a> - `try/catch` only catches terminating — set `ErrorAction Stop` first
67 <a id="l58" href="#l58">58</a> - `$?` is last command success — `$LASTEXITCODE` for native commands
68 <a id="l59" href="#l59">59</a> 
69 <a id="l60" href="#l60">60</a> ## Common Mistakes
70 <a id="l61" href="#l61">61</a> - No space before `{` in `if` — `if($x){` works but `if ($x) {` preferred
71 <a id="l62" href="#l62">62</a> - `=` is assignment in conditions — use `-eq` for comparison
72 <a id="l63" href="#l63">63</a> - Function return array unrolls — `return ,@($arr)` to keep array
73 <a id="l64" href="#l64">64</a> - `Get-Content` returns lines array — `-Raw` for single string
74 <a id="l65" href="#l65">65</a> - `Select-Object` creates new object — properties are copies, not references
75 <a id="l66" href="#l66">66</a> 
76 <a id="l67" href="#l67">67</a> ## Claude Code PowerShell tool: delete guard
77 <a id="l68" href="#l68">68</a> - The tool scans the command text. It blocks the call when the text has a delete word (`rm`, `rmdir`, `Remove-Item`) and a token that looks like a top-level path (`/`, `/home`, `/1KB`). The error is `Remove-Item on system path &#x27;&lt;token&gt;&#x27; is blocked`.
78 <a id="l69" href="#l69">69</a> - The guard also reads inside a single-quoted `ssh` string, and it reads a division such as `$sum/1KB` as a path.
79 <a id="l70" href="#l70">70</a> - Put each delete in its own call, with the full exact path. Keep `cd /`, `df -h /home`, and `/` arithmetic out of that call.
80 <a id="l71" href="#l71">71</a> 
81 <a id="l72" href="#l72">72</a> ## Cross-Platform
82 <a id="l73" href="#l73">73</a> - `pwsh` is PowerShell 7+ — `powershell` is Windows PowerShell 5.1
83 <a id="l74" href="#l74">74</a> - Paths use `/` or `\` — `Join-Path` for portable
84 <a id="l75" href="#l75">75</a> - Environment vars: `$env:VAR` — works on all platforms
85 <a id="l76" href="#l76">76</a> - Aliases differ across platforms — `ls`, `cat` may not exist, use full cmdlet names</pre>
