10 <p>rules/windows-powershell.md (2236 bytes)</p><pre class="src"><a id="l1" href="#l1">1</a> ## MANDATORY on the Windows PC: PowerShell 7.6 syntax
11 <a id="l2" href="#l2">2</a> 
12 <a id="l3" href="#l3">3</a> This section applies on the Windows PC only, not on the Linux desktop `g`.
13 <a id="l4" href="#l4">4</a> 
14 <a id="l5" href="#l5">5</a> The PC has PowerShell 7.6 (`pwsh.exe`). The Claude Code agent shell runs it. Checked 2026-10-03. The desktop Terminal panel can run Windows PowerShell 5.1 (seen 2026-10-04), so a command for the user must work in both. `powershell.exe` is the old Windows PowerShell 5.1. Most broken commands on this PC came from mixing the two.
15 <a id="l6" href="#l6">6</a> 
16 <a id="l7" href="#l7">7</a> - Check your own shell once per session: `$PSVersionTable.PSVersion`. On 7.x, `&amp;&amp;`, `||`, `?:`, `??` and `?.` work. On 5.x they fail with &quot;The token &#x27;&amp;&amp;&#x27; is not a valid statement separator&quot;. Then use `A; if ($?) { B }`.
17 <a id="l8" href="#l8">8</a> - Never wrap a command in `powershell -Command &quot;...&quot;`. That starts 5.1, and your shell expands each `$` inside the double quotes first. For a child shell, write a `.ps1` file and run `pwsh -NoProfile -File &lt;file&gt;.ps1`.
18 <a id="l9" href="#l9">9</a> - Put a command longer than about 3 lines, or one with nested quotes, in a `.ps1` file. Do not build one long line of escaped quotes.
19 <a id="l10" href="#l10">10</a> - Unix commands do not exist: `head`, `tail`, `wc`, `sed`, `awk`, `grep`, `readlink`, `base64`, `printf`, `which`, `touch`, `rsync`, `wsl`. A Unix flag on a PowerShell alias (`ls -la`, `rm -rf`, `mkdir -p`) fails with &quot;A positional parameter cannot be found&quot;. Use `Select-Object -First N`, `Get-ChildItem -Force`, `Remove-Item -LiteralPath &lt;p&gt; -Recurse -Force`, `New-Item -ItemType Directory -Force &lt;p&gt;`, `(Get-Content f).Count`, `(Get-Command x).Source`, `$env:X = &#x27;1&#x27;`.
20 <a id="l11" href="#l11">11</a> - These native programs exist: `ssh`, `scp`, `tar`, `git`, `gh`, `curl.exe`, `py -3`, `node`, `go`.
21 <a id="l12" href="#l12">12</a> - Single quotes are literal. Double quotes expand `$var` on the PC. Put a remote `ssh` command in single quotes, and write a literal `&#x27;` inside it as `&#x27;&#x27;`.
22 <a id="l13" href="#l13">13</a> - A pipe into a native program adds CRLF: `&#x27;a&#x27; | prog` sends `a\r\n`. A Linux host then gets a stray `\r`. Copy files with `scp -O` instead of piping text into `ssh`. Hosts without an SFTP server, such as `g`, need `scp -O`.
23 <a id="l14" href="#l14">14</a> - Do not use `2&gt;&amp;1` on a native program. Check `$LASTEXITCODE`.
24 <a id="l15" href="#l15">15</a> - The UI language is Russian (`ru-RU`), so many errors are in Russian. &quot;Не удается найти путь&quot; means the path was not found. Check exit codes, not English error text.</pre>
