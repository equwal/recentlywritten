11 <a id="l2" href="#l2">2</a> 
12 <a id="l3" href="#l3">3</a> Give each new project the Contextual Copyleft AI (CCAI) License v1.0 as its `LICENSE` file from the first commit. This includes private repos, so they are licensed when they become public.
13 <a id="l4" href="#l4">4</a> 
14 <a id="l5" href="#l5">5</a> - Copy the text byte-for-byte from `CCAI-1.0.txt` in the `ccai-license` skill folder. Never retype it.
15 <a id="l6" href="#l6">6</a> - Replace `[year]` with the current year and `[author]` with the repo&#x27;s `git config user.name`.
16 <a id="l7" href="#l7">7</a> - If a manifest has a license field, point it at the file: npm `&quot;SEE LICENSE IN LICENSE&quot;`, Cargo `license-file = &quot;LICENSE&quot;`, pyproject `license = {file = &quot;LICENSE&quot;}`, other formats `LicenseRef-CCAI-1.0`.
17 <a id="l8" href="#l8">8</a> - Exception: a fork, a patch for an upstream project, and client or employer work keep the license of their owner.</pre>
