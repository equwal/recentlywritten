37 <span class="a">+## MANDATORY: Clean up files AND processes before you finish</span>
38 <span class="a">+</span>
39 <span class="a">+A task is not done while anything it started is still running or lying around. Leftovers from dead agents once kept 10 `grep -r` processes and 2 emulators busy for hours, and made the desktop slow.</span>
40 <span class="a">+</span>
41 <span class="a">+- **Processes.** Stop every process, job, and service that you started: background commands, `nohup`/`&amp;` jobs, emulators (qemu), dev servers, watchers, tunnels, `sleep` loops, long `find`/`grep -r` runs, and containers. Do this on every host you touched, also over ssh. Kill by PID that you recorded, or by an exact command-line match, never by a broad pattern that can hit the user&#x27;s own programs.</span>
42 <span class="a">+- **Files.** Delete the scratch files, temp scripts, logs, and test output that you created, on every host (`/tmp`, scratch folders, copied scripts).</span>
43 <span class="a">+- **Before you report.** Run `ps` on each host you used and confirm that none of your processes remain. Say in the report what you stopped and deleted.</span>
44 <span class="a">+- **Keep.** Deliverables, backups of files you edited, and anything the user asked to keep. If you must leave something running on purpose (a service, a long build), name it, its PID, and how to stop it.</span>
45 <span class="a">+- **Unsure?** If you did not start it, do not kill it. Ask.</span></pre>
