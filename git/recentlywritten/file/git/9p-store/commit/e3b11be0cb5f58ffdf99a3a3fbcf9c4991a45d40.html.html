78 <span class="a">+# 9p-store</span>
79 <span class="a">+</span>
80 <span class="a">+A small, disk-backed 9P file server for a private network. It uses diod</span>
81 <span class="a">+(Debian package) because plan9port has no persistent disk server: its ramfs</span>
82 <span class="a">+keeps files in RAM only. diod idles at under 1 MB of memory.</span>
83 <span class="a">+</span>
84 <span class="a">+## Server</span>
85 <span class="a">+</span>
86 <span class="a">+```sh</span>
87 <span class="a">+LISTEN_ADDR=10.0.0.1 ./install.sh</span>
88 <span class="a">+```</span>
89 <span class="a">+</span>
90 <span class="a">+The unit listens on `$LISTEN_ADDR` and on 127.0.0.1 (for SSH tunnels), with a</span>
91 <span class="a">+64 MB memory cap and restart on failure.</span>
92 <span class="a">+</span>
93 <span class="a">+### Security</span>
94 <span class="a">+</span>
95 <span class="a">+diod runs with no 9P authentication (`-n`). Access control is the network:</span>
96 <span class="a">+</span>
97 <span class="a">+- Bind only to a private address, for example a WireGuard interface.</span>
98 <span class="a">+- Drop traffic to that address unless it arrives on the private interface:</span>
99 <span class="a">+</span>
100 <span class="a">+  ```sh</span>
101 <span class="a">+  nft add rule inet filter input ip daddr 10.0.0.1 iifname != &quot;wg0&quot; drop</span>
102 <span class="a">+  ```</span>
103 <span class="a">+</span>
104 <span class="a">+- Check that nothing listens on a public address: `ss -ltnp | grep :564`.</span>
105 <span class="a">+- Never store secrets in the export.</span>
106 <span class="a">+</span>
107 <span class="a">+Hosts outside the private network can reach the loopback listener through an</span>
108 <span class="a">+SSH forward limited with `permitopen=&quot;127.0.0.1:564&quot;` in `authorized_keys`.</span>
109 <span class="a">+</span>
110 <span class="a">+## Clients</span>
111 <span class="a">+</span>
112 <span class="a">+### Linux kernel (v9fs)</span>
113 <span class="a">+</span>
114 <span class="a">+Needs `CONFIG_9P_FS` and `CONFIG_NET_9P` (`modprobe 9p`).</span>
115 <span class="a">+</span>
116 <span class="a">+```sh</span>
117 <span class="a">+mount -t 9p -o trans=tcp,port=564,aname=/srv/9pstore,version=9p2000.L,access=any 10.0.0.1 /mnt/9pstore</span>
118 <span class="a">+```</span>
119 <span class="a">+</span>
120 <span class="a">+Through an SSH tunnel:</span>
121 <span class="a">+</span>
122 <span class="a">+```sh</span>
123 <span class="a">+ssh -fN -L 127.0.0.1:5640:127.0.0.1:564 tunnel@server</span>
124 <span class="a">+mount -t 9p -o trans=tcp,port=5640,aname=/srv/9pstore,version=9p2000.L,access=any 127.0.0.1 /mnt/9pstore</span>
125 <span class="a">+```</span>
126 <span class="a">+</span>
127 <span class="a">+### plan9port</span>
128 <span class="a">+</span>
129 <span class="a">+```sh</span>
130 <span class="a">+9p -a tcp!10.0.0.1!564 -A /srv/9pstore ls /</span>
131 <span class="a">+9p -a tcp!10.0.0.1!564 -A /srv/9pstore read /file.txt</span>
132 <span class="a">+echo hi | 9p -a tcp!10.0.0.1!564 -A /srv/9pstore write /file.txt</span>
133 <span class="a">+9pfuse -A /srv/9pstore &#x27;tcp!10.0.0.1!564&#x27; /mnt/9pstore</span>
134 <span class="a">+```</span>
135 <span class="a">+</span>
136 <span class="a">+### diod tools</span>
137 <span class="a">+</span>
138 <span class="a">+```sh</span>
139 <span class="a">+diodls -s 127.0.0.1:564 -a /srv/9pstore</span>
140 <span class="a">+diodcat -s 127.0.0.1:564 -a /srv/9pstore file.txt</span>
141 <span class="a">+```</span>
142 <span class="a">+</span>
143 <span class="a">+Windows has no built-in 9P TCP client; use a Linux host or plan9port.</span>

152 <span class="a">+# Usage: LISTEN_ADDR=&lt;private-ip&gt; ./install.sh</span>
153 <span class="a">+#   LISTEN_ADDR  private address to serve on (for example a WireGuard address). Required.</span>
154 <span class="a">+#   EXPORT_DIR   directory to serve (default /srv/9pstore)</span>
155 <span class="a">+#   SQUASH_USER  account that owns every file (default 9pstore)</span>
156 <span class="a">+#   PORT         TCP port (default 564)</span>
157 <span class="a">+set -eu</span>
158 <span class="a">+: &quot;${LISTEN_ADDR:?set LISTEN_ADDR to a private address, never a public one}&quot;</span>
159 <span class="a">+EXPORT_DIR=${EXPORT_DIR:-/srv/9pstore}</span>
160 <span class="a">+SQUASH_USER=${SQUASH_USER:-9pstore}</span>
161 <span class="a">+PORT=${PORT:-564}</span>
162 <span class="a">+</span>
163 <span class="a">+DEBIAN_FRONTEND=noninteractive apt-get install -y diod</span>
164 <span class="a">+systemctl disable --now diod 2&gt;/dev/null || true   # Debian ships a sysv unit; use ours.</span>
165 <span class="a">+id &quot;$SQUASH_USER&quot; &gt;/dev/null 2&gt;&amp;1 ||</span>

168 <span class="a">+chown &quot;$SQUASH_USER&quot;: &quot;$EXPORT_DIR&quot;</span>
