27 <span class="a">+### Client behind a WireGuard sidecar container</span>
28 <span class="a">+</span>
29 <span class="a">+A host without its own WireGuard interface can run a small container that</span>
30 <span class="a">+holds the tunnel and forwards 9P to the host&#x27;s loopback. Placeholders:</span>
31 <span class="a">+`SERVER_WG_IP`, `CLIENT_WG_IP`, `SERVER_PUBKEY`, `SERVER_HOST`.</span>
32 <span class="a">+</span>
33 <span class="a">+```sh</span>
34 <span class="a">+# entrypoint.sh (alpine + wireguard-tools-wg, iproute2-minimal, socat)</span>
35 <span class="a">+ip link add wg0 type wireguard</span>
36 <span class="a">+wg set wg0 private-key /keys/privatekey peer SERVER_PUBKEY \</span>
37 <span class="a">+  endpoint SERVER_HOST:51820 allowed-ips SERVER_WG_IP/32 persistent-keepalive 25</span>
38 <span class="a">+ip addr add CLIENT_WG_IP/32 dev wg0</span>
39 <span class="a">+ip link set wg0 up</span>
40 <span class="a">+ip route add SERVER_WG_IP/32 dev wg0</span>
41 <span class="a">+exec socat TCP-LISTEN:564,fork,reuseaddr TCP:SERVER_WG_IP:564</span>
42 <span class="a">+```</span>
43 <span class="a">+</span>
44 <span class="a">+```sh</span>
45 <span class="a">+docker run -d --name wg-9p --restart unless-stopped --cap-drop ALL \</span>
46 <span class="a">+  --cap-add NET_ADMIN --memory 32m -v &quot;$PWD/privatekey:/keys/privatekey:ro&quot; \</span>
47 <span class="a">+  -p 127.0.0.1:564:564 wg-9p</span>
48 <span class="a">+mount -t 9p -o trans=tcp,port=564,aname=/srv/9pstore,version=9p2000.L 127.0.0.1 /mnt/9pstore</span>
49 <span class="a">+```</span>
50 <span class="a">+</span>
51 <span class="a">+The server needs a `[Peer]` with the container&#x27;s public key and</span>
52 <span class="a">+`AllowedIPs = CLIENT_WG_IP/32`. One sidecar can forward several services.</span></pre>
