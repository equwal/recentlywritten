13 <a id="l4" href="#l4">4</a> Register you directories in the ASDF subsystem. [[https://common-lisp.net/project/asdf/asdf.html#Configuration-DSL][ASDF has a better way to do it]], but this one works too. Also, [[https://github.com/roswell/roswell][roswell can do better]], so I have archived this repository.

15 <a id="l6" href="#l6">6</a> * Install
16 <a id="l7" href="#l7">7</a> Run the install script. If it complains, set =$CL_INIT= and =$ASDF_REPO=.
17 <a id="l8" href="#l8">8</a> #+begin_src shell
18 <a id="l9" href="#l9">9</a> git clone git@github.com:equwal/asdf-registration.git
19 <a id="l10" href="#l10">10</a> export CL_INIT=&quot;$HOME/.sbclrc&quot; # for some SBCLs only.
20 <a id="l11" href="#l11">11</a> export ASDF_REPO=&quot;$HOME/common-lisp&quot; # This is where mine is.
21 <a id="l12" href="#l12">12</a> sh asdf-registration/install.sh
22 <a id="l13" href="#l13">13</a> #+end_src
23 <a id="l14" href="#l14">14</a> * Advanced install
24 <a id="l15" href="#l15">15</a> ** More than one repository
25 <a id="l16" href="#l16">16</a>   Add =asdf-registration:add-repo= lines to your init file. The subdirectories
26 <a id="l17" href="#l17">17</a>   will be added to the ASDF registry.
27 <a id="l18" href="#l18">18</a> ** Directories not in a repository
28 <a id="l19" href="#l19">19</a>    For an ASDF project not inside of a repository directory, use
29 <a id="l20" href="#l20">20</a>    =asdf-registration:add-to-registry=.
30 <a id="l21" href="#l21">21</a> * Guts
31 <a id="l22" href="#l22">22</a>   ASDF-registration is a wrapper around the  =*central-registry*=. If you need something more complex, use the [[https://common-lisp.net/project/asdf/asdf.html#Configuration-DSL][configuration DSL]].</pre>
