33 <a id="l24" href="#l24">24</a> ## Full description (4000 max)
34 <a id="l25" href="#l25">25</a> 
35 <a id="l26" href="#l26">26</a> ```
36 <a id="l27" href="#l27">27</a> Rebind remaps your device&#x27;s hardware keys: volume keys, the power button, page-turn buttons, camera and assistant keys, and on the Viwoods AiPaper the AI key.
37 <a id="l28" href="#l28">28</a> 
38 <a id="l29" href="#l29">29</a> Turn pages with the volume keys. Hold the power button for Home, double press it for Recents. Put three different actions on one key with a tap, a double tap and a hold.
39 <a id="l30" href="#l30">30</a> 
40 <a id="l31" href="#l31">31</a> Setup is three taps: tap the button in a drawing of your device, choose tap, double tap or hold, choose what it does. Rebind asks only for what that needs.
41 <a id="l32" href="#l32">32</a> 
42 <a id="l33" href="#l33">33</a> No spare button? Add the on-screen button: a small round button that floats over every app.
43 <a id="l34" href="#l34">34</a> 
44 <a id="l35" href="#l35">35</a> Built for e-ink readers, and it works on any Android 12+ phone or tablet.
45 <a id="l36" href="#l36">36</a> 
46 <a id="l37" href="#l37">37</a> WHAT EACH KEY CAN DO
47 <a id="l38" href="#l38">38</a> 
48 <a id="l39" href="#l39">39</a> AI key and volume keys
49 <a id="l40" href="#l40">40</a> • 1 to 5 taps, each bound separately
50 <a id="l41" href="#l41">41</a> • Press and hold
51 <a id="l42" href="#l42">42</a> • Combinations: hold one key and press another
52 <a id="l43" href="#l43">43</a> • A key with only a single-tap binding fires instantly - you only wait out a double-tap window on keys where you asked for a double tap
53 <a id="l44" href="#l44">44</a> 
54 <a id="l45" href="#l45">45</a> Power button
55 <a id="l46" href="#l46">46</a> • Hold Power, then press another key: three extra combinations
56 <a id="l47" href="#l47">47</a> • Press and hold: run any action (Rebind becomes your digital assistant app)
57 <a id="l48" href="#l48">48</a> • Double press: run any action (Rebind becomes your default camera app)
58 <a id="l49" href="#l49">49</a> • Short press: choose the firmware behaviour
59 <a id="l50" href="#l50">50</a> 
60 <a id="l51" href="#l51">51</a> ACTIONS
61 <a id="l52" href="#l52">52</a> 
62 <a id="l53" href="#l53">53</a> • Viwoods AI: crop, lookup, quick prompt, full assistant, history, repository, edit screenshot
63 <a id="l54" href="#l54">54</a> • Navigation: Back, Home, Recents, notifications, quick settings, power menu, lock screen, screenshot
64 <a id="l55" href="#l55">55</a> • Page turning: swipes and scrolls, for reading apps that only accept touch
65 <a id="l56" href="#l56">56</a> • Sound and media: volume up, down, mute, play/pause, next, previous
66 <a id="l57" href="#l57">57</a> • Open any app, or any screen inside an app
67 <a id="l58" href="#l58">58</a> • Send an intent or a broadcast, for automation apps
68 <a id="l59" href="#l59">59</a> • A menu of actions: one gesture opens a menu with as many actions as you want, so you have more actions than keys
69 <a id="l60" href="#l60">60</a> • Ready-made menus for navigation, system, sound and media, and page turning
70 <a id="l61" href="#l61">61</a> • Do nothing - disable a key you keep pressing by accident
71 <a id="l62" href="#l62">62</a> • Export and import your setup as a file, to move it to another device or share it
72 <a id="l63" href="#l63">63</a> 
73 <a id="l64" href="#l64">64</a> VOICE TYPING
74 <a id="l65" href="#l65">65</a> Bind a key to Voice typing: press, speak, and the words appear where the cursor is - in any app, with the keyboard you already have. Rebind has no speech engine and no internet access; a speech recognition app on your device does the listening.
75 <a id="l66" href="#l66">66</a> 
76 <a id="l67" href="#l67">67</a> MORE FOR E-INK
77 <a id="l68" href="#l68">68</a> • Opens Ink Recents, our free recent-apps app for e-ink, from any button
78 <a id="l69" href="#l69">69</a> 
79 <a id="l70" href="#l70">70</a> BUILT FOR E-INK
80 <a id="l71" href="#l71">71</a> 
81 <a id="l72" href="#l72">72</a> Black on white, large text, no animation. No ads. No account.
82 <a id="l73" href="#l73">73</a> 
83 <a id="l74" href="#l74">74</a> PRIVATE BY CONSTRUCTION
84 <a id="l75" href="#l75">75</a> 
85 <a id="l76" href="#l76">76</a> Rebind has no internet permission. It cannot send anything anywhere, and you can verify that on the app&#x27;s permissions page. It collects nothing and stores nothing except your own key bindings, on your device.
86 <a id="l77" href="#l77">77</a> 
87 <a id="l78" href="#l78">78</a> ACCESSIBILITY SERVICE
88 <a id="l79" href="#l79">79</a> 
89 <a id="l80" href="#l80">80</a> Rebind uses Android&#x27;s AccessibilityService API, and only to remap hardware keys. The service receives key presses so it can recognise taps, holds and combinations, and performs the action you chose - Back, Home, a swipe - on your behalf. It looks at the window in front only to find a scrollable area when you use the Scroll action. It does not record what you type or what is on your screen. The app explains this and asks for your agreement before sending you to the accessibility switch.
90 <a id="l81" href="#l81">81</a> 
91 <a id="l82" href="#l82">82</a> GOOD TO KNOW
92 <a id="l83" href="#l83">83</a> 
93 <a id="l84" href="#l84">84</a> • Made for the Viwoods AiPaper Reader. The volume and power features work on most Android 12+ devices; the AI key and Viwoods actions are specific to Viwoods hardware.
94 <a id="l85" href="#l85">85</a> • Android does not let any app see the power button directly, so power gestures are limited to short press, double press and hold.
95 <a id="l86" href="#l86">86</a> • Hiding the navigation bar, switching system gestures off, and giving Rebind sole control of the AI key are one-time steps done from a computer over USB. Android does not allow any app to change them. The app shows the exact commands.
96 <a id="l87" href="#l87">87</a> • If a volume key does not respond, the device&#x27;s own key settings may be holding on to it. The built-in key tester shows exactly which keys Rebind can see, and the Firmware key hooks screen shows the fix.
97 <a id="l88" href="#l88">88</a> 
98 <a id="l89" href="#l89">89</a> COMPATIBILITY
99 <a id="l90" href="#l90">90</a> Works on Android 12 and later. Built and tested on the Viwoods AiPaper Reader; key remapping, page turning, and voice typing work on Boox, Bigme, Meebook and ordinary phones and tablets too. Search terms people use for this: button mapper, key remapper, remap buttons, volume key page turn, double tap, long press, key combination.
