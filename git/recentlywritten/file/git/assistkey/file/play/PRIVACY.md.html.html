11 <a id="l2" href="#l2">2</a> 
12 <a id="l3" href="#l3">3</a> *Effective 21 September 2026*
13 <a id="l4" href="#l4">4</a> 
14 <a id="l5" href="#l5">5</a> Rebind is published by equwal. Contact: truex@equwal.com
15 <a id="l6" href="#l6">6</a> 
16 <a id="l7" href="#l7">7</a> ## The short version
17 <a id="l8" href="#l8">8</a> 
18 <a id="l9" href="#l9">9</a> Rebind collects nothing, stores nothing about you, and sends nothing
19 <a id="l10" href="#l10">10</a> anywhere. It does not hold Android&#x27;s internet permission, so it is not able to.
20 <a id="l11" href="#l11">11</a> 
21 <a id="l12" href="#l12">12</a> ## What the app handles
22 <a id="l13" href="#l13">13</a> 
23 <a id="l14" href="#l14">14</a> **Hardware key presses.** With its accessibility service switched on, Rebind
24 <a id="l15" href="#l15">15</a> is told when the AI key or a volume key is pressed or released. It uses this
25 <a id="l16" href="#l16">16</a> only to recognise the taps, holds and combinations you have set up and to run
26 <a id="l17" href="#l17">17</a> the action you chose. Key presses are handled in memory as they arrive and are
27 <a id="l18" href="#l18">18</a> not recorded. The built-in key tester lists recent presses on screen while that
28 <a id="l19" href="#l19">19</a> screen is open; the list is never saved and is discarded when you leave it.
29 <a id="l20" href="#l20">20</a> 
30 <a id="l21" href="#l21">21</a> **The window in front.** When you use the Scroll action, and only then, the
31 <a id="l22" href="#l22">22</a> service asks Android which part of the current window can scroll, so that it
32 <a id="l23" href="#l23">23</a> can scroll it. It does not read, record or transmit what the window contains.
33 <a id="l24" href="#l24">24</a> 
34 <a id="l25" href="#l25">25</a> **Your settings.** Your key bindings, timing preferences and which capture
35 <a id="l26" href="#l26">26</a> channels are on are saved in the app&#x27;s private storage on your device. Rebind
36 <a id="l27" href="#l27">27</a> also keeps a copy of them as a file in your Documents folder
37 <a id="l28" href="#l28">28</a> (`Documents/Rebind/rebind-settings.json`), so that an uninstall does not lose
38 <a id="l29" href="#l29">29</a> them. The file stays on your device. Your settings leave the device only
39 <a id="l30" href="#l30">30</a> through Android&#x27;s own backup, if you have it on, or if you share the file.
40 <a id="l31" href="#l31">31</a> 
41 <a id="l32" href="#l32">32</a> **Voice typing.** If you bind the Voice typing action, Rebind asks for the
42 <a id="l33" href="#l33">33</a> microphone permission. A speech recognition app on your device, which you
43 <a id="l34" href="#l34">34</a> choose, does the listening; how it handles audio is covered by that app&#x27;s own
44 <a id="l35" href="#l35">35</a> policy. Rebind receives only the recognised text, and puts it into the text
45 <a id="l36" href="#l36">36</a> field that has the cursor. To do that it reads the current text of that one
46 <a id="l37" href="#l37">37</a> field at that moment. It keeps and sends none of it, and never writes into
47 <a id="l38" href="#l38">38</a> password fields.
48 <a id="l39" href="#l39">39</a> 
49 <a id="l40" href="#l40">40</a> **Recent apps.** Rebind has no recent-apps list of its own. The Recent apps action opens Ink Recents, a separate app with a privacy policy of its own.
50 <a id="l41" href="#l41">41</a> 
51 <a id="l42" href="#l42">42</a> **Apps of other makers.** The build for direct install carries the release files of other apps (inkOS, ThinkLauncher, Ink Recents, Whisper) and can hand them to the installer of Android, which asks you first. Rebind downloads nothing. Each of those apps has its own policy. The Google Play build carries none of them.
52 <a id="l43" href="#l43">43</a> 
53 <a id="l44" href="#l44">44</a> **The on-screen button.** If you give the on-screen button an action, the accessibility service draws a small round button over other apps. It reads nothing from the screen. It remembers only where you put it.
54 <a id="l45" href="#l45">45</a> 
55 <a id="l46" href="#l46">46</a> **Device detection.** At first start the app asks Android which buttons the device has and what the device can do, and saves the answer on your device. It never asks you to press a button for this.
56 <a id="l47" href="#l47">47</a> 
57 <a id="l48" href="#l48">48</a> **Shell access.** Not in the Google Play build. In the build for direct
58 <a id="l49" href="#l49">49</a> install, if you connect Rebind to Shizuku, it runs commands on your
59 <a id="l50" href="#l50">50</a> device as the shell user to read the Power button, switch the navigation bar
60 <a id="l51" href="#l51">51</a> and gestures, and set the light. These act on your device only.
61 <a id="l52" href="#l52">52</a> 
62 <a id="l53" href="#l53">53</a> **Device report.** The report you can create under Advanced lists your device
63 <a id="l54" href="#l54">54</a> model, firmware, input devices, navigation options and a short list of key and
64 <a id="l55" href="#l55">55</a> navigation settings. It does not include your apps, accounts or identifiers.
65 <a id="l56" href="#l56">56</a> It is shown to you in full and goes nowhere unless you send it yourself.
66 <a id="l57" href="#l57">57</a> 
67 <a id="l58" href="#l58">58</a> **Licence state.** The app saves, on your device, the date it was first
68 <a id="l59" href="#l59">59</a> opened, whether it was used during the beta, and which Rebind products
69 <a id="l60" href="#l60">60</a> Google Play reports your account as owning.
70 <a id="l61" href="#l61">61</a> 
71 <a id="l62" href="#l62">62</a> ## The accessibility service
72 <a id="l63" href="#l63">63</a> 
73 <a id="l64" href="#l64">64</a> Rebind uses Android&#x27;s AccessibilityService API for one purpose: remapping
74 <a id="l65" href="#l65">65</a> hardware keys, and carrying out navigation actions such as Back, Home and
75 <a id="l66" href="#l66">66</a> Recents on your behalf. It is not used to collect information, and the app asks
76 <a id="l67" href="#l67">67</a> for your agreement, in the app, before directing you to switch the service on.
77 <a id="l68" href="#l68">68</a> You can switch it off at any time in Android&#x27;s accessibility settings.
78 <a id="l69" href="#l69">69</a> 
79 <a id="l70" href="#l70">70</a> ## Purchases
80 <a id="l71" href="#l71">71</a> 
81 <a id="l72" href="#l72">72</a> Purchases are made through Google Play. Rebind never sees your payment
82 <a id="l73" href="#l73">73</a> details. It learns from Google Play only whether your account owns a licence.
83 <a id="l74" href="#l74">74</a> Google&#x27;s handling of the purchase is covered by Google&#x27;s own privacy policy:
84 <a id="l75" href="#l75">75</a> &lt;https://policies.google.com/privacy&gt;.
85 <a id="l76" href="#l76">76</a> 
86 <a id="l77" href="#l77">77</a> Rebind includes Google&#x27;s Play Billing Library in order to do this. The part
87 <a id="l78" href="#l78">78</a> of that library which reports usage statistics to Google has been removed from
88 <a id="l79" href="#l79">79</a> Rebind, and the app has no network access with which it could do so.
89 <a id="l80" href="#l80">80</a> 
90 <a id="l81" href="#l81">81</a> ## What is not in the app
91 <a id="l82" href="#l82">82</a> 
92 <a id="l83" href="#l83">83</a> No advertising. No analytics. No crash reporting. No accounts. No third-party
93 <a id="l84" href="#l84">84</a> SDKs other than Google&#x27;s Play Billing Library.
94 <a id="l85" href="#l85">85</a> 
95 <a id="l86" href="#l86">86</a> ## Children
96 <a id="l87" href="#l87">87</a> 
97 <a id="l88" href="#l88">88</a> Rebind is a utility for a general audience and is not directed at children.
98 <a id="l89" href="#l89">89</a> It collects no personal information from anyone.
99 <a id="l90" href="#l90">90</a> 
100 <a id="l91" href="#l91">91</a> ## Changes
101 <a id="l92" href="#l92">92</a> 
102 <a id="l93" href="#l93">93</a> If this policy changes, the new version will be published at the same address
103 <a id="l94" href="#l94">94</a> with a new effective date.</pre>
