10 <p>play/CHECKLIST.md (7277 bytes)</p><pre class="src"><a id="l1" href="#l1">1</a> # Publishing AssistKey on Google Play
11 <a id="l2" href="#l2">2</a> 
12 <a id="l3" href="#l3">3</a> Everything that can be prepared without your Google account is already in this
13 <a id="l4" href="#l4">4</a> repository. What is left needs your login, your card, or your identity, in this
14 <a id="l5" href="#l5">5</a> order.
15 <a id="l6" href="#l6">6</a> 
16 <a id="l7" href="#l7">7</a> ## 1. Open the developer account (you, once)
17 <a id="l8" href="#l8">8</a> 
18 <a id="l9" href="#l9">9</a> 1. Go to &lt;https://play.google.com/console/signup&gt; with the Google account that
19 <a id="l10" href="#l10">10</a>    should own the app.
20 <a id="l11" href="#l11">11</a> 2. Choose **Personal** unless you have a registered business.
21 <a id="l12" href="#l12">12</a> 3. Pay the registration fee: **US$25, one time**. (Not $5.)
22 <a id="l13" href="#l13">13</a> 4. Complete identity verification. Google asks for a government ID and a phone
23 <a id="l14" href="#l14">14</a>    number, and the name must match the payment card. Approval takes from a few
24 <a id="l15" href="#l15">15</a>    hours to a few days.
25 <a id="l16" href="#l16">16</a> 5. To be paid, set up a **payments profile** (Play Console &gt; Setup &gt; Payments
26 <a id="l17" href="#l17">17</a>    profile) with a bank account and tax information. You cannot create a priced
27 <a id="l18" href="#l18">18</a>    product until this exists.
28 <a id="l19" href="#l19">19</a> 
29 <a id="l20" href="#l20">20</a> A personal account created after November 2023 must run a **closed test with at
30 <a id="l21" href="#l21">21</a> least 12 testers opted in for 14 continuous days** before Google will let the
31 <a id="l22" href="#l22">22</a> app go to production. That is your beta; plan for it.
32 <a id="l23" href="#l23">23</a> 
33 <a id="l24" href="#l24">24</a> ## 2. Create the app
34 <a id="l25" href="#l25">25</a> 
35 <a id="l26" href="#l26">26</a> Play Console &gt; **Create app**
36 <a id="l27" href="#l27">27</a> 
37 <a id="l28" href="#l28">28</a> | Field | Value |
38 <a id="l29" href="#l29">29</a> |---|---|
39 <a id="l30" href="#l30">30</a> | App name | `AssistKey: E-Ink Key Remap` |
40 <a id="l31" href="#l31">31</a> | Default language | English (United States) |
41 <a id="l32" href="#l32">32</a> | App or game | App |
42 <a id="l33" href="#l33">33</a> | Free or paid | **Free** (the licence is an in-app product; a paid app could not give testers a discount) |
43 <a id="l34" href="#l34">34</a> 
44 <a id="l35" href="#l35">35</a> The package name is fixed by the first upload: `dev.equwal.assistkey`.
45 <a id="l36" href="#l36">36</a> 
46 <a id="l37" href="#l37">37</a> ## 3. App signing - do this before the first upload
47 <a id="l38" href="#l38">38</a> 
48 <a id="l39" href="#l39">39</a> Play re-signs every app. If it signs with a key of its own, the APK you hand to
49 <a id="l40" href="#l40">40</a> testers and the copy Play delivers will carry different signatures. Then Play
50 <a id="l41" href="#l41">41</a> cannot upgrade a sideloaded install in place, and purchases made from a
51 <a id="l42" href="#l42">42</a> sideloaded install fail.
52 <a id="l43" href="#l43">43</a> 
53 <a id="l44" href="#l44">44</a> So give Play **the key this repo already signs with**:
54 <a id="l45" href="#l45">45</a> 
55 <a id="l46" href="#l46">46</a> Play Console &gt; Test and release &gt; Setup &gt; **App signing** &gt; *Use a different
56 <a id="l47" href="#l47">47</a> key* &gt; *Export and upload a key from Java keystore*. Download the
57 <a id="l48" href="#l48">48</a> `encryption_public_key.pem` it offers and the PEPK tool, then:
58 <a id="l49" href="#l49">49</a> 
59 <a id="l50" href="#l50">50</a> ```bash
60 <a id="l51" href="#l51">51</a> java -jar pepk.jar --keystore=assistkey-release.jks --alias=assistkey \
61 <a id="l52" href="#l52">52</a>   --output=assistkey-play-signing.zip --include-cert \
62 <a id="l53" href="#l53">53</a>   --rsa-aes-encryption --encryption-key-path=encryption_public_key.pem
63 <a id="l54" href="#l54">54</a> ```
64 <a id="l55" href="#l55">55</a> 
65 <a id="l56" href="#l56">56</a> It asks for the keystore password, which is in `keystore.properties`. Upload the
66 <a id="l57" href="#l57">57</a> zip. Expected certificate SHA-256:
67 <a id="l58" href="#l58">58</a> 
68 <a id="l59" href="#l59">59</a> ```
69 <a id="l60" href="#l60">60</a> bcb3127e1931a9b906e8e2498184ef5380f97cbf3531e5bc8bb0064476ee2919
70 <a id="l61" href="#l61">61</a> ```
71 <a id="l62" href="#l62">62</a> 
72 <a id="l63" href="#l63">63</a> **Back up `assistkey-release.jks` and `keystore.properties` somewhere safe.**
73 <a id="l64" href="#l64">64</a> Neither is in git. Without them you cannot ship another update.
74 <a id="l65" href="#l65">65</a> 
75 <a id="l66" href="#l66">66</a> ## 4. Upload the build
76 <a id="l67" href="#l67">67</a> 
77 <a id="l68" href="#l68">68</a> Test and release &gt; Testing &gt; **Internal testing** &gt; Create new release &gt; upload
78 <a id="l69" href="#l69">69</a> `AssistKey-&lt;version&gt;-play.aab` (attached to the GitHub release, or rebuild with
79 <a id="l70" href="#l70">70</a> `./gradlew bundlePlayRelease`). Upload the `play` build only. It has no Shizuku
80 <a id="l71" href="#l71">71</a> code and no Shizuku permission. The `full` APK is for direct install.
81 <a id="l72" href="#l72">72</a> 
82 <a id="l73" href="#l73">73</a> Internal testing needs no review and is live in minutes. Products cannot be
83 <a id="l74" href="#l74">74</a> created until one build has been uploaded.
84 <a id="l75" href="#l75">75</a> 
85 <a id="l76" href="#l76">76</a> ## 5. Create the three products
86 <a id="l77" href="#l77">77</a> 
87 <a id="l78" href="#l78">78</a> Monetize with Play &gt; Products &gt; **One-time products**. The ids can never be
88 <a id="l79" href="#l79">79</a> changed or reused, and the app looks for exactly these:
89 <a id="l80" href="#l80">80</a> 
90 <a id="l81" href="#l81">81</a> | Product id | Name | Price | State |
91 <a id="l82" href="#l82">82</a> |---|---|---|---|
92 <a id="l83" href="#l83">83</a> | `assistkey_pro` | AssistKey licence | **US$2.99** | Active |
93 <a id="l84" href="#l84">84</a> | `assistkey_pro_tester` | AssistKey licence - beta tester price | **US$1.49** | Active |
94 <a id="l85" href="#l85">85</a> | `assistkey_beta_open` | Beta access flag (not for sale) | US$0.99 | **Active while the beta runs** |
95 <a id="l86" href="#l86">86</a> 
96 <a id="l87" href="#l87">87</a> All three: purchase type **Buy**, non-consumable. Let Play convert the prices
97 <a id="l88" href="#l88">88</a> to other currencies.
98 <a id="l89" href="#l89">89</a> 
99 <a id="l90" href="#l90">90</a> `assistkey_beta_open` is never offered by the app. It is only a switch - see
100 <a id="l91" href="#l91">91</a> section 9.
101 <a id="l92" href="#l92">92</a> 
102 <a id="l93" href="#l93">93</a> Price review, 2026-09-21: the market check advises **US$4.99**, not US$2.99.
103 <a id="l94" href="#l94">94</a> Reason: US$2.99 is the exact price of Button Mapper Pro, which has 5M+ installs,
104 <a id="l95" href="#l95">95</a> so a price match cannot win; the e-ink features have no paid competitor. At
105 <a id="l96" href="#l96">96</a> US$4.99 the margin is US$4.24 per sale, and US$1,000 a month needs 236 sales
106 <a id="l97" href="#l97">97</a> and not 394. The owner has not decided. A price is a Console edit, not a release.
107 <a id="l98" href="#l98">98</a> 
108 <a id="l99" href="#l99">99</a> Pricing: Button Mapper Pro, the nearest comparable app, is US$2.99. AssistKey
109 <a id="l100" href="#l100">100</a> serves a far smaller audience but does more on the hardware it targets, so it
110 <a id="l101" href="#l101">101</a> matches that price rather than undercutting it. Prices are read from Play at
111 <a id="l102" href="#l102">102</a> run time; changing one is a Console edit, not a release.
112 <a id="l103" href="#l103">103</a>

129 <a id="l120" href="#l120">120</a> ## 8. Test the purchase before anyone else does
130 <a id="l121" href="#l121">121</a> 
131 <a id="l122" href="#l122">122</a> Billing could not be tested before the app existed on Play. Do this first:
132 <a id="l123" href="#l123">123</a> 
133 <a id="l124" href="#l124">124</a> 1. Play Console &gt; Setup &gt; **License testing**: add your own Gmail address.
134 <a id="l125" href="#l125">125</a>    License testers buy with a test card and are never charged.
135 <a id="l126" href="#l126">126</a> 2. Internal testing &gt; Testers: add the same address, open the opt-in link on
136 <a id="l127" href="#l127">127</a>    the reader, install from Play.
137 <a id="l128" href="#l128">128</a> 3. On the reader, Google Play must be switched on - the Viwoods firmware ships
138 <a id="l129" href="#l129">129</a>    with it disabled.
139 <a id="l130" href="#l130">130</a> 4. Open AssistKey &gt; the licence row. Prices should appear within a second or
140 <a id="l131" href="#l131">131</a>    two. Buy with the test card and confirm it shows **Unlocked**.
141 <a id="l132" href="#l132">132</a> 5. Refund it from Order management to test again.
142 <a id="l133" href="#l133">133</a> 
143 <a id="l134" href="#l134">134</a> If the prices never appear, the usual causes are: products not Active, the
144 <a id="l135" href="#l135">135</a> account not on the tester list, or the signatures not matching (section 3).
145 <a id="l136" href="#l136">136</a> 
146 <a id="l137" href="#l137">137</a> ## 9. Running the beta, and ending it
147 <a id="l138" href="#l138">138</a> 
148 <a id="l139" href="#l139">139</a> **During the beta** hand testers either the Play opt-in link or
149 <a id="l140" href="#l140">140</a> the `play` APK from the GitHub release. Both are the same build. While
150 <a id="l141" href="#l141">141</a> `assistkey_beta_open` is Active, every install is fully unlocked for free, and
151 <a id="l142" href="#l142">142</a> each one quietly marks itself as a tester.
152 <a id="l143" href="#l143">143</a> 
153 <a id="l144" href="#l144">144</a> **To end the beta:** set `assistkey_beta_open` to **Inactive**. Within hours,
154 <a id="l145" href="#l145">145</a> every install that can reach Play drops to a 7-day trial and then locks.
155 <a id="l146" href="#l146">146</a> Installs that cannot reach Play lock on the date compiled into the build,
156 <a id="l147" href="#l147">147</a> `2027-03-31` (`assistkey.betaExpires` in `gradle.properties`).
157 <a id="l148" href="#l148">148</a> 
158 <a id="l149" href="#l149">149</a> **The tester discount** then appears by itself: an install that ran during the
159 <a id="l150" href="#l150">150</a> beta is offered `assistkey_pro_tester` instead of `assistkey_pro`. A tester who
160 <a id="l151" href="#l151">151</a> changed device, or had to reinstall, types the tester code instead. The code is
161 <a id="l152" href="#l152">152</a> in `keystore.properties` (`testerCode`), never in git; only its hash ships.
162 <a id="l153" href="#l153">153</a> Changing it means a new release.
163 <a id="l154" href="#l154">154</a> 
164 <a id="l155" href="#l155">155</a> To stop offering the discount later, deactivate `assistkey_pro_tester`.
165 <a id="l156" href="#l156">156</a> 
166 <a id="l157" href="#l157">157</a> ## 10. Go to production
167 <a id="l158" href="#l158">158</a> 
168 <a id="l159" href="#l159">159</a> After the 14-day closed test, Play Console offers **Apply for production
169 <a id="l160" href="#l160">160</a> access**. It asks about the test; answer plainly. Then promote the build to
170 <a id="l161" href="#l161">161</a> Production and choose countries.
