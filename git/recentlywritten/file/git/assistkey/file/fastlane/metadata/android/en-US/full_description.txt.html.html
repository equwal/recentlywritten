10 <p>fastlane/metadata/android/en-US/full_description.txt (1696 bytes)</p><pre class="src"><a id="l1" href="#l1">1</a> Rebind changes what the hardware buttons of your device do: the volume buttons, the Power button, page-turn buttons, and on the Viwoods AiPaper the AI button.
11 <a id="l2" href="#l2">2</a> 
12 <a id="l3" href="#l3">3</a> Turn pages with the volume buttons. Hold Power for Home. Double press Power for Recents. Put three actions on one button: a tap, a double tap and a hold.
13 <a id="l4" href="#l4">4</a> 
14 <a id="l5" href="#l5">5</a> Setup takes three taps. Tap a button in the drawing of your device. Choose tap, double tap or hold. Choose what it does. Rebind asks only for the permissions that the choice needs.
15 <a id="l6" href="#l6">6</a> 
16 <a id="l7" href="#l7">7</a> If the device has no spare button, add the on-screen button. It floats over every app.
17 <a id="l8" href="#l8">8</a> 
18 <a id="l9" href="#l9">9</a> Rebind is made for e-ink readers. It works on any Android 12 or later phone or tablet.
19 <a id="l10" href="#l10">10</a> 
20 <a id="l11" href="#l11">11</a> Actions:
21 <a id="l12" href="#l12">12</a> - Navigation: Back, Home, Recents, notifications, quick settings, power menu, lock screen, screenshot.
22 <a id="l13" href="#l13">13</a> - Page turning: swipes and scrolls, for reading apps that accept only touch.
23 <a id="l14" href="#l14">14</a> - Sound and media: volume, mute, play and pause, next, previous.
24 <a id="l15" href="#l15">15</a> - Open any app, or any screen inside an app.
25 <a id="l16" href="#l16">16</a> - Send an intent or a broadcast, for automation apps.
26 <a id="l17" href="#l17">17</a> - A menu of actions: one gesture opens a menu, so you have more actions than buttons.
27 <a id="l18" href="#l18">18</a> - Voice typing with a speech recognition app that is on the device.
28 <a id="l19" href="#l19">19</a> 
29 <a id="l20" href="#l20">20</a> Shizuku is optional. It lets Rebind read the Power button for taps and switch the navigation bar. Hold Power and double press Power do not need it.
30 <a id="l21" href="#l21">21</a> 
31 <a id="l22" href="#l22">22</a> Rebind has no INTERNET permission. It collects nothing and has no advertisements. The Accessibility service reads button presses only to run the actions that you chose. It never sends them anywhere.
32 <a id="l23" href="#l23">23</a> 
33 <a id="l24" href="#l24">24</a> Rebind is free and open source (GPL-3.0-or-later). This F-Droid build has no licence check and no paid part. To thank the author, open the Licence screen in the app.</pre>
