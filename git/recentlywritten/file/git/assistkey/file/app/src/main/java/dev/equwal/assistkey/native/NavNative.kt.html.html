18 <a id="l9" href="#l9">9</a>  * How the reader is navigated, as far as the system is concerned: whether the

23 <a id="l14" href="#l14">14</a>  *
24 <a id="l15" href="#l15">15</a>  *  - The bar is Android&#x27;s navigation-mode overlay. `threebutton` shows it;

27 <a id="l18" href="#l18">18</a>  *  - The swipe up from the bottom edge to Home is Viwoods&#x27; own, present in both

29 <a id="l20" href="#l20">20</a>  *    is an OEM key outside SettingsProvider&#x27;s public list, so no ordinary app
