22 <a id="l13" href="#l13">13</a> ## 0.1.0-beta - 2026-09-21
23 <a id="l14" href="#l14">14</a> 
24 <a id="l15" href="#l15">15</a> Version code 16. The first beta. The alpha versions end here.
25 <a id="l16" href="#l16">16</a> 
26 <a id="l17" href="#l17">17</a> - **Updates: Ink Update.** Rebind has no internet permission, so it cannot
27 <a id="l18" href="#l18">18</a>   look for a new version. Ink Update, an open source app of its own, does
28 <a id="l19" href="#l19">19</a>   that: F-Droid first, then Google Play (it leaves an app that Google Play
29 <a id="l20" href="#l20">20</a>   installed to Google Play), then GitHub. It makes a notification and opens
30 <a id="l21" href="#l21">21</a>   the page. Setup has an &quot;Updates&quot; row that installs or opens it. The build
31 <a id="l22" href="#l22">22</a>   for direct install carries it.
32 <a id="l23" href="#l23">23</a> - The build for direct install carries Ink Dim too. Hardware hacks lists it.
33 <a id="l24" href="#l24">24</a> - The lists of carried apps are named &quot;Extensions&quot;.
34 <a id="l25" href="#l25">25</a> 
35 <a id="l26" href="#l26">26</a> - **Settings are safe across versions and across an uninstall.** An update
36 <a id="l27" href="#l27">27</a>   always kept the settings: they are in the data of the app. An uninstall
37 <a id="l28" href="#l28">28</a>   removed them. Now Android asks at uninstall whether to keep the data
38 <a id="l29" href="#l29">29</a>   (`hasFragileUserData`), and Rebind keeps an automatic copy of the settings in
39 <a id="l30" href="#l30">30</a>   `Documents/Rebind/rebind-settings.json`, which an uninstall does not touch.
40 <a id="l31" href="#l31">31</a>   Import opens that folder. `StoredFormatTest` holds the texts that every
41 <a id="l32" href="#l32">32</a>   0.0.x version stored, so a new version cannot stop reading them unseen.

73 <a id="l64" href="#l64">64</a>   request dialog for the assistant role. The row now opens the settings page
74 <a id="l65" href="#l65">65</a>   &quot;Default digital assistant app&quot;.
