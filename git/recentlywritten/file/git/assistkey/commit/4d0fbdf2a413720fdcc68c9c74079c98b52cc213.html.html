14 Fix Extra dim toggle; add a switch for the system Emergency SOS
15 
16 Extra dim toggle. On now goes to the lowest level. Off gives the light back to
17 the brightness set in the system. Before, on used the level last in use, or a
18 middle level when there was none. ExtraDim.toggled is the rule, with regression
19 tests. The stored &quot;last level&quot; value is deleted.
20 
21 The three light actions get their name from the payload and not from the stored
22 label, so a binding made by 0.0.6 shows the new name: Extra dim toggle, Extra
23 dim darker, Extra dim brighter.
24 
25 Emergency SOS. Android starts Emergency SOS on five quick Power presses, which
26 collides with a 5-tap binding. The Power screen has a switch for it
27 (Settings.Secure emergency_gesture_enabled). The app never turns it off by
28 itself. The app writes the setting directly when it holds
29 WRITE_SECURE_SETTINGS, and through the shell otherwise. The switch shows only
30 where one of the two ways is open. Tested on the reader: with the value 0, five
31 presses are counted and no SOS starts.
