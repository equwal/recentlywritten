14 Fix a Camera key in the drawing of a device that has none
15 
16 The Viwoods reader declares a camera key to Android and has no such
17 button. Device.keys added the keys that detection found, so the drawing
18 showed a Camera key. A declared key is not a button.
19 
20 Device.keys now lists the keys of the device profile and the keys that
21 were really pressed in normal use. The Detect screen still lists what
22 the device declares, and marks a key that was never seen.
23 
24 DeviceKeysTest holds the input that caused the defect.
