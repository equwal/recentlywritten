14 Let the user change a button from the Done step
15 
16 The Done step has two buttons: Change what it does, and Change how you
17 press it. They go back to those steps with the button and the gesture
18 kept, so that the user can adjust a binding while he tests it. Back on
19 the Done step goes to the actions too.
20 
21 Route.back holds the rule for Back as a pure function, with a test for
22 each branch. The step that follows a return from the action list now
23 runs only after the screen was really left for that list.
