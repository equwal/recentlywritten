14 Add ready-made menus, a permissions screen and recents polish; tone down shell access (0.0.7-alpha)
15 
16 Ready-made menus. The action list offers menus that bind in one tap:
17 Brightness (full build), Navigation, System, Sound and media, Page turning,
18 and Viwoods AI on Viwoods devices. Each is an ordinary menu after it is bound.
19 
20 Brightness up and down. Two more light actions, for the system brightness. A
21 step is a quarter of the present value and at least 5, and stays in range;
22 tests cover every value from 0 to 255.
23 
24 Permissions screen. Every grant the app can use, with its purpose and state.
25 &quot;Set up what is missing&quot; opens the grant screens one after the other. It
26 opens once by itself on the first run and can be run again at any time. A
27 permission dialog reports twice on return, as a result and as a resume, so a
28 second step close behind the first is dropped.
29 
30 The accessibility disclosure is now one shared text. It names voice typing and
31 the app-in-front note, which the old text did not.
32 
33 Recent apps. One swipe moves one card. A row of icons under the cards shows
34 every recent app and marks the one in the middle. The heading says which app
35 and its position. Each card that can be closed says &quot;Swipe up to close&quot;, and
36 &quot;Close all but &lt;app&gt;&quot; sits beside &quot;Close all&quot;.
37 
38 Shell access and the extra-dim light move under Advanced, and shell access is
39 not counted as a missing permission. They serve the few devices with Shizuku
40 or root, and the app is complete without them.
41 
42 Store listing: the title is &quot;AssistKey: E-Ink Key Remap&quot;. No device maker is
43 named in the title, and the description has a not-affiliated line. A maker
44 name at the front of a title reads as an official app and can be removed as
45 impersonation. The checklist records the advice to price at US$4.99; the owner
46 has not decided.
