14 Open Ink Recents where the system shows its recent apps
15 
16 Android does not let an app take the place of the recent-apps screen of
17 the system. The key filter already gets the window-state events. When
18 the screen in front is the recents of the system (the task manager of
19 the Viwoods launcher, or the two stock Android ones), the service sends
20 Back and starts Ink Recents. A switch on Home and recents turns it off.
21 It is on when Ink Recents is installed.
22 
23 The accessibility disclosure and the Play declaration name this use.
24 
25 Version 0.0.15-alpha, version code 15.
