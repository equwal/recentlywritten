14 Keep the settings across an uninstall, and pin the stored formats
15 
16 An update always kept the settings, because they are in the data of the
17 app. An uninstall removed them. hasFragileUserData makes Android ask at
18 uninstall whether to keep the data. AutoBackup writes the export text to
19 Documents/Rebind/rebind-settings.json a few seconds after each change,
20 and once at start. It needs no permission. Import opens that folder.
21 
22 StoredFormatTest holds the bindings and the settings file as the 0.0.x
23 versions wrote them. A change that cannot read them fails the test.
