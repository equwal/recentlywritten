14 Add action menus, settings export and import, and extra-dim key actions (0.0.6-alpha)
15 
16 Menu of actions. A gesture can open a menu that holds any number of actions, so
17 there can be more actions than keys. The menu is stored in the payload of its
18 own binding as a JSON array of action specs. There is no second store, so
19 export, import and delete treat a menu like any other binding. A menu cannot
20 hold a menu. MenuActivity closes before it runs the action, because Back, a
21 swipe or voice typing act on the app in front.
22 
23 Export and import. SettingsFile turns the settings into one JSON document and
24 back. It has no Android types. SettingsFile.ALLOWED is the only list of what
25 may pass, in both directions. The licence, the firmware values that
26 PowerControl saved, and facts about one device never enter the file, and a
27 file cannot write them. An import shows what it holds and applies it only
28 after a yes. It keeps only bindings whose trigger this version can parse.
29 
30 Extra-dim key actions, full flavour only: darker, brighter, on and off.
31 
32 Voice typing now prefers a speech app that recognises on the device over one
33 that may use a server, and the Voice typing screen offers Whisper from F-Droid
34 when no on-device speech app is installed. With no language tag the speech app
35 detects the language. The app does not bundle a Whisper model: a multilingual
36 model is 140 MB or more, and with no INTERNET permission the app cannot
37 download one.
38 
39 Tests: JUnit 4 and the org.json jar are new test dependencies. There was no
40 test framework before. Android gives unit tests an empty stub of org.json, so
41 the jar is needed to test SettingsFile. 20 tests: the speech app choice rule,
42 the settings round trip on 500 random cases and its allow-list, the light
43 level steps, the menu round trip.
