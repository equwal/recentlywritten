14 Ask for a grant at the moment the user needs it
15 
16 GuidedSetupActivity.askIfMissing takes any context and says whether it
17 opened the allow step. The menu editor calls it after a save. The
18 Navigation screen calls it for the first Power binding that needs
19 something. A Power press that arrives while button remapping is off
20 opens the allow step and no longer shows a toast, which the reader
21 hides. Voice typing with no microphone grant opens the Voice typing
22 screen.
