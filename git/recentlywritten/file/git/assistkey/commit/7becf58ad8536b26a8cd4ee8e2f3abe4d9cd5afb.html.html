14 Add a key tester, and call out the restricted-settings block
15 
16 Two things only a real device would have shown.
17 
18 Android silently reverts accessibility access for apps installed outside
19 an app store - the switch appears to turn on and then quietly goes back
20 off, with no message anywhere. There is no API to detect it, so the
21 accessibility channel now says so in place and links straight to App
22 info. Over adb the equivalent is appops set ACCESS_RESTRICTED_SETTINGS
23 allow.
24 
25 Whether a key reaches an input filter at all is a per-firmware question
26 with no way to look it up, and events injected with adb shell input
27 keyevent bypass accessibility input filters entirely, so remote testing
28 proves nothing either way. The key tester records every event the filter
29 sees; a key that never appears is a key the window manager consumed
30 upstream, which is what Power looks like everywhere.
31 
32 isAccessibilityOn now trusts the running service over the settings
33 string, since the service lives in this process and the string is itself
34 subject to read restrictions.
