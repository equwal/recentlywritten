14 Recent apps: a row of swipe cards in place of the list (0.0.5-alpha)
15 
16 RecentsActivity now shows the recent apps as cards, like the Android switcher.
17 Swipe sideways through the cards, tap a card to open the app, swipe a card up
18 to close it. The cards are drawn for e-ink: black outlines on white, no fling,
19 and the row moves one card for each swipe with no animation.
20 
21 With shell access the cards are the real tasks of the system. A swipe up runs
22 `am stack remove &lt;task id&gt;`, which the shell user may do. Where the shell is
23 root, each card shows the picture the system keeps of the task, read from
24 /data/system_ce/0/snapshots. Those files belong to `system`, so a plain shell
25 cannot read them, and the card then shows the app icon.
26 
27 The task list parser now accepts both forms of a task line: `A=&lt;uid&gt;:&lt;package&gt;`
28 and `I=&lt;package&gt;/&lt;class&gt;`.
29 
30 The list view is deleted; the cards replace it.
