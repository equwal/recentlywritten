16 Navigation screen: button bar, swipe gestures and Power key combinations in any
17 mix, with five named setups. The system half cannot be switched by an app, so
18 the screen reports live state and gives the commands; tools/nav-mode runs them.
19 Measured: the gestural overlay removes the bar outright on this firmware, the
20 swipe-up Home gesture is Viwoods&#x27; own (Settings.System disable_gesture_bottom),
21 and edge-swipe Back only goes away with the inset scale at zero. The overlay
22 has to be switched before the setting is written or SystemUI forgets it.
23

25 role, and a key pressed while it is still down reaches the filter, so &quot;hold
26 Power, then AI / Volume up / Volume down&quot; are three real combinations. Back,
27 Home and Recents on them keep working when the app is locked, so a reader with
28 no bar and no gestures cannot be bricked by an expired trial.
29

31 consumed the key; earlier tests only looked right because Home landed last.

33 the filter never sees the key. AiKeyActivity is that component: taps are
34 counted from launches. tools/ai-key hook|unhook|status.
