14 Add the Viwoods AI voice prompt as an action
15 
16 On a hold of the AI key, the firmware starts WebViewAiActivity of the
17 Viwoods AI app with the text extra recodeKey=recode_key_start. The
18 action AI voice prompt does the same, so that any button can have it.
19 
20 The payload of LAUNCH_COMPONENT can carry text extras after a question
21 mark. ComponentPayload parses it with no Android types. A payload from
22 before reads as it did.
