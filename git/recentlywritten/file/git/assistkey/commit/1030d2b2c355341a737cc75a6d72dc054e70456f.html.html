14 Viwoods: inside the AI screen or the crop screen, the AI key goes back
15 
16 The key filter now reads window changes to know which app was in use before an
17 AI screen opened. It keeps the latest package name only, in memory only. When
18 the AI key is pressed inside the Viwoods AI assistant, or inside the crop and
19 screenshot-edit screens, the app brings that earlier app back with the same
20 intent a launcher sends. If the earlier app was a home screen, it goes Home.
21 
22 The firmware reacts to the AI key by itself and can open its AI screen again,
23 so the return waits 350 ms for that to land first. The same rule applies when
24 the firmware hook points at AiKeyActivity.
25 
26 A switch on the AI key screen turns the rule off. It is on by default on
27 Viwoods devices and absent on others.
28 
29 Test on a device: tools/e2e/ai-key-return.sh.
