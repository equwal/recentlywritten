14 Add an action that shows or hides the button bar
15 
16 Android 16 has no auto-hide for the three-button bar. ActionKind.NAV
17 with the payload toggle_bar switches the bar through shell access, with
18 the commands that the Navigation screen uses, and keeps the gestures as
19 the user set them. The allow step asks for shell access when an action
20 works through the shell: the button bar and the light.
