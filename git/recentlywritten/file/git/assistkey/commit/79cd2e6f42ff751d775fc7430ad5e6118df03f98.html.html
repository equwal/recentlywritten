14 Handle hidden power settings being unreadable, not just unwritable
15 
16 Android 12 blocks non-system apps from reading settings keys annotated
17 @hide, and holding WRITE_SECURE_SETTINGS does not exempt you - reading
18 power_button_short_press threw SecurityException and took the main
19 screen down on first launch.
20 
21 Every read now returns null on refusal, the UI says unknown instead of
22 inventing a value, and the two gesture switches became explicit On/Off
23 pickers because there is nothing to toggle away from when the current
24 value cannot be read. Writes are unaffected and still work.
25
