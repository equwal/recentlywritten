675 <span class="a">+## Known Limitations</span>
676 <span class="a">+</span>
677 <span class="a">+### Use ~~ To Create ~</span>
678 <span class="a">+</span>
679 <span class="a">+cl-yag crashes if you use a single &quot;**~**&quot; caracter inside one data</span>
680 <span class="a">+structure in **articles.lisp** files, because Common Lisp employs the</span>
681 <span class="a">+tilde as a prefix to indicate format specifiers in format strings.</span>
682 <span class="a">+</span>
683 <span class="a">+In order to use a literal `~` - e.g. for creating a :title or :url</span>
684 <span class="a">+reference - you have to **escape** the tilde **by duplicating** it:</span>
685 <span class="a">+``~~``.  </span>
686 <span class="a">+(See _:url_ in section &#x27;Configuration&#x27;).</span>
687 <span class="a">+</span>

700 <span class="a">+focuses only on generating html- and gopher-compliant structural</span>
701 <span class="a">+markup - not themed layouts.</span>
