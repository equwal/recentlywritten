112 <span class="a">+## Use of ~ character</span>
113  
114  The application will crash if you use a single &quot;**~**&quot; caracter inside one data structure in **articles.lisp** files. This is due to the format function trying to interpret the ~ symbol while we just one a ~ symbol. This symbol in the others files are automatically replaced by ~~ which produce a single ~. So, if you want to have a &quot;~&quot; as a title/url/author/description/short/date you have to double it. It may be interestind to sanitize it in the tool maybe.
