82 <span class="a">+# ai-config-render (`aicr`)</span>
83 <span class="a">+</span>
84 <span class="a">+Write your AI-agent rules, skills, and MCP servers once. `aicr` renders them into the native files of Claude Code, Codex, Copilot CLI, Gemini CLI, Antigravity, Cursor, Windsurf, or any agent you describe in five lines of TOML.</span>
85 <span class="a">+</span>
86 <span class="a">+It never takes over a file. It owns only:</span>
87 <span class="a">+</span>
88 <span class="a">+- **Instruction files:** the blocks between `&lt;!-- aicr:NAME --&gt;` and `&lt;!-- /aicr:NAME --&gt;`. Your own text stays.</span>
89 <span class="a">+- **MCP configs:** the server entries it wrote. Your other servers and settings stay.</span>
90 <span class="a">+- **Skills and plain files:** the paths it wrote last run (tracked in a state file).</span>
91 <span class="a">+</span>
92 <span class="a">+It backs up every file before it changes it (`&lt;file&gt;.aicr-bak-&lt;timestamp&gt;`). Python 3.11+ standard library only.</span>
93 <span class="a">+</span>
94 <span class="a">+## Quickstart</span>
95 <span class="a">+</span>
96 <span class="a">+```bash</span>
97 <span class="a">+pipx install git+https://github.com/equwal/ai-config-render</span>
98 <span class="a">+aicr list-targets --source examples/basic   # built-in targets; * = enabled</span>
99 <span class="a">+aicr diff   --source examples/basic         # dry run: unified diff of every change</span>
100 <span class="a">+aicr render --source examples/basic         # write, with backups</span>
101 <span class="a">+aicr check  --source examples/basic         # exit 1 if any target drifted (CI, cron)</span>
102 <span class="a">+```</span>
103 <span class="a">+</span>
104 <span class="a">+## Source layout</span>
105 <span class="a">+</span>
106 <span class="a">+Any folder works, git or not:</span>
107 <span class="a">+</span>
108 <span class="a">+```</span>
109 <span class="a">+aicr.toml            targets, rules, MCP servers, skills, files, vars</span>
110 <span class="a">+rules/&lt;name&gt;.md      one block per rule; rules/&lt;name&gt;.&lt;target&gt;.md overrides for one target</span>
111 <span class="a">+skills/&lt;name&gt;/       copied whole into each target&#x27;s skills folders</span>
112 <span class="a">+```</span>
113 <span class="a">+</span>
114 <span class="a">+See [`examples/basic/aicr.toml`](examples/basic/aicr.toml). Enable a built-in target with `[targets.claude]`; override any field, or define a new target:</span>
115 <span class="a">+</span>
116 <span class="a">+```toml</span>
117 <span class="a">+[targets.myagent]</span>
118 <span class="a">+instructions = &quot;${home}/.myagent/RULES.md&quot;</span>
119 <span class="a">+skills = [&quot;${home}/.myagent/skills&quot;]</span>
120 <span class="a">+mcp = { format = &quot;json&quot;, path = &quot;${home}/.myagent/mcp.json&quot;, key = &quot;servers&quot; }  # or format = &quot;toml&quot;</span>
121 <span class="a">+```</span>
122 <span class="a">+</span>
123 <span class="a">+Any rule, server, skill, or file takes `targets = [...]` and `machines = [...]` filters.</span>
124 <span class="a">+</span>
125 <span class="a">+## Per-machine values</span>
126 <span class="a">+</span>
127 <span class="a">+`~/.config/aicr/machine.toml` (or `--machine FILE`) holds what differs per computer: `name`, `[vars]`, `skip_targets`, `state`, and `[mcp.&lt;server&gt;]` overrides. `${var}` works in every path and string. Built-in vars: `home`, `home_posix`, `os`, `machine`. See [`examples/machine.example.toml`](examples/machine.example.toml).</span>
128 <span class="a">+</span>
129 <span class="a">+## Why not ruler, rulesync, or chezmoi?</span>
130 <span class="a">+</span>
131 <span class="a">+- **ruler / rulesync** generate project-level agent files and mostly overwrite them. `aicr` targets user-level config, edits only its own blocks and entries, and backs up first, so it can share a file with your hand edits and with other tools.</span>
132 <span class="a">+- **chezmoi** manages whole dotfiles. A single `~/.claude.json` mixes your MCP servers with app state that changes every minute; `aicr` merges one key instead of owning the file.</span>
133 <span class="a">+</span>

342 <span class="a">+            if m.group(1) not in env:</span>
343 <span class="a">+                raise Missing(m.group(1))</span>
344 <span class="a">+            return env[m.group(1)]</span>
345 <span class="a">+</span>
346 <span class="a">+        return VAR.sub(rep, value)</span>
347 <span class="a">+    if isinstance(value, list):</span>
348 <span class="a">+        return [sub(v, env) for v in value]</span>
349 <span class="a">+    if isinstance(value, dict):</span>
350 <span class="a">+        return {k: sub(v, env) for k, v in value.items()}</span>
351 <span class="a">+    return value</span>

355 <span class="a">+    out = dict(a)</span>
356 <span class="a">+    for k, v in b.items():</span>
357 <span class="a">+        out[k] = merge(out[k], v) if isinstance(v, dict) and isinstance(out.get(k), dict) else v</span>
358 <span class="a">+    return out</span>

371 <span class="a">+    stamp: str = field(default_factory=lambda: dt.datetime.now().astimezone().strftime(&quot;%Y%m%d%H%M%S&quot;))</span>
372 <span class="a">+    changes: list[tuple[Path, str | None, str | None]] = field(default_factory=list)</span>
373 <span class="a">+    pending: dict[Path, str] = field(default_factory=dict)  # what a dry run would have written</span>

375 <span class="a">+    def read(self, p: Path) -&gt; str | None:</span>
376 <span class="a">+        return self.pending.get(p, p.read_text(encoding=&quot;utf-8&quot;) if p.exists() else None)</span>

378 <span class="a">+    def backup(self, p: Path) -&gt; None:</span>
379 <span class="a">+        if p.exists() and not self.dry:</span>

381 <span class="a">+            if p.is_dir():</span>

384 <span class="a">+                shutil.copy2(p, dst)</span>
385 <span class="a">+</span>
386 <span class="a">+    def text(self, p: Path, new: str) -&gt; None:</span>
387 <span class="a">+        old = self.read(p)</span>
388 <span class="a">+        if old == new:</span>
389 <span class="a">+            return</span>
390 <span class="a">+        self.changes.append((p, old, new))</span>
391 <span class="a">+        self.pending[p] = new</span>
392 <span class="a">+        if self.dry:</span>
393 <span class="a">+            return</span>
394 <span class="a">+        self.backup(p)</span>
395 <span class="a">+        p.parent.mkdir(parents=True, exist_ok=True)</span>
396 <span class="a">+        tmp = p.with_name(p.name + &quot;.aicr-tmp&quot;)</span>
397 <span class="a">+        tmp.write_text(new, encoding=&quot;utf-8&quot;, newline=&quot;&quot;)</span>
398 <span class="a">+        os.replace(tmp, p)</span>

400 <span class="a">+    def copy(self, src: Path, dst: Path) -&gt; None:</span>
401 <span class="a">+        if dst.exists() and dst.read_bytes() == src.read_bytes():</span>
402 <span class="a">+            return</span>
403 <span class="a">+        self.changes.append((dst, None, None))</span>
404 <span class="a">+        if not self.dry:</span>
405 <span class="a">+            self.backup(dst)</span>
406 <span class="a">+            dst.parent.mkdir(parents=True, exist_ok=True)</span>
407 <span class="a">+            shutil.copy2(src, dst)</span>

409 <span class="a">+    def remove(self, p: Path) -&gt; None:</span>
410 <span class="a">+        if not p.exists():</span>
411 <span class="a">+            return</span>
412 <span class="a">+        self.changes.append((p, &quot;&quot;, None))</span>
413 <span class="a">+        if not self.dry:</span>
414 <span class="a">+            self.backup(p)</span>
415 <span class="a">+            if p.is_dir():</span>
416 <span class="a">+                shutil.rmtree(p)</span>
417 <span class="a">+            else:</span>
418 <span class="a">+                p.unlink()</span>

424 <span class="a">+def block_re(name: str) -&gt; re.Pattern[str]:</span>
425 <span class="a">+    n = re.escape(name)</span>
426 <span class="a">+    return re.compile(rf&quot;&lt;!-- aicr:{n} --&gt;\n.*?&lt;!-- /aicr:{n} --&gt;\n?&quot;, re.DOTALL)</span>

429 <span class="a">+def render_instructions(text: str, blocks: dict[str, str], dropped: set[str]) -&gt; str:</span>
430 <span class="a">+    &quot;&quot;&quot;Replace or append each owned block; remove dropped ones; keep all other text.&quot;&quot;&quot;</span>
431 <span class="a">+    for name in dropped:</span>
432 <span class="a">+        text = block_re(name).sub(&quot;&quot;, text)</span>
433 <span class="a">+    for name, body in blocks.items():</span>
434 <span class="a">+        new = f&quot;&lt;!-- aicr:{name} --&gt;\n{body.rstrip()}\n&lt;!-- /aicr:{name} --&gt;\n&quot;</span>
435 <span class="a">+        rx = block_re(name)</span>
436 <span class="a">+        first = rx.search(text)</span>
437 <span class="a">+        if first:</span>
438 <span class="a">+            # Keep the first position, drop duplicates.</span>
439 <span class="a">+            text = text[: first.start()] + new + rx.sub(&quot;&quot;, text[first.end() :])</span>
440 <span class="a">+        else:</span>
441 <span class="a">+            text = text.rstrip(&quot;\n&quot;) + (&quot;\n\n&quot; if text.strip() else &quot;&quot;) + new</span>
442 <span class="a">+    return text</span>

452 <span class="a">+def toml_value(v: Any) -&gt; str:</span>
453 <span class="a">+    if isinstance(v, bool):</span>
454 <span class="a">+        return &quot;true&quot; if v else &quot;false&quot;</span>
455 <span class="a">+    if isinstance(v, (int, float)):</span>
456 <span class="a">+        return repr(v)</span>
457 <span class="a">+    if isinstance(v, str):</span>
458 <span class="a">+        return json.dumps(v, ensure_ascii=False).replace(chr(0x7F), &quot;\\u007f&quot;)  # TOML forbids a raw DEL</span>
459 <span class="a">+    if isinstance(v, list):</span>
460 <span class="a">+        return &quot;[&quot; + &quot;, &quot;.join(toml_value(x) for x in v) + &quot;]&quot;</span>
461 <span class="a">+    if isinstance(v, dict):</span>
462 <span class="a">+        return &quot;{ &quot; + &quot;, &quot;.join(f&quot;{toml_key(k)} = {toml_value(x)}&quot; for k, x in v.items()) + &quot; }&quot;</span>
463 <span class="a">+    raise TypeError(f&quot;cannot write {type(v).__name__} to TOML&quot;)</span>

466 <span class="a">+def render_toml(text: str, servers: dict[str, dict[str, Any]], owned: set[str]) -&gt; str:</span>
467 <span class="a">+    &quot;&quot;&quot;Drop every [mcp_servers.&lt;owned&gt;...] table, then append ours in one marked block.&quot;&quot;&quot;</span>
468 <span class="a">+    text = re.sub(r&quot;# aicr:mcp\n.*?# /aicr:mcp\n?&quot;, &quot;&quot;, text, flags=re.DOTALL)</span>
469 <span class="a">+    out: list[str] = []</span>
470 <span class="a">+    skip = False</span>
471 <span class="a">+    for line in text.splitlines(keepends=True):</span>
472 <span class="a">+        m = re.match(r&quot;\s*\[\[?\s*([^\]]+?)\s*\]\]?\s*(#.*)?$&quot;, line)</span>
473 <span class="a">+        if m:</span>
474 <span class="a">+            parts = [p.strip().strip(&quot;\&quot;&#x27;&quot;) for p in re.split(r&quot;\.(?=(?:[^\&quot;]*\&quot;[^\&quot;]*\&quot;)*[^\&quot;]*$)&quot;, m.group(1))]</span>
475 <span class="a">+            skip = len(parts) &gt;= 2 and parts[0] == &quot;mcp_servers&quot; and parts[1] in owned</span>
476 <span class="a">+        if not skip:</span>
477 <span class="a">+            out.append(line)</span>
478 <span class="a">+    text = &quot;&quot;.join(out).rstrip(&quot;\n&quot;)</span>
479 <span class="a">+    if servers:</span>
480 <span class="a">+        body = [&quot;# aicr:mcp&quot;]</span>
481 <span class="a">+        for name, cfg in servers.items():</span>
482 <span class="a">+            body.append(f&quot;[mcp_servers.{toml_key(name)}]&quot;)</span>
483 <span class="a">+            body += [f&quot;{toml_key(k)} = {toml_value(v)}&quot; for k, v in cfg.items()]</span>
484 <span class="a">+            body.append(&quot;&quot;)</span>
485 <span class="a">+        text += (&quot;\n\n&quot; if text else &quot;&quot;) + &quot;\n&quot;.join(body) + &quot;# /aicr:mcp\n&quot;</span>
486 <span class="a">+    tomllib.loads(text)  # refuse to write a broken config</span>
487 <span class="a">+    return text if not text or text.endswith(&quot;\n&quot;) else text + &quot;\n&quot;</span>

528 <span class="a">+def render(source: Path, machine_file: Path, dry: bool) -&gt; tuple[Writer, list[str]]:</span>
529 <span class="a">+    cfg, mach, env = load(source, machine_file)</span>
530 <span class="a">+    machine = env[&quot;machine&quot;]</span>
531 <span class="a">+    state_file = Path(sub(mach.get(&quot;state&quot;, DEFAULT_STATE), env)).expanduser()</span>
532 <span class="a">+    state = json.loads(state_file.read_text(encoding=&quot;utf-8&quot;)) if state_file.exists() else {}</span>
533 <span class="a">+    new_state: dict[str, Any] = {}</span>
534 <span class="a">+    w = Writer(dry)</span>
535 <span class="a">+    notes: list[str] = []</span>
536 <span class="a">+</span>
537 <span class="a">+    for tname, raw in targets(cfg).items():</span>
538 <span class="a">+        if tname in mach.get(&quot;skip_targets&quot;, []):</span>
539 <span class="a">+            continue</span>
540 <span class="a">+        try:</span>
541 <span class="a">+            t = sub(raw, env)</span>
542 <span class="a">+        except Missing as e:</span>
543 <span class="a">+            notes.append(f&quot;{tname}: skipped, no var {e}&quot;)</span>
544 <span class="a">+            continue</span>
545 <span class="a">+        prev = state.get(tname, {})</span>
546 <span class="a">+        cur = new_state.setdefault(tname, {})</span>
547 <span class="a">+</span>
548 <span class="a">+        if &quot;instructions&quot; in t:</span>
549 <span class="a">+            blocks: dict[str, str] = {}</span>
550 <span class="a">+            for name, r in cfg.get(&quot;rules&quot;, {}).items():</span>
551 <span class="a">+                if not applies(r, tname, machine):</span>
552 <span class="a">+                    continue</span>
553 <span class="a">+                src = source / &quot;rules&quot; / f&quot;{name}.{tname}.md&quot;</span>
554 <span class="a">+                src = src if src.exists() else source / &quot;rules&quot; / f&quot;{name}.md&quot;</span>
555 <span class="a">+                try:</span>
556 <span class="a">+                    blocks[name] = sub(src.read_text(encoding=&quot;utf-8&quot;), env)</span>
557 <span class="a">+                except Missing as e:</span>
558 <span class="a">+                    notes.append(f&quot;{tname}: rule {name} skipped, no var {e}&quot;)</span>
559 <span class="a">+            p = Path(t[&quot;instructions&quot;]).expanduser()</span>
560 <span class="a">+            # Two targets can share one file (gemini, antigravity): merge their blocks.</span>
561 <span class="a">+            file_state = new_state.setdefault(&quot;_instructions&quot;, {}).setdefault(str(p), [])</span>
562 <span class="a">+            dropped = set(prev.get(&quot;rules&quot;, [])) - blocks.keys() - set(file_state)</span>
563 <span class="a">+            file_state.extend(sorted(blocks))</span>
564 <span class="a">+            if blocks or dropped:</span>
565 <span class="a">+                w.text(p, render_instructions(w.read(p) or &quot;&quot;, blocks, dropped))</span>
566 <span class="a">+            cur[&quot;rules&quot;] = sorted(blocks)</span>
567 <span class="a">+</span>
568 <span class="a">+        if &quot;mcp&quot; in t:</span>
569 <span class="a">+            servers: dict[str, dict[str, Any]] = {}</span>
570 <span class="a">+            for name, s in cfg.get(&quot;mcp&quot;, {}).items():</span>
571 <span class="a">+                if not applies(s, tname, machine):</span>
572 <span class="a">+                    continue</span>
573 <span class="a">+                m = mach.get(&quot;mcp&quot;, {}).get(name, {})</span>
574 <span class="a">+                # Precedence, low to high: target defaults, server, server.target.&lt;t&gt;, machine, machine.target.&lt;t&gt;</span>
575 <span class="a">+                spec: dict[str, Any] = t[&quot;mcp&quot;].get(&quot;defaults&quot;, {})</span>
576 <span class="a">+                for layer in (s, s.get(&quot;target&quot;, {}).get(tname, {}), m, m.get(&quot;target&quot;, {}).get(tname, {})):</span>
577 <span class="a">+                    spec = merge(spec, layer)</span>
578 <span class="a">+                spec = {k: v for k, v in spec.items() if k not in (&quot;targets&quot;, &quot;machines&quot;, &quot;target&quot;)}</span>
579 <span class="a">+                try:</span>
580 <span class="a">+                    servers[name] = sub(spec, env)</span>
581 <span class="a">+                except Missing as e:</span>
582 <span class="a">+                    notes.append(f&quot;{tname}: mcp {name} skipped, no var {e}&quot;)</span>
583 <span class="a">+            p = Path(t[&quot;mcp&quot;][&quot;path&quot;]).expanduser()</span>
584 <span class="a">+            owned = set(servers) | set(prev.get(&quot;mcp&quot;, []))</span>
585 <span class="a">+            if servers or owned:</span>
586 <span class="a">+                old = w.read(p) or &quot;&quot;</span>
587 <span class="a">+                fmt = t[&quot;mcp&quot;][&quot;format&quot;]</span>
588 <span class="a">+                if fmt == &quot;toml&quot;:</span>
589 <span class="a">+                    w.text(p, render_toml(old, servers, owned))</span>
590 <span class="a">+                elif fmt == &quot;json&quot;:</span>
591 <span class="a">+                    w.text(p, render_json(old, servers, owned, t[&quot;mcp&quot;].get(&quot;key&quot;, &quot;mcpServers&quot;)))</span>
592 <span class="a">+                else:</span>
593 <span class="a">+                    raise SystemExit(f&quot;{tname}: unknown mcp format {fmt!r} (use json or toml)&quot;)</span>
594 <span class="a">+            cur[&quot;mcp&quot;] = sorted(servers)</span>
595 <span class="a">+</span>
596 <span class="a">+        names = [n for n, s in cfg.get(&quot;skills&quot;, {}).items() if applies(s, tname, machine)]</span>
597 <span class="a">+        for d in t.get(&quot;skills&quot;, []):</span>
598 <span class="a">+            root = Path(d).expanduser()</span>
599 <span class="a">+            for n in names:</span>
600 <span class="a">+                skill = source / &quot;skills&quot; / n</span>
601 <span class="a">+                for f in sorted(skill.rglob(&quot;*&quot;)) if skill.is_dir() else []:</span>
602 <span class="a">+                    if f.is_file() and &quot;__pycache__&quot; not in f.parts:</span>
603 <span class="a">+                        w.copy(f, root / n / f.relative_to(skill))</span>
604 <span class="a">+            for n in set(prev.get(&quot;skills&quot;, [])) - set(names):</span>
605 <span class="a">+                w.remove(root / n)</span>
606 <span class="a">+        cur[&quot;skills&quot;] = names</span>
607 <span class="a">+</span>
608 <span class="a">+    owned_files: list[str] = []</span>
609 <span class="a">+    for dest, f in cfg.get(&quot;files&quot;, {}).items():</span>
610 <span class="a">+        if not applies(f, &quot;&quot;, machine):</span>
611 <span class="a">+            continue</span>
612 <span class="a">+        try:</span>
613 <span class="a">+            dest_p, src = Path(sub(dest, env)).expanduser(), source / sub(f[&quot;src&quot;], env)</span>
614 <span class="a">+            data = src.read_text(encoding=&quot;utf-8&quot;)</span>
615 <span class="a">+            w.text(dest_p, sub(data, env) if f.get(&quot;template&quot;, False) else data)</span>
616 <span class="a">+        except Missing as e:</span>
617 <span class="a">+            notes.append(f&quot;file {dest} skipped, no var {e}&quot;)</span>
618 <span class="a">+            continue</span>
619 <span class="a">+        owned_files.append(str(dest_p))</span>
620 <span class="a">+    for gone in set(state.get(&quot;_files&quot;, [])) - set(owned_files):</span>
621 <span class="a">+        w.remove(Path(gone))</span>
622 <span class="a">+    new_state[&quot;_files&quot;] = owned_files</span>
623 <span class="a">+    new_state.pop(&quot;_instructions&quot;, None)</span>
624 <span class="a">+</span>
625 <span class="a">+    if not dry:</span>
626 <span class="a">+        state_file.parent.mkdir(parents=True, exist_ok=True)</span>
627 <span class="a">+        state_file.write_text(json.dumps(new_state, indent=1), encoding=&quot;utf-8&quot;)</span>
628 <span class="a">+    return w, notes</span>
