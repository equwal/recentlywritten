14 Import local edits instead of overwriting them; add aicr watch
15 
16 aicr records a hash of every owned file and block it writes. A target
17 that no longer matches was edited there: if the source is unchanged the
18 edit is copied back into the source; if both changed, the local copy is
19 saved as &lt;source&gt;.conflict-&lt;machine&gt;-&lt;date&gt; and the source wins. Text
20 matching an [import] deny pattern is never imported.
21 
22 aicr watch polls the owned files and the source tree, waits for a burst
23 of changes to settle, renders, and runs an optional --exec command.
24 --remote-every pulls when the upstream branch moves. Backups are now one
25 rolling &lt;file&gt;.aicr-bak.
26 
27 examples/service has a post-receive notify hook, systemd and runit
28 services, a Windows logon task, and a commit-and-push hook.
