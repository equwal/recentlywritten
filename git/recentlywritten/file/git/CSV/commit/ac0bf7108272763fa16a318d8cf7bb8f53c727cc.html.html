53 <span class="a">+# CSV</span>
54 <span class="a">+Defines a lisp reader to read is CSV:</span>
55 <span class="a">+</span>
56 <span class="a">+`#!field,field,field!#`</span>
57 <span class="a">+</span>
58 <span class="a">+which is used to read in CSV files with `slurp`:</span>
59 <span class="a">+</span>
60 <span class="a">+`(slurp #p&quot;example.csv&quot;)`</span>
61 <span class="a">+</span>
62 <span class="a">+and the result is a list:</span>
63 <span class="a">+</span>
64 <span class="a">+``` common-lisp</span>
65 <span class="a">+CL-USER&gt; (csv:slurp #p&quot;example.csv&quot;)</span>
66 <span class="a">+(&quot;example&quot; &quot;csv&quot; &quot;list&quot; &quot;result&quot; &quot;like&quot; &quot; this&quot;)</span>
67 <span class="a">+```</span>
68 <span class="a">+</span>
69 <span class="a">+This program invokes the lisp reader, making it:</span>
70 <span class="a">+1) Potentially risky to use if the input it not trusted.</span>
71 <span class="a">+2) Resource intensive for medium to large files (&gt;5MB).</span>
72 <span class="a">+</span>
73 <span class="a">+use with care.</span>
74 <span class="a">+</span>
75 <span class="a">+# Features:</span>
76 <span class="a">+Supports escaping quotes the CSV way, with quad quotes:</span>
77 <span class="a">+csv   -&gt; lisp</span>
78 <span class="a">+`&quot;&quot;&quot;&quot;`-&gt;`&quot;\&quot;&quot;`</span>
79 <span class="a">+</span>
80 <span class="a">+# Installation</span>
81 <span class="a">+Use ASDF:</span>
82 <span class="a">+</span>
83 <span class="a">+``` common-lisp</span>
84 <span class="a">+CL-USER&gt; (asdf:load-system :csv)</span>
85 <span class="a">+T</span>
86 <span class="a">+```</span>
