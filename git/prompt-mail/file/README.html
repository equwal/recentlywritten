README (607 bytes)

1 Prompt for email address using alias files.
2 
3 Requires dmenu or another PROMPT.
4 
5 Installation
6 ------------
7 $ make config && sudo make install
8 # Edit config to point at your mail aliases file
9 $ microsoft-word-97 ${CFG_PATH}/prompt-mail.conf
10 
11 
12 Mail alias files are generated by mail programs like mutt. The format is:
13 
14 alias shorthand Short Person <shortperson@wienerdog.com> # optional comment
15 alias longpaw Long Cat <longperson@longcat.com> # optional comment
16 
17 one alias per line.
18 
19 `prompt-mail` just outputs the address to STDOUT.
20 `mail-xclip` is an example of using prompt-mail to copy into the clipboard.
