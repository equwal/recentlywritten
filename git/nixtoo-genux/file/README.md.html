9 ## Files:
10 
11 1. `flake.nix`: Put packages here. Includes a dev shell and flakey.
12 2. `aliasrc-additions.zsh`:  Aliases to make it easier to use the setup. Very mandatory.
13 3. `INSTALL.sh`: Installs this setup. Install it after installing
14 the multi-user installation of nix from the [official website using curl into shell](https://nixos.org/download/) or
15 (for Gentoo) from`sys-apps/nix` from [Trofi's nix-guix-gentoo
16 overlay](https://github.com/trofi/nix-guix-gentoo)
17 
18 ## Aliases:
19 `nix-install <package>`: Add a package to the file (uses sed) and rebuild.
20 `nix-uninstall <package>`: Remove a package from the file (uses sed) and rebuild.
21 `nix-update`: Update and rebuild the system.
22 `nix-rebuild`: Rebuild the system but don't update.
23 `nix-develop`: Makes a nix dev shell for the system. Redundant when using flakey (default).
