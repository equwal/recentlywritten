Use sbmsync.com as the default server

The sbm-sync site moved from sbm.subread.space to sbmsync.com. New
sign-ins now use https://sbmsync.com. The README, the store description
and the Play Console notes name the new host and its privacy page.

Installs of 0.1.0 keep https://sbm.subread.space. That host keeps a
proxy for /api/, so these installs continue to sync.
