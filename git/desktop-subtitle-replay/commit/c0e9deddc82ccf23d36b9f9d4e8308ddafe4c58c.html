Restore session scrollback in the reader after a reload

Mining means going back to something said minutes ago, and a page refresh
previously threw the whole session away. The reader now replays this session's
lines from captions.log, which livecap marks with a session header on startup
so earlier sessions are not dragged in.

The log is written with CRLF, so splitting it on \n left a trailing carriage
return on every line. That broke de-duplication against the server's replay
buffer - the last few lines appeared twice - and, worse, put an invisible \r
inside the text Yomitan would mine. Split on /\r?\n/ and trim fields.
