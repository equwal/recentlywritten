5 Like [Hack](https://github.com/ryanoasis/nerd-fonts) fonts? Dislike
6 zeros with vertical strikes? Then this package is for you. Desktop (ttf)
7 and web (woff) fonts included.
8 
9 Generated with [alt-hack](https://github.com/source-foundry/alt-hack) glyphs,
10 and [the `generator.ros` Common Lisp script](https://github.com/equwal/alt-hack/tree/generator.ros).
