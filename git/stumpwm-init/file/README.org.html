5 Custom stumpwm init. Should work out of the box without any configuration other
6 than adding
7 #+begin_src lisp
8 (stumpwm:load-module :stumpwm-init)
9 #+end_src
10 to your ~.stumpwmrc~ (although there is some [[*Optional Configuration][optional configuration]]!).
11 
12 * Features
13   - Key remappings for Okular (pdf viewer) if it is installed. The bindings are
14     a Spacemacs-like Emacs/vim mix (which you may not like).
15   - Include a few lightweight contrib modules.
16   - ~poison~ command to banish and turn off mouse (q)
17   - Call xterm with the =Hack= font.
18   - Use a package to keep the namespace clean, export symbols for [[*Optional Configuration][optional
19     configuration]].
20 * Optional Configuration
21 ** xterm
22 Install the =Hack= font, or add your own to =stumpwm-init:*xterm-font*=.
23 #+begin_src common-lisp
24 (setf stumpwm-init:*xterm-font* "Hack"
25       stumpwm-init:*xterm-font-pt* 12)
26 #+end_src
27 ** deftermcom
28 Write commands which will be run and opened in the terminal. Useful for curses
29 programs.
30 #+begin_src common-lisp
31 (stumpwm-init:deftermcom nmtui "-e nmtui" xterm)
32 #+end_src
33 ** poison
34 Find your mouse's name with ~xinput --list~, and set it to
35 ~stumpwm-init:*my-mouse*~. Turns the mouse all the way off using ~xinput~.
36 ** app-menu
37 Add programs to the app menu (bound to =M-`= by default) using ~pushnew-apps~.
38 This keeps them sorted alphabetically. Any programs in ~stumpwm-init:*app-menu*~
39 need to be installed to work:
40 - emacs
41 - web browser
42 Example:
43 #+begin_src common-lisp
44 (stumpwm-init:pushnew-apps '("eclipse" "eclipse")
45                            '("spotify" "spotify")
46                            '("gimp" "gimp")
47                            '("office" "openoffice")
48                            '("pass"
49                              ("copy" pass:pass-copy-menu)
50                              ("generate" pass:pass-generate))
51                            '("PDF" "okular")
52                            '("sound" "pavucontrol"))
53 #+end_src
54 * Keybindings
55   Most can be found under the prefix (bound to =C-i=), but =M-`= (no prefix) is the app-menu.
