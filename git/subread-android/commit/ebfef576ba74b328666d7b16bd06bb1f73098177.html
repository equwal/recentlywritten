Make the F-Droid recipe pass the fdroidserver scanner

The build job of fdroiddata MR 49668 failed. The scanner counts 17
problems in the source tree: the Whisper model in the assets, a ZIP
test fixture, the test models of whisper.cpp, and Maven URLs in the
Java bindings of whisper.cpp.

The recipe now deletes the parts of whisper.cpp that the build does
not use (bindings, examples, models) and the test archive, and
ignores the speech model. MaintainerNotes explains the model.
Categories are in the order that fdroid rewritemeta writes.

Checked with fdroidserver 3.x scan_source on a clean checkout of
v0.9.1: 17 problems with the old recipe, 0 with this one, and
rewritemeta makes no change.
