equwal <truex@equwal.com>

Remove the recent-apps switcher

The switcher does not belong to this product. This change deletes its
activity, quick-settings tile, launcher alias, setting, string and icon,
and the usage-access permission and package queries it needed. The app
now asks for no permission.

The cancel code from the native bridge is now 1000. whisper_full uses
small negative numbers for its own errors, and -1 could be read as a
cancel. Job.cancel logs its caller: two device test runs stopped with
no visible cause while a second tool drove the same tablet, and the
log will show the source if it occurs again.
