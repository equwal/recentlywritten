Link the speech library without a build ID, and set the version to 0.9.3

The F-Droid build of 0.9.2 differed from the signed APK only in the 20 bytes of the GNU build ID of libsubread_whisper.so. The linker makes the ID from the debug information, and that holds the build folder of Gradle (.cxx/<hash>), whose name depends on the CMake arguments of each machine. Without the ID, the stripped library is the same everywhere.
