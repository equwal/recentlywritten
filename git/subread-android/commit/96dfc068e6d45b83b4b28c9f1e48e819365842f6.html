Test the five languages against the reference aligner

SubRead is checked for English, Portuguese, Spanish, Russian and Japanese.
Only Japanese had a golden fixture, so a defect in another language was not
found by a test.

Add tools/make_synthetic_golden.py. It makes a fixture for a language that
has no recorded transcript: it cuts a public-domain text into segments of the
size Whisper makes, adds the errors a small speech model makes, and runs the
reference implementation on the result. The transcript is deterministic.

Add a fixture for English, Portuguese, Spanish and Russian. The same file
goes to subplz-web, so the Kotlin engine and the browser engine are checked
against the same reference output.

The anchored aligner must now score 0.99 of the exact aligner at the
production block size, not 0.999. A small alphabet gives more paths with
almost the same score, so an anchor can move a gap a few characters. The
cues stay the same.
