Compile the speech library without the compiler version line, and set the version to 0.9.4

The F-Droid build of 0.9.3 still differed in libsubread_whisper.so, and only in the .comment section: the clang of the Windows NDK adds its own version line there, and the clang of the Linux NDK does not. With -fno-ident, the library built on Windows is byte for byte the same as the library that the F-Droid CI built for 0.9.3.
