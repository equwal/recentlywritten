README (1300 bytes)

1 Keyboard layouts for Minimak 4, 8 and 12 on Linux
2 
3 See minimak.org for details.
4 
5 TTYs (with .map files) and graphical X keymaps (with .xkb) are supported.
6 
7     # In a TTY
8     $ sudo loadkeys minimak12.map
9     # In an X session
10     $ xkbcomp minimak12.xkb $DISPLAY
11 
12 Also a good idea to put these commands in /etc/profile and ~/.xinitrc
13 for setting at startup.
14 
15 Some extra layouts set Caps Lock to ESC, swap [] with (), rctrl as a "compose key", and flip punctuation and numbers.
16 
17 These are the supported layouts as of v1.0, feel free to submit <truex@equwal.com>.
