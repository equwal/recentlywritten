1 # My dmenu scripts
2 
3 [website](https://therealtruex.com/posts/dmenu-scripts-repo-released)
4 
5 [dmenu](https://tools.suckless.org/dmenu/) is a simple program with a
6 pretty selection window for X. These are my scripts for doing things
7 with that.
8 
9 - `dbc`: do `bc -l` on the input so you can do math
10 - `dbrowsel`: select a browser for the link in the clipboard to open
11 - `dcpupower`: select CPU throttling settings
12 - `dkeymap`: select a keymap
13 - `dintelbacklight`: select backlight with dmenu or wjt (a scroll wheel)
14 - `ddmenu`: use dmenu to select a dmenu script -- dception
15 - `dmenu_run/dsudo`: run programs, maybe from a keybind set with xbindkeys or a wm
16 - `dmenupass`: ask for the sudo password as SUDO_ASKPASS
17 - `dmount/dunmount`: mount/unmount drives
18 - `dopenrc-runlevel`: choose openrc runlevels for various advanced tasks like networking
19 - `drssadd`: add RSS links to the newsboat config from clipboad
20 - `dshow`:  run a command and show output without having to open a terminal
21 - `dsysact`: reboot/shutdown/etc.
22 - `dtimer`: a coffee timer. Check out [uniformativ.de](https://www.uninformativ.de/git/countty/file/README.html)'s countty for a non-dmenu one.
23 - `dtmpl`: copy template files from a directory into the clipboard
24 - `passmenu`: unix [`pass`](https://www.passwordstore.org/) interface, copies to clipboard.
25 - `passmenu-otp`: like passmenu but copies the OTP code to clipboard.
26 - `y-or-n`: ask if yes or no
27 
28 ## Submodules with even more scripts
29 
30 - [dmodurl](https://github.com/equwal/dmodurl): change a URL in the clipboard according to sed rules
31 - [dpatchmail](https://github.com/equwal/dpatchmail): do (code) patches with dmenu
32 - [dsad](https://github.com/equwal/dsad): manage background audio with Simple Audio Daemon
33 - [prompt-mail](https://github.com/equwal/prompt-mail): manage your email contacts list (neomutt compatible)
34 - [sbm](https://github.com/equwal/sbm): manage your bookmarks list
35 - [tnon](https://github.com/equwal/tnot): like tmux but not (using mtm and abduco)

37 ## Quick hack for dmenu with sudo
38 
39 You *could* do:
40 ```
41 alias program='SUDO_ASKPASS=dgivepass sudo -A program'
42 ```
43 
44 but it won't come up in dmenu_run. So move `program` to `program-aux` and make a new script at program:
45 ```
46 #!/bin/sh
47 SUDO_ASKPASS=dgivepass sudo -A program
48 ```
