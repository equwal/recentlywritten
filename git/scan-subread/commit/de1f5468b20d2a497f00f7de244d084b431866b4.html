Follow the audiobook through the SubRead suite

The reader reads every page of a PDF as it opens: the text layer first, else OCR, the current page and its neighbors before the rest, with the tokens cached. The cues are aligned again as pages finish. The clock of the player drives the follower: highlight and turn pages, turn pages only, or off. A tap on a word sends the text to the dictionary app and pauses the player until the dictionary closes. On Android the menu asks SubRead to make the subtitles from the audiobook and the book text, keeps the result for the PDF, and shares it as a file. The web keeps an audio element as its clock.

The README describes the new scope. The LICENSE file holds the AGPL-3.0 text, the same as the other members of the suite.

+  the page, and the page turns when the cue is on another page.

+### Text layer or OCR
+
+The app reads the text layer of a page first. When the page has fewer
+than 10 characters of text, it is a scan: the app renders the page and

+The status line says which one was used for each page.

+### Lookups
+
