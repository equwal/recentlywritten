Share the .srt with a clip, and find the debug build of SubRead Anki

On the phone "Share the .srt" logged a SecurityException: the chooser
read the file for its preview without a grant. shareText now puts the
Uri in the clip of the intent. createChooser gives that clip, with the
read grant, to the chooser.

The phone had only the debug build of SubRead Anki
(space.subread.anki.debug), and ankiAdd answered not_installed in
16 ms. ankiAdd and suite now try the release build, then the debug
build, the same as the two authorities of the overlay. The manifest
queries hold the debug package, else Android hides it.
firstInstalled picks the package, and a JVM test covers it.
