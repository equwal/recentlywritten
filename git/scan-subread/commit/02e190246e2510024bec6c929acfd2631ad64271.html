Do not let late meta data undo a change of the user

The meta data of a book can come many seconds after the open: getMeta
waits behind the database upgrade. Two changes of the user were lost:

- The user opens B and ticks Force OCR before the meta data of B comes.
  applyMeta then set Force OCR back and started the reading again
  without it, while the store said on.
- The user opens B. Page 1 shows, and a save of page 1 waits. The user
  opens C before the meta data of B comes: the save of page 1 went over
  the saved page of B, and the meta data of B never applied.

state.changed now notes a page turn (by the user or by the follow) and
a change of Force OCR after the open. lateMeta (book-open.ts) gives the
fields of the meta data that apply: each field that did not change.
The first page of an open is the saved page or a placeholder, and the
page of the meta data is the saved page, so showPage does not save
them. Only a page turn saves the page.
