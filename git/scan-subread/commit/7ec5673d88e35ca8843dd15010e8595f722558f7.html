Load pdf.js and tesseract.js when the app needs them

The new UI modules made the main chunk 503 kB, and the build warned
about a chunk over 500 kB. pdf.js now loads with the first PDF, and
tesseract.js with the first page that needs OCR. The main chunk is now
53 kB and the pdf.js chunk 432 kB, so the build gives no warning, and
the start card shows before the browser parses pdf.js.
