Fit the top bar to a phone, and show a start card

At 360 CSS pixels the top bar was wider than the screen, and the page
scrolled sideways. The bar now has small icon buttons with a label and
a title on each: menu, previous page, the page label, next page, play or
pause, and "move the audio to this page".

With no PDF, the viewer shows a start card: the app name, what the app
does, an "Open a PDF" button that opens the file field of the menu, a
line about the subtitles, and an empty #suite-checklist for a later
change. The arrows and the page label are disabled with no PDF, the
previous arrow on the first page and the next arrow on the last page.
The strip hides the player until a PDF is open, and an empty strip
takes no space.
