Upgrade the page cache database and make the cache optional

Earlier builds of the app made version 1 of the "scan-subread" database with the stores "dictionaries" and "terms". An install over such a build keeps the WebView data, so the upgrade did not run and each PDF open failed with NotFoundError. The cache now opens version 2. The upgrade makes each store that is missing and deletes the two old stores.

When IndexedDB fails, a cache read now finds nothing and a cache write does nothing. One warning goes to the console. The reader continues without the cache.

The tests use fake-indexeddb, an in-memory IndexedDB for Node. Node has no IndexedDB.
