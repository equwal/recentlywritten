Do not watch android/ in the dev server

The dev server watched android/. "cap sync" writes the web build into android/app/src/main/assets/public, so the dev server reloaded the open app. Then it stopped with "Error: UNKNOWN: unknown error, lstat '...\android\app\src\main\assets\public\assets'". The watch now ignores android/.
