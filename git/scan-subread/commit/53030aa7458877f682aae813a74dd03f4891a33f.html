Put no space around ー and the other shared kana marks

The CJK test used the Script property. The Script of ー (U+30FC) is Common, so joinWords put a space around it when OCR gave it a word of its own. The lookup text and the book text for SubRead had "ニャ ー 泣いていた". The test now uses Script_Extensions, which also include ・, ゛, ゜, 々 and 〆. The CJK punctuation ranges stay.

joinWords also read the last UTF-16 unit of the previous word. For a character outside the BMP, that unit is half of a surrogate pair and failed the CJK test. It now reads the last code point.

book-text.ts exports the test as isCjk, for the lookup.
