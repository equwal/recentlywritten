Hide the elements that have the hidden attribute

Rules such as "#make, #audio-row { display: flex }" and ".row { display: flex }" won over the "[hidden] { display: none }" rule of the browser. On Android the drawer showed "Audio (web only)" with a file field and a player that did nothing. The first run showed a "Download the .srt" text that did nothing. On the web the drawer showed "Make subtitles with SubRead", which did nothing. A "[hidden] { display: none !important; }" rule near the top of style.css now keeps these elements hidden.
