Go on after a page that OCR cannot read, and keep Force OCR per book

- The reading ended with an unhandled rejection when OCR could not
  start, and the progress stayed in the strip: the stop did
  `await (await started).terminate()`. stopOcr stops a started OCR and
  ignores a start that failed.
- When OCR cannot start, the strip says "OCR could not start. The first
  OCR run needs a network connection to download the language data."
  with Retry. OCR starts before the render, so no page renders for
  nothing.
- One page that fails no longer stops the other pages. The reading
  counts it and goes on, and at the end the strip says "N pages could
  not be read." with Retry. Retry reads only the pages that are not
  read.
- A new reading (another OCR language, Force OCR, another book) stops
  the OCR of the reading before at once. Two quick changes of a setting
  ran two OCR jobs at the same time. tesseract.js does not settle a
  page when its worker stops, so a page of a stopped OCR now rejects.
- Force OCR is a setting of the book, in its meta data. As a global
  setting it sent each later text PDF through the slow OCR. The
  checkbox shows the setting of the open book, and the strip says
  "Force OCR is on" while it is on.
- "Clear the page cache" removed the OCR work of all books with no
  question. "Clear this book's pages" and "Clear all pages" ask first.

The strip shows a button after a message (fill, onAction). OcrStartError
moves to ocr-job.ts, so main.ts can use it without tesseract.js in its
chunk.

+import { afterEach, describe, expect, it, vi } from 'vitest';
+import { OcrStartError, stopOcr } from '../src/ocr-job';
+
+/** The reasons of the unhandled rejections while `run` runs, and 20 ms after it. */
+async function unhandledDuring(run: () => void): Promise<unknown[]> {
+  const reasons: unknown[] = [];
+  const record = (reason: unknown): void => {
+    reasons.push(reason);
+  };
+  process.on('unhandledRejection', record);
+  try {
+    run();
+    await new Promise((resolve) => setTimeout(resolve, 20));
+  } finally {
+    process.off('unhandledRejection', record);
+  }
+  return reasons;
+}
+
+describe('stopOcr', () => {
+  afterEach(() => vi.restoreAllMocks());
+
+  it('stops the OCR that started', async () => {
+    const terminate = vi.fn(() => Promise.resolve());
+    stopOcr(Promise.resolve({ terminate }));
+    await new Promise((resolve) => setTimeout(resolve, 0));
+    expect(terminate).toHaveBeenCalledTimes(1);
+  });
+
+  it('does nothing when no OCR started', () => {
+    expect(() => stopOcr(undefined)).not.toThrow();
+  });
+
+  it('gives no unhandled rejection when the OCR could not start', async () => {
+    // The web finding: the reading ended with an unhandled rejection, and the
+    // progress stayed in the strip.
+    const failed = Promise.reject(new OcrStartError('TypeError: Failed to fetch'));
+    expect(await unhandledDuring(() => void stopOcr(failed))).toEqual([]);
+  });
+
+  it('gives no unhandled rejection when the stop fails', async () => {
+    const terminate = vi.fn(() => Promise.reject(new Error('The worker is gone.')));
+    expect(await unhandledDuring(() => void stopOcr(Promise.resolve({ terminate })))).toEqual([]);
+  });
+});
