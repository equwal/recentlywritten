The README now tells:

- The worker and the core of tesseract.js are in the app. Only the
  language data comes from jsDelivr, on the first OCR run of a language.
- What IndexedDB keeps: the pages, the copy of the last book, and the
  meta data of each book. The restore at start, and the subtitles of
  each book.
- Back, the rule of the screen, and the SubRead suite checklist.
- The long press for an Anki card.
- Force OCR per book, the two clear buttons, the per-page errors with
  Retry, and the checks before a SubRead result loads.
- The plugin methods, the new modules and the dependencies
  @capacitor/app, tesseract.js-core and fake-indexeddb.
