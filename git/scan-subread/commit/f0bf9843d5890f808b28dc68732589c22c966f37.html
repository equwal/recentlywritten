Keep one aligner for each subtitle file

The reader now makes the aligner when it loads the subtitles, and gives
it the tokens of each page. The aligner keeps the result of each page,
so an alignment after a new page costs the work of that page only.

The tokens of a new page now go into their place in the token list.
Before, the reader joined the tokens of all read pages again after each
page.
