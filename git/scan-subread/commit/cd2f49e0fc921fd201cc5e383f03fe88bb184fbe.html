Add the Capacitor App plugin

@capacitor/app 8.1.1 goes with @capacitor/core 8.5.2. It gives the
Android back button, the app state (active or not active) and the
minimize of the app, so the reader needs no native code of its own for
them. The next change of main.ts uses it.

cap sync adds the module :capacitor-app to capacitor.settings.gradle
and to app/capacitor.build.gradle, with the relative node_modules path.
