Keep the last book, its page and its subtitles in IndexedDB

A reload or an app restart forgot the book, the page and the
subtitles. On Android the system stops the reader while the user is in
the dictionary or in the player app, so the user came back to an empty
reader.

Version 3 of the database adds two stores:

- "books" keeps a copy of the last book under the key "last".
  putLastBook replaces it and gives false when IndexedDB fails, for
  example when the quota is full. getLastBook gives the file.
- "meta" keeps, for each book key, the page, the subtitles and the
  "Force OCR" setting. putMeta merges a patch in one transaction, and a
  field that is undefined in the patch is removed.

The upgrade moves each text of the "srt" store to meta.subtitles, with
the source "subread" and the name of the book with ".srt", and deletes
"srt". The upgrade still deletes the stores of the old dictionary.

clearPages(key) removes only the pages of that book. getSrt and putSrt
stay as thin wrappers over the meta store, because main.ts still uses
them. The next change of main.ts removes them.

+export async function putMeta(key: string, patch: Partial<BookMeta>): Promise<void> {
+  await tryDb((d) => {
+    // One transaction reads and writes, so two merges at the same time keep
+    // the fields of both.
+    const tx = d.transaction('meta', 'readwrite');
+    const merge = async (): Promise<void> => {
+      const meta: BookMeta = { ...(await tx.store.get(key)), ...patch };
