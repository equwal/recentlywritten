Make a card in SubRead Anki from the plugin

The new plugin method ankiAdd starts space.subread.anki.action.ADD for
a result. It sends the word, the reading, the sentence, the text and
the source as string extras, and show as a boolean extra, only when the
caller gives them. SubRead Anki needs a word or a text, so the call
rejects without both.

RESULT_OK resolves added true with the note id. A cancel resolves added
false. ReturnWatch decides when SubRead Anki is closed, the same as for
a lookup. Without SubRead Anki, and on the web, the call resolves the
error not_installed. The manifest now queries the SubRead Anki package.
