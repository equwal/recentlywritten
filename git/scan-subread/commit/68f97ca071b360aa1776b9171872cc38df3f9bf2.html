Grow the side padding of the mark with the line height

On the phone the mark ended inside the last letter of a scan line. The
view padded each box by 2 CSS pixels. On a phone of 360 CSS pixels that
is 9 page pixels, and the phone test measured tesseract symbol boxes
that end 10 to 18 page pixels before the ink.

padBox now pads the left and the right side by a quarter of the line
height when that is more than the padding: 14 page pixels for a line
box of 56 pixels. A quarter of the line height is about the width of a
word space, so the box does not reach the next word. lineBoxes gives
the boxes without padding, and main.ts pads them with padBox.

+/**
+ * `box` with `pad` pixels on each side. The left and the right side get
+ * SIDE_PAD of the height of the box when that is more.

+export function padBox(box: Box, pad: number): Box {
+  const side = Math.max(pad, SIDE_PAD * (box.y1 - box.y0));
+  return { x0: box.x0 - side, y0: box.y0 - pad, x1: box.x1 + side, y1: box.y1 + pad };
