Make a tap on the page work like a finger

The tap tolerance was 1.5% of the page width, about 6 CSS pixels on a
phone. It is now 24 CSS pixels, converted to page pixels with the
displayed size of the page and the pinch zoom.

A tap on punctuation only sends nothing. A tap on a page that is not
read yet tells how many pages are read. When the pause before a lookup
fails, the lookup still runs, and the player plays again only when this
app paused it.

The web has no dictionary app, so the web copies the text to the
clipboard itself and shows "Copied" or "Copy failed" in the strip. It
does not pause. The Dictionary and "Pause on lookup" settings show only
on Android.
