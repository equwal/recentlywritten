Stop the OCR worker when its start fails

When the language data does not load, tesseract.js gives the error to
errorHandler, and its start promise does not settle: src/createWorker.js
rejects that promise only when the core does not load, and the start
chain ends in .catch(() => {}). An earlier change let the error reject
the start, but the Web Worker stayed, with the WebAssembly core in its
memory. tesseract.js gives the worker to the app only after the start,
so the app could not stop it. Each Retry, book open or setting change
then left one more worker, for as long as the data did not load.

startWorker (ocr.ts) now keeps the Web Worker that createWorker makes:
createWorker makes it in the synchronous part of the call, so during
the call a Worker class that keeps each new worker stands in for the
class of the browser. When the start fails, the app stops that worker.
An error after the start belongs to a page, and OcrJob handles it.

A Retry still starts a new worker, so OCR starts when the network comes
back. A check of the language data before the start was not used: the
URL of the data is internal to tesseract.js and is not one path for
"jpn+eng", and a failed or stalled start still left its worker.

+/**
+ * Runs `create`, and gives its result and the Web Worker that it made, if
+ * any. createWorker of tesseract.js makes its Web Worker in the synchronous
+ * part of the call (src/createWorker.js calls spawnWorker before it
+ * returns). So during the call, a Worker class that keeps each new worker
+ * stands in for the Worker class of the browser. The class of the browser
+ * comes back before any other code runs.
+ */
+function spawnedBy<T>(create: () => T): { result: T; worker: Worker | undefined } {
+  const Native = globalThis.Worker;
+  // Node has no Worker: tesseract.js uses worker_threads there.
+  if (typeof Native !== 'function') return { result: create(), worker: undefined };
+  let worker: Worker | undefined;
+  globalThis.Worker = class extends Native {
+    constructor(url: string | URL, options?: WorkerOptions) {
+      super(url, options);
+      worker = this;
+    }
+  };
+  try {
+    const result = create();
+    return { result, worker };
+  } finally {
+    globalThis.Worker = Native;
+  }
