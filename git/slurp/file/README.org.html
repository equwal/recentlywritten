10 * Description
11 To slurp is the quest of many an Emacser. While vim has the =:r= and =:r!=,
12 emacs has other slurping tools, allowing for prepending, appending, inserting, and copying =buffers= too!
13 
14 * Key bindings
15 
16 =SPC i[nsert] b[uffer]= is the intended mnemonic.
17 
18 | Key Binding | Description                             |
19 |-------------+-----------------------------------------|
20 | ~SPC i b <~ | prepend-to-buffer                       |
21 | ~SPC i b >~ | append-to-buffer                        |
22 | ~SPC i b i~ | insert-[another buffer into this]buffer |
23 | ~SPC i b c~ | copy-buffer                             |
24 | ~SPC i b f~ | amend-to-file                           |
25 
26 
27 * Install
28 To use this configuration layer, add it to your =~/.spacemacs=. You will need to
29 add =slurp= to the existing =dotspacemacs-configuration-layers= list in this
30 file.
