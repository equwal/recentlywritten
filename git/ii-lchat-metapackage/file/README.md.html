8 
9 Just the bare minimum of POSIX shell scripts to be usable.
10 
11 # INSTALL
12 
13 - Go install ii with the SSL patch added. This will run as a local server that makes files named in and out for lchat to
14 use.
15 - Go install lchat. It uses the suckless library grapheme that you will need to install and link up.
16 - Go to services and edit/install the file. You will need to register
17 with nickserv on liberachat. Install it on your machine. If you are
18 using a service that isn't in there, or you find it doesn't work,
19 please contribute.
20 - copy filter/indent to the folder you will have the irc at as .filter if you want that one. To just remove messages
21   that match a pattern (eg. join messages) check out that script. Use both for a very clean experience.
22 
23 Copy irc-connect, lchat-connect, and lc to your path. Modify as needed.
24 
25 ```
26 # connect to a channel
27 lc commonlisp
28 beach: the sicl compiler bootstraps itself
29 > (you type)
30 ```
