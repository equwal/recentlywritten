1 # How to submit Ink Recents to F-Droid
2 
3 1. The release tag exists already: `v0.1.1`. For a later version, tag it and push the tag.
4 2. Fork `fdroid/fdroiddata` on GitLab, then clone your fork.
5 3. Copy `dev.equwal.inkrecents.yml` into `metadata/` of your clone.
6 4. Run `fdroid readmeta` and `fdroid lint dev.equwal.inkrecents` to check it.
7 5. Commit on a new branch and push it to your fork.
8 6. Open a merge request against `fdroid/fdroiddata`.
