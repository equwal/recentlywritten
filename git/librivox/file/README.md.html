1 # Purpose
2 Downloads audiobooks and images from [librivox](librivox.org), then makes a video and uploads it to youtube.
3 # Requirements:
4 Foreign command line applications:
5 `mp3info`
6 `ffmpeg`
7 `bash`

9 `Quicklisp`
10 `The LATEST CL+SSL, from the source repo. Quicklisp might not work.`
11 If CL+SSL doesn't work,
12 `curl`
13 command line application can be used as a workaround.
14 
15 A google console secret must be added to `src/client_secrets.json`
