6 # Skill Finder
7 
8 You have access to the `skillfish` CLI, which allows you to install and manage AI agent skills from GitHub repositories. Use it whenever the user asks for a capability you don't have, or if you need a specific tool.
9 
10 ## Usage
11 
12 You can run `npx --yes skillfish <command>` via your terminal execution tools.
13 
14 Commands:
15 - `search <query>`: Search for skills in the registry.
16 - `add <owner/repo> [skill-name]`: Install a skill from a GitHub repository. If you don't know the specific skill name, run `npx --yes skillfish add <owner/repo>` to see the list of available skills in that repository.
17 - `list`: List installed skills across all detected agents.
18 - `remove [skill]`: Remove an installed skill.
19 - `update`: Check for and apply updates to installed skills.
20 
21 Whenever the user asks you to use skill finder or add a skill from skill.fish, use the commands above to find and install the requested capabilities.
