6 # Discord call transcripts
7 
8 CallScribe writes one Markdown file for each Discord call in `D:\CallScribe\transcripts`.
9 The file name is the start time of the call: `YYYY-MM-DD_HHMMSS.md`. The file with the
10 highest name is the latest call. To find it:
11 
12     Get-ChildItem D:\CallScribe\transcripts -Filter *.md | Sort-Object Name | Select-Object -Last 1
13 
14 Each line of speech has this form: `- [HH:MM:SS] Speaker: text`.
15 
16 - `Me` is the user's microphone.
17 - `Them` is the speaker that Discord plays to. It holds all the other people on the call,
18   and it does not tell them apart. It also holds other sound on that speaker, for example
19   a video.
20 
21 The file grows during the call. The line `Call ended HH:MM:SS.` shows that the call is
22 finished.
23 
24 Speech recognition makes mistakes, mostly with names and rare words. When one word is
25 important, tell the user that the word can be wrong.
26 
27 If a call has no transcript, read `watch.log` and `record.log` in `W:\src\callscribe`.
