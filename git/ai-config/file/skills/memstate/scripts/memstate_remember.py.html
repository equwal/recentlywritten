2 """Store a markdown summary (memstated).
3 
4 Two modes:
5 - explicit: pass --keypath to write the whole content at that path.
6 - extract:  omit --keypath; each `## heading` in the markdown becomes its
7             own keypath (deeper headings nest via dot segments). Use --root
8             to apply a common prefix to every extracted keypath.
9 
10 --scope user writes to the reserved user scope. Only sections that land at
11 preferences.* or profile.* pass the daemon's allowlist there; host facts
12 need an explicit --keypath host.<host_slug>.env.* or .tools.*. One bad
13 section rejects the whole call, nothing is written.
14 
15 Server response (both modes): { method, items: [{keypath, action, stored, superseded?}] }.
16 """
