6 # ccai-license
7 
8 `CCAI-1.0.txt` in this folder is the license text, byte-for-byte as jose gave it.
9 
10 1. Copy `CCAI-1.0.txt` to `LICENSE` in the project root. Copy the file; do not retype the text.
11 2. Replace `[year]` with the current year and `[author]` with `git config user.name`.
12 3. If a manifest has a license field, set it: npm `"SEE LICENSE IN LICENSE"`, Cargo `license-file = "LICENSE"`, pyproject `license = {file = "LICENSE"}`, other formats `LicenseRef-CCAI-1.0`.
13 4. Commit `LICENSE` (and the manifest change) in its own commit.
14 
15 Do not use it for a fork, a patch for an upstream project, client or employer work, or apps published on F-Droid or any store or distro that requires an OSI/FSF license. Those keep their owner's license or a plain FLOSS license with no CCAI.
