rules/no-bak.md (467 bytes)

1 ## MANDATORY: Git, not .bak files
2 
3 Never create `.bak`, `.orig`, `~`, or similar backup copies next to the file you edit.
4 
5 - Use git. Commit the file before you edit it, or check that it is already committed and clean.
6 - If the file is not in a git repo and you cannot put it in one, copy it into a new folder under the system temp directory: `mktemp -d` on Linux, `$env:TEMP` on Windows. Never put the backup in the file tree.
7 - Name the backup path in your report.
