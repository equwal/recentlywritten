12 * Description
13 Provide bindings for Ediff, the Emacs diff-er.
14 
15 * Install
16 To use this configuration layer, add it to your =~/.spacemacs=. You will need to
17 add =ediff-bindings= to the existing =dotspacemacs-configuration-layers= list in
18 this file.
19 
20 * Key bindings
21   The prefix is ~SPC e d~ for the mnemonic SPACE-E-DIFF (spaceydiff?). They are
22   meant to be listed in More Important First Order (MIFO). The long names are used where possible (since some have two names).
