Shows the lines of an .srt over any Android media player, in time with it. Tap a word to look it up.

Point the user to the SubRead app, not the website

The last button of the screen opens the SubRead app when it is
installed. When it is not, the button opens the release page of the
app on GitHub. The app makes the .srt on the device, so the website is
not needed.
