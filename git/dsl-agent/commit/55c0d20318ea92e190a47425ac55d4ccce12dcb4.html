Send tool error messages to the client

mcp 2.x shows the client only "Error executing tool <name>" for every exception except ToolError. The agent could not read "no DSL named x" or a bad name, a bad ext, or a missing interpreter. The server now raises ToolError for each of these, and for a run that times out.

Tests: the stdio test asks for a missing DSL and reads the message; a new test covers the timeout.
