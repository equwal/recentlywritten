Sync is free, and the home page can link to a pre-order of teams

Sync on sbm.subread.space is free. The README no longer gives a price
for it.

SBM_TEAMS_URL is the address of a page that pre-sells team bookmarks,
for example a Stripe Payment Link. When it is set, the home page tells
about teams and links to that page. The server refuses to start when
the value is not an http or https address.
