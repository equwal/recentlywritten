Default feeds for new accounts, and the daily email on by default

SBM_DEFAULT_FEEDS names the feeds that an account follows until it
unfollows them: an account without a feeds.txt has these, and its own
file counts as soon as it changes the list, also when the file is empty.
On sbmsync.com the default is the feed of recentlywritten.com.

The daily email is now on for every account that the server can send
email to. The account gave its address at sign-up. The setting is
NoMail, so the accounts from before this change get the email too. A
save of the settings without the email box, on a server that sends no
email, keeps the choice. The first run for an account still sends
nothing: it only notes the items of that day.
