Home and account pages: links to all payment pages

SBM_TEAMS_LARGE_URL pre-sells team bookmarks for 11 people or more. The
home page shows it next to SBM_TEAMS_URL. SBM_SUPPORT_URL is the page of
a supporter subscription. The home page and the account page link to
it. The server does not start when one of these values is not an http
or https address.

+// link gives the address in the environment variable name, or "". The
+// server does not start when the value is not an http or https address.
+func link(name string) string {
+	v := os.Getenv(name)
+	if u, err := url.Parse(v); v != "" && (err != nil || u.Host == "" || (u.Scheme != "https" && u.Scheme != "http")) {
+		log.Fatalf("%s: not an address: %q", name, v)
+	}
+	return v
+}
