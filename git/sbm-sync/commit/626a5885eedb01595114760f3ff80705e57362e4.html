Bookmarks page: remove the live preview

Most sites do not let a page of another site show them in a frame: they
send X-Frame-Options or a frame-ancestors policy. YouTube is one of them.
For these sites the frame of the preview stayed empty, so the preview did
not work for most bookmarks. The server cannot change this.

This reverts b3d3f70. Enter opens the first result again, and the policy
allows no frames. The new test TestNoFrames checks that the bookmarks
page has no frame and that the policy allows none.
