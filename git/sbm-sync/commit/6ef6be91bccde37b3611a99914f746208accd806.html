Fetch a feed without -z while its item file is empty

sfeed_update 1.7 touches the item file before the first fetch. With -z on
that empty file, curl skips the whole feed as not newer than the file, so
the first fetch of each feed gave no items. The fetch now uses -z only
when the item file has items in it.
