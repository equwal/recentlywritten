Report an error when no Wayland session can show bemenu

Over SSH on g, WAYLAND_DISPLAY is unset. bemenu then exits with code 1, the same code as Escape, so handoff.py told the agent that the user answered Not done. MenuDialog now refuses to start without WAYLAND_DISPLAY, and the agent gets status error. Release 0.6.1.
