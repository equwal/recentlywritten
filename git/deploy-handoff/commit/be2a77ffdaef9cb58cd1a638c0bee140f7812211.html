Open pull requests from a fork to its upstream repository

handoff.py pr --repo UPSTREAM_OWNER/NAME opened a form that compared a
branch of the upstream repository, not the branch of the fork. GitHub
needs OWNER:BRANCH for a branch in another repository. pr_request now
adds the owner of the remote when --repo names another repository.
compare_url keeps the ":" of OWNER:BRANCH. find_open_pr filters the
pull requests by the owner of the branch, because gh filters by the
branch name only.

The skill, the README, and the rule tell Claude to give --repo for a
pull request to the upstream project of a fork.
