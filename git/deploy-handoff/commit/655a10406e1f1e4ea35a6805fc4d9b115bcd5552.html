Keep the agent browser running when its window closes

The browser that "handoff.py browser" starts stopped when its last
window closed. On 2026-09-26 this occurred two times in one task. The
window of the agent browser looks like the other Brave windows on the
shared desktop, and a person or a program closed it. Then the agent got
"Failed to open a new tab" and "connect ECONNREFUSED 127.0.0.1:9333".

After each stop, the profile showed a normal exit and no crash report.
The end of the tool call did not stop the browser: a browser started
from Git Bash in a tool call ran for more than 11 minutes after the call
ended.

Start the browser with --no-startup-window. With this flag and a remote
debugging port, Chromium keeps the browser running with no window. The
agent opens a window when it opens a page.

The new test starts the real browser with a temporary profile and closes
all of its tabs. Then it makes sure that the browser still runs and can
open a new tab. The test fails without the flag. README tells how to
stop the browser, because a click on the close button no longer does.

+def free_port() -> int:
+    """Return a port on 127.0.0.1 that no program uses now."""
+    with socket.socket() as sock:
+        sock.bind(("127.0.0.1", 0))
+        port: int = sock.getsockname()[1]
+    return port

+def devtools(port: int, path: str, method: str = "GET") -> str:
+    """Send one HTTP request to the remote debugging port of a browser. Return the body."""
+    request = urllib.request.Request(f"http://127.0.0.1:{port}{path}", method=method)
+    with handoff.LOCAL_OPENER.open(request, timeout=10) as response:
+        body: bytes = response.read()
+    return body.decode()
