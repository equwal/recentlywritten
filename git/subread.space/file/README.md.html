1 Webpage that lets you read an SRT by pressing spacebar to see the next subtitle. Doesn't do anything else.

5 - kakiyomi https://github.com/rtr46/kikiyomi which requires adding the audiobook.
6 - a text hooker page
7 
8 Why do you want this:
9 - You want to use furigana or pitch accent markup in the browser so need the whole file loaded at once
10 - You want to use yomitan to lookup words
11 - You want to have subs despite your player not supporting subs very well
12 - You want a lightweight text viewer, not a multimedia player
13 - kakiyomi or asbplayer don't work well for you when loading local files
