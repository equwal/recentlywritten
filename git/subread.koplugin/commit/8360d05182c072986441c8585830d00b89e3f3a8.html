Keep the follow near the last found cue, add the mark style

A short cue can match the same words at another place of the book. When
the user turned pages ahead, the forward search found such a hit, the
lower limit moved there, and every cue after it was dropped. The follow
then froze. A hit is now dropped when it lies many pages after the
nearest cue already found. When no hit is found after the current page,
the whole book is read once from that cue. After two misses in a row the
page limit is dropped, so a subtitle file that skips a part of the book
still works. The miss backoff is capped at four cues. An error in the
follow step is logged and the next tick is still scheduled.

The controls get a "Mark" button that cycles the style of the mark:
Shade, Underline, Strikeout, Invert, None. The mark is drawn with
ReaderView:drawHighlightRect, the same as a highlight.
