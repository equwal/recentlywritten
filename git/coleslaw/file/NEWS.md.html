10 ## Changes for 0.9.7 (2014-11-25):
11 
12 * **New Plugin**: Support for [embedded gfycats](http://gfycat.com/)
13   has been added. See the [plugin use][plg-use] docs for further details.
14 * **Enhancement**: UTF-8 support has been made more portable and
15   added to the Wordpress import plugin. (Thanks @cmstrickland!)
16 * **Enhancement**: Filenames are now included in errors from the
17   content loader. (via @PuercoPop)
18 * **Enhancement**: Coleslaw now handles **deploy-dir**, **repo**,
19   and **staging-dir** config options more gracefully. Previously,
20   various errors could be encountered if directory options lacked
21   a trailing slash.
22 * Several portability fixes were made to CCL's encoding handling
23   and usage in the post-receive script.

25 * Some namespacing bugs in the Static Pages plugin have been fixed.

27 ## Changes for 0.9.6 (2014-09-27):
28 
29 * **SITE-BREAKING CHANGE**: Coleslaw now defaults to a "basic" deploy
30   instead of the previous symlinked, timestamped deploy strategy.
31   To retain the previous behavior, add `(versioned)` to your config's
32   `:plugins` list.
33 * **Incompatible Change**: Custom themes will be broken by a change
34   to URL handling. Previously, we were hand-constructing URLs in the
35   templates. All site objects now store their URL in an instance slot.
36   In general, hrefs should be of the form `<a href="{$config.domain}/{$obj.url}"> ...</a>`.
37 * **Incompatible Change**: The interface of the `add-injection` function
38   has changed. If you have written a plugin which uses `add-injection`
39   you should update it to conform to the [new interface][plg-api].
40 * **New Plugin**: Support for [twitter summary cards][ts-cards] on blog
41   posts has been added thanks to @PuercoPop.
42 * **Docs**: Improved README and Theming docs. New Config File docs.
43 * Changes to `:routing` would previously break links in the templates
44   but now work seamlessly due to the updated URL handling.
45 * Loading content is more robust when empty lines or metadata are passed.
46   Thanks to @PuercoPop for the bug report and preliminary fix.
47 * The config `:repo` option is now deprecated as its value has become
48   a required argument to `coleslaw:main`. The value passed to `main`
49   will override the config value going forward.
50 * Improved handling of directories and error-reporting when they
51   don't exist is available thanks to @PuercoPop.
52 * The templates are now HTML5 valid thanks to @Ferada.
53 * Fixed a bug where RSS/Atom tag feeds were being published multiple times.

55 ## Changes for 0.9.5 (2014-06-13):
56 
57 * **New Plugin**: Incremental builds, cutting runtime for generating
58   medium to large sites roughly in half!
59 * **New Plugin**: A Twitter plugin to tweet about your new posts. Thanks to @PuercoPop!

68 ## Changes for 0.9.4 (2014-05-05):
69 
70 * **SITE-BREAKING CHANGE**: Coleslaw now supports user-defined routing.
71   Instead of hard-coding the paths various content types are stored at,
72   they **must** be specified in the configuration file (.coleslawrc).
73   Just copy the `:routing` key from the [example][example.rc] to
74   get the old behavior.
75 * **SITE-BREAKING CHANGE**: Coleslaw's multi-site support has changed.
76   Instead of having a single .coleslawrc in the user's home directory
77   that has sections for multiple repos, a .coleslawrc may be included
78   *in* the blog repo itself. If no .coleslawrc is found in the repo,
79   it is loaded from the user's home directory instead.
80 * Coleslaw no longer expects a particular repo layout. Use whatever
81   directory hierarchy you like.
82 * New Content Type Plugin: Static Pages, accepting a title, url, and
83   optionally tags and a date. All files with a `.page` extension are
84   compiled as static pages and reuse the POST template.
85   To enable Static Pages, add `(static-pages)` to the `:plugins`
86   section of your config.
87 * Coleslaw now allows content without a date or tags. Note that POSTs
88   without a date will still show up in the reverse chronological
89   indexes at the very end.
90 * Fixed an embarrassing escaping bug in our last quicklisp release.
