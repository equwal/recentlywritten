1 # Deploying on a standalone server
2 
3 Coleslaw can deploy to a standalone server.
4 If you want this server installation, initialize a bare git repo and
5 set up the post-receive hook on that repo.
6 
7 * First initialize a [git bare repo](http://git-scm.com/book/en/Git-on-the-Server-Setting-Up-the-Server) on the server.
8 * Copy [example post-receive hook][post_hook] to your blog's bare repo and set the executable bit (`chmod +x`).
9 
10 * Point the web server at `:deploy-dir` attribute on the config file.
11   Or "deploy-dir/.curr" if the `versioned` plugin is enabled.
12 
13 [post_hook]: https://github.com/redline6561/coleslaw/blob/master/examples/example.post-receive
