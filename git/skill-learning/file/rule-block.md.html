2 ## Self-improvement: learn skills from experience
3 
4 At the end of each task, after it is verified and committed, run the
5 `skill-learning` skill check. If the task took about 5 or more tool calls, hit
6 errors before it worked, got a correction from the user, or showed that a
7 skill you used is wrong, then patch the matching skill or create a new one.
8 Copy it to the skills folders of the other AIs on this computer and commit.
9 Most tasks need no skill: skip silently when none of these is true.
10 <!-- skill-learning:end -->
