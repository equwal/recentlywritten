Build a separate zip for addons.mozilla.org

The linter of addons.mozilla.org warned that Firefox ignores
background.service_worker. Chrome needs that key, so one zip cannot
satisfy both stores. npm run build:firefox now makes
sbm_bookmarks-<version>-firefox.zip from a copy whose manifest.json
leaves the key out. npm run lint checks that copy, with no warnings.

The store texts get the version notes and the notes to the reviewer
for addons.mozilla.org.

+// Stages the package for addons.mozilla.org in build/firefox. Firefox
+// ignores background.service_worker, and the linter of addons.mozilla.org
+// warns about it, so the staged manifest.json leaves it out. Chrome needs
+// it, so manifest.json keeps it. "npm run build:firefox" builds the zip from
+// the staged copy.
+import { cpSync, readdirSync, readFileSync, rmSync, writeFileSync } from "node:fs";
+
+const out = "build/firefox";
+const skip = new Set(["build", "node_modules", "web-ext-artifacts", ".git"]);
+
+rmSync(out, { recursive: true, force: true });
+for (const name of readdirSync(".")) {
+  if (!skip.has(name)) cpSync(name, `${out}/${name}`, { recursive: true });
+}
+const manifest = JSON.parse(readFileSync(`${out}/manifest.json`, "utf8"));
+delete manifest.background.service_worker;
+writeFileSync(`${out}/manifest.json`, JSON.stringify(manifest, null, 2) + "\n");
