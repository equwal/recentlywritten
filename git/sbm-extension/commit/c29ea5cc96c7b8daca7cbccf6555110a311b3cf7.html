Popup: remove the live preview

Most sites do not let a page of another site show them in a frame: they
send X-Frame-Options or a frame-ancestors policy. YouTube is one of them.
For these sites the frame of the preview stayed empty, so the preview did
not work for most bookmarks. An add-on can change this only with access
to all sites, which is too much for a bookmark add-on.

This reverts c915c68. Enter opens the first match again, and the options
have no preview setting. The new test test/popup.test.js checks that the
popup has no frame.
