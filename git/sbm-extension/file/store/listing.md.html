9 ## Texts for both stores
10 
11 **Name:** sbm bookmarks
12 
13 **Summary** (132 characters or less):
14 Your sbm bookmarks in the browser: search as you type, add the page, sync with bm and the sbm app.
15 
16 **Description:**
17 
18 sbm keeps your bookmarks in one plain text file: one bookmark per line, with the address, a description and tags. This add-on brings that file to your browser.
19 
20 - Search as you type: press Alt+Shift+M or click the icon. The search is fuzzy, as in fzf. Enter opens the first match. Text that is no bookmark opens as an address, or as a web search.
21 - In the address bar, type bm, a space, then words.
22 - Add the page that you look at, with a description and tags.
23 - Sync with bm on your computers, the sbm app for Android and your other browsers, through an sbm-sync server. The server is free software: use the default one, sbm.subread.space (paid after a free trial), or run your own.
24 
25 Without an account, your bookmarks stay in the browser. The add-on has no ads, no analytics and no trackers.

37 ## Chrome Web Store (chrome.google.com/webstore/devconsole)
38 
39 - Category: Tools. Language: English.
40 - **Single purpose:** Search, add and sync the sbm bookmarks of the user.
41 - **Permission justifications:**
42   - storage: keeps the bookmarks of the user and the sign-in token in the browser.
43   - activeTab: reads the address and the title of the current page when the user clicks "Add this page".
44   - alarms: syncs the bookmarks every 30 minutes.
45   - Host permission sbm.subread.space: sends the bookmark file to the default sync server after the user signs in.
46   - Optional host permissions (https://\*/\*, http://\*/\*): the user can choose another sync server; at sign-in the add-on asks for that one site only.
47 - **Remote code:** No. All code is in the package.
48 - **Data usage:** the add-on collects, only after the user signs in:
49   personally identifiable information (the email address), authentication
50   information (the password, sent once to get a token) and web history (the
51   addresses of the bookmarks). Tick the three statements: not sold, not used
52   for purposes unrelated to the single purpose, not used for credit.
53 - Distribution: public, all regions. Free.
