3 Packages: `npm run build` makes `web-ext-artifacts/sbm_bookmarks-<version>.zip`
4 for the Chrome Web Store. `npm run build:firefox` makes
5 `web-ext-artifacts/sbm_bookmarks-<version>-firefox.zip` for
6 addons.mozilla.org. The two zips have the same files. Only the manifest.json
7 of the Firefox zip has no `background.service_worker`, which Firefox ignores
8 and warns about. Neither zip has a build step or minified code, so no

13 ## Texts for both stores
14 
15 **Name:** sbm bookmarks
16 
17 **Summary** (132 characters or less):
18 Your sbm bookmarks in the browser: search as you type, add the page, sync with bm and the sbm app.
19 
20 **Description:**
21 
22 sbm keeps your bookmarks in one plain text file: one bookmark per line, with the address, a description and tags. This add-on brings that file to your browser.
23 
24 - Search as you type: press Alt+Shift+M or click the icon. The search is fuzzy, as in fzf. Enter opens the first match. Text that is no bookmark opens as an address, or as a web search.
25 - In the address bar, type bm, a space, then words.
26 - Add the page that you look at, with a description and tags.
27 - Sync with bm on your computers, the sbm app for Android and your other browsers, through an sbm-sync server. The server is free software: use the default one, sbmsync.com, or run your own. Sync on sbmsync.com is free.
28 - The options page shows the plan of your account and the paid options of the server, such as a supporter subscription. Stripe takes all payments on its own pages. The add-on never sees your card.
29 
30 Without an account, your bookmarks stay in the browser. The add-on has no ads, no analytics and no trackers.
31 
32 The operator of sbmsync.com sells its paid options, not Google or Mozilla. Terms of sale, with the refund policy: https://sbmsync.com/terms

46 ## Chrome Web Store (chrome.google.com/webstore/devconsole)
47 
48 - Category: Tools. Language: English.
49 - **Single purpose:** Search, add and sync the sbm bookmarks of the user.
50 - **Permission justifications:**
51   - storage: keeps the bookmarks of the user and the sign-in token in the browser.
52   - activeTab: reads the address and the title of the current page when the user clicks "Add this page".
53   - alarms: syncs the bookmarks every 30 minutes.
54   - Host permissions sbmsync.com and sbm.subread.space (the old address of the same server): send the bookmark file to the default sync server after the user signs in.
55   - Optional host permissions (https://\*/\*, http://\*/\*): the user can choose another sync server; at sign-in the add-on asks for that one site only.
56 - **Remote code:** No. All code is in the package.
57 - **Data usage:** the add-on collects, only after the user signs in:
58   personally identifiable information (the email address), authentication
59   information (the password, sent once to get a token) and web history (the
60   addresses of the bookmarks). Tick the three statements: not sold, not used
61   for purposes unrelated to the single purpose, not used for credit.
62 - Distribution: public, all regions. Free. If the Distribution tab has the
63   option "Contains in-app purchases", tick it: the options page leads to
64   Stripe subscriptions of the server.
