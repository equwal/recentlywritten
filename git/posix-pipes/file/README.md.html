1 # posix-pipes
2 
3 Portably run a command with input/output to/from CL.
4 
5 From [Newport](https://github.com/Sharp-CLOCC/Newport) which is the Sharp-CLOCC's maintenance of [CLOCC's port module](https://clocc.sourceforge.net/dist/port.html)
6 
7 # Includes free pipes
8 
9 ```
10 posix-pipes:pipe-output
11 posix-pipes:pipe-input
12 posix-pipes:with-open-pipe
13 posix-pipes:close-pipe
14 ```
