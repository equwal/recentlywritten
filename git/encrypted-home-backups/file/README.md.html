1 # Automatic Daily Encrypted /home Backups
2 
3 # Install
4 Encrypt and install filesystems on the backup disk.
5 
6 ``` shell
7 # lsblk
8 # parted /dev/sdb
9 > mktable
10 > mkpart
11 # cryptsetup luksFormat /dev/sdb1
12 # cryptsetup luksOpen /dev/sdb1 sdb1
13 # mkdir /mnt/sdb1
14 # mount /dev/mapper/sdb1 /mnt/sdb1
15 # mkfs.ext4 /mnt/sdb1
16 # umount /dev/mapper/sdb1
17 ```
18 
19 Modify the user-data bash file (`backup`) to fit your keyfile, UUID, username,
20 and mount folder.
21 
22 Keyfile should just be a plaintext file with the password for the disk.
23 
24 Get the uuid with `# blkid` on the partition.
25 
26 Username is for the folder to backup under `/home`.
27 
28 Mount folder cannot be in the `/home/username` and must exist: `# mkdir /mnt`.
29 
30 Install it
31 
32 `root # ./install`
33 
34 Run it for the first backup and to verify install to /usr/bin.
35 
36 `root # backup`
37 
38 Or, if you have cron installed, it will install itself in cron.daily for fully
39 automated daily encrypted backup.
