23 ## 0.1.0-beta - 2026-09-21
24 
25 Version code 16. The first beta. The alpha versions end here.
26 
27 - **Updates: Ink Update.** Rebind has no internet permission, so it cannot
28   look for a new version. Ink Update, an open source app of its own, does
29   that: F-Droid first, then Google Play (it leaves an app that Google Play
30   installed to Google Play), then GitHub. It makes a notification and opens
31   the page. Setup has an "Updates" row that installs or opens it. The build
32   for direct install carries it.
33 - The build for direct install carries Ink Dim too. Hardware hacks lists it.
34 - The lists of carried apps are named "Extensions".
35 
36 - **Settings are safe across versions and across an uninstall.** An update
37   always kept the settings: they are in the data of the app. An uninstall
38   removed them. Now Android asks at uninstall whether to keep the data
39   (`hasFragileUserData`), and Rebind keeps an automatic copy of the settings in
40   `Documents/Rebind/rebind-settings.json`, which an uninstall does not touch.
41   Import opens that folder. `StoredFormatTest` holds the texts that every
42   0.0.x version stored, so a new version cannot stop reading them unseen.

75   "Default digital assistant app".

104   microphone grant. Before, those places showed a short message or nothing.

106   system does not call `onBackPressed` for an app with this target version.

308 ## 0.0.4-alpha - 2026-09-20
309 
310 Version code 4.
311 
312 - **Voice typing.** A new action. Press the key, speak, and the words go where
313   the cursor is. The app has no speech engine: it uses the Android
314   SpeechRecognizer interface, so any speech recognition app on the device does
315   the listening. The accessibility service puts the text into the focused
316   field. Password fields are never written to.
317 - **Two builds.** `play` for Google Play has no Shizuku code and no Shizuku
318   permission. `full` for direct install keeps shell access. Same app id and
319   signature, so one can replace the other.
320 - **Viwoods: AI key goes back.** Inside the AI screen or the crop screen, the AI
321   key returns to the app that was in use before. Switch on the AI key screen.
322   Test: `tools/e2e/ai-key-return.sh`.
323 - **Fix: Power always wakes and unlocks.** While the app manages the Power
324   button, a press on a sleeping or locked device is never a gesture. The app
325   also sends the wake and the keyguard dismissal through the shell, so waking
326   does not depend on the firmware. Regression test: `tools/e2e/power-wake.sh`.
327 
328 Known limits:
329 
330 - Voice typing needs a speech recognition app that has its own microphone
331   permission. The Viwoods voice prompt cannot be used: it sends audio to the
332   Viwoods cloud and has no interface for other apps.
333 - The listening screen pauses the app behind it for a moment. An app that
334   clears its text field on resume loses what was typed before.

340 - **Shell access** through Shizuku, set up on the device over wireless

391 ## 0.0.1-alpha — 2026-09-20
392 
393 First alpha. Version code 1.
394 
395 - Remaps the AI key and both volume keys through an accessibility key filter:
396   1–5 taps, press-and-hold, and key combinations, each bound separately.
397 - Remaps Power: hold (as the digital assistant), double press (as the default
398   camera app), and the firmware short-press behaviour.
399 - Actions: Viwoods AI screens, navigation, page-turn swipes and scrolls,
400   volume and media, open an app or component, send an intent or broadcast.
401 - Licensing through Google Play Billing: licensed, beta, 7-day trial, locked.
402   The beta is opened and closed from Play Console; testers get a lower price.
403 - In-app accessibility disclosure with explicit consent.
404 - Key tester, and a read-only view of the firmware's own key hooks.
405 - No `INTERNET` permission.
406 
407 Known limits:
408 
409 - Purchases are untested: Play Billing cannot be exercised until the app exists
410   in Play Console. Everything up to the purchase sheet is tested on the device.
411 - A volume key whose firmware hook is set is invisible to every app, and only
412   adb can unset it.
413 - The reader ships with Google Play disabled; buying needs it switched on.
