13 ## 0.1.0-beta - 2026-09-21
14 
15 Version code 16. The first beta. The alpha versions end here.
16 
17 - **Updates: Ink Update.** Rebind has no internet permission, so it cannot
18   look for a new version. Ink Update, an open source app of its own, does
19   that: F-Droid first, then Google Play (it leaves an app that Google Play
20   installed to Google Play), then GitHub. It makes a notification and opens
21   the page. Setup has an "Updates" row that installs or opens it. The build
22   for direct install carries it.
23 - The build for direct install carries Ink Dim too. Hardware hacks lists it.
24 - The lists of carried apps are named "Extensions".
25 
26 - **Settings are safe across versions and across an uninstall.** An update
27   always kept the settings: they are in the data of the app. An uninstall
28   removed them. Now Android asks at uninstall whether to keep the data
29   (`hasFragileUserData`), and Rebind keeps an automatic copy of the settings in
30   `Documents/Rebind/rebind-settings.json`, which an uninstall does not touch.
31   Import opens that folder. `StoredFormatTest` holds the texts that every
32   0.0.x version stored, so a new version cannot stop reading them unseen.

46 ## 0.0.14-alpha - 2026-09-21

49 
50 - **Permissions covers the extensions again.** New items, each only where it
51   can apply: "Install apps from Rebind" (the build that carries apps), "Ink
52   Recents: app usage data" (when Ink Recents is installed), and "Home screen"

64   request dialog for the assistant role. The row now opens the settings page
65   "Default digital assistant app".

94   microphone grant. Before, those places showed a short message or nothing.
95 - **Fix: system Back always closed the button setup.** From Android 13 the
96   system does not call `onBackPressed` for an app with this target version.
97   The setup now registers the Back callback, and Back goes one step back.

298 ## 0.0.4-alpha - 2026-09-20
299 
300 Version code 4.
301 
302 - **Voice typing.** A new action. Press the key, speak, and the words go where
303   the cursor is. The app has no speech engine: it uses the Android
304   SpeechRecognizer interface, so any speech recognition app on the device does
305   the listening. The accessibility service puts the text into the focused
306   field. Password fields are never written to.
307 - **Two builds.** `play` for Google Play has no Shizuku code and no Shizuku
308   permission. `full` for direct install keeps shell access. Same app id and
309   signature, so one can replace the other.
310 - **Viwoods: AI key goes back.** Inside the AI screen or the crop screen, the AI
311   key returns to the app that was in use before. Switch on the AI key screen.
312   Test: `tools/e2e/ai-key-return.sh`.
313 - **Fix: Power always wakes and unlocks.** While the app manages the Power
314   button, a press on a sleeping or locked device is never a gesture. The app
315   also sends the wake and the keyguard dismissal through the shell, so waking
316   does not depend on the firmware. Regression test: `tools/e2e/power-wake.sh`.
317 
318 Known limits:
319 
320 - Voice typing needs a speech recognition app that has its own microphone
321   permission. The Viwoods voice prompt cannot be used: it sends audio to the
322   Viwoods cloud and has no interface for other apps.
323 - The listening screen pauses the app behind it for a moment. An app that
324   clears its text field on resume loses what was typed before.

381 ## 0.0.1-alpha — 2026-09-20
382 
383 First alpha. Version code 1.
384 
385 - Remaps the AI key and both volume keys through an accessibility key filter:
386   1–5 taps, press-and-hold, and key combinations, each bound separately.
387 - Remaps Power: hold (as the digital assistant), double press (as the default
388   camera app), and the firmware short-press behaviour.
389 - Actions: Viwoods AI screens, navigation, page-turn swipes and scrolls,
390   volume and media, open an app or component, send an intent or broadcast.
391 - Licensing through Google Play Billing: licensed, beta, 7-day trial, locked.
392   The beta is opened and closed from Play Console; testers get a lower price.
393 - In-app accessibility disclosure with explicit consent.
394 - Key tester, and a read-only view of the firmware's own key hooks.
395 - No `INTERNET` permission.
396 
397 Known limits:
398 
399 - Purchases are untested: Play Billing cannot be exercised until the app exists
400   in Play Console. Everything up to the purchase sheet is tested on the device.
401 - A volume key whose firmware hook is set is invisible to every app, and only
402   adb can unset it.
403 - The reader ships with Google Play disabled; buying needs it switched on.
