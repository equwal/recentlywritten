137 // One dependency, and only because there is no other way to sell on Play.

139 //
140 // The billing library talks to the Play Store app over IPC and needs no network
141 // access of its own. What does want the network is its usage telemetry, which
142 // rides on Google's datatransport runtime and would merge INTERNET and
143 // ACCESS_NETWORK_STATE into the manifest. An accessibility service that sees
144 // key presses should not also hold INTERNET, so that runtime is left out.
145 //
146 // This is safe by construction, not by luck: the only class in the library that
147 // touches datatransport (zzdn in 8.3.0) initialises it inside a catch-all and
148 // falls back to "Skipping logging since initialization failed". Re-check that
149 // with javap before bumping the billing version, and re-check the merged
150 // permissions with `aapt2 dump badging` after.
