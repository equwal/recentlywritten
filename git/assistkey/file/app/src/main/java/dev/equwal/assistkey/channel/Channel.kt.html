7 /**
8  * A capture channel: one way the system can be persuaded to hand us control.
9  *
10  * Each is independently switchable because they compete for different system
11  * slots and their availability varies by firmware. Turning one on enables its
12  * manifest components; turning it off disables them, so the app stops showing
13  * up as a candidate anywhere in Settings.
14  *
15  * Power never reaches an input filter - PhoneWindowManager eats it before the
16  * dispatcher - so the three impersonation channels exist purely to get the
17  * power gestures routed back to us as ordinary app launches.
18  */
