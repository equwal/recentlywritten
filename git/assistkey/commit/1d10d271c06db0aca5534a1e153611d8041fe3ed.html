Carry inkOS and ThinkLauncher in place of CLauncher

The build for direct install carries inkOS v0.6 (gezimos, GPL-3.0) and
ThinkLauncher v3.0 (MatiasDesuu, GPL-3.0), each the release file of its
maker and not changed. CLauncher is no longer in the build. NOTICE.txt
names each maker, licence, source and SHA-256. The main screen counts
the home screens and Ink Recents that are installed.

Version 0.0.13-alpha, version code 13.
