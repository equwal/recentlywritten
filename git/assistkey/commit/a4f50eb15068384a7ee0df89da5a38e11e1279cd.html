Ask for a grant at the moment the user needs it

GuidedSetupActivity.askIfMissing takes any context and says whether it
opened the allow step. The menu editor calls it after a save. The
Navigation screen calls it for the first Power binding that needs
something. A Power press that arrives while button remapping is off
opens the allow step and no longer shows a toast, which the reader
hides. Voice typing with no microphone grant opens the Voice typing
screen.
