Open Ink Recents where the system shows its recent apps

Android does not let an app take the place of the recent-apps screen of
the system. The key filter already gets the window-state events. When
the screen in front is the recents of the system (the task manager of
the Viwoods launcher, or the two stock Android ones), the service sends
Back and starts Ink Recents. A switch on Home and recents turns it off.
It is on when Ink Recents is installed.

The accessibility disclosure and the Play declaration name this use.

Version 0.0.15-alpha, version code 15.
