Release 0.1.0-beta: updates through Ink Update

Rebind has no internet permission and keeps it that way. Ink Update, an
open source app of its own, looks for new versions and makes the
notification. The build for direct install carries Ink Update and Ink
Dim. Setup has an Updates row, and Hardware hacks lists Ink Dim. The
lists of carried apps are named Extensions.

Version 0.1.0-beta, version code 16. The alpha versions end here.
