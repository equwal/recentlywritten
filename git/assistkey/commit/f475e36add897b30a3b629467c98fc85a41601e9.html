Turn on R8, leave the Google dependency list out, and set the version to 0.1.2-beta

F-Droid asks for R8 and for a reproducible build. The recipe now names the signed fdroid APK on GitHub (Binaries) and the key that signs it (AllowedAPKSigningKeys). proguard-rules.pro keeps all names, keeps Shizuku.newProcess for Shell.kt, and allows the Play Billing telemetry classes that the build leaves out. dependenciesInfo is off: F-Droid rejects the encrypted dependency list in the signing block.
