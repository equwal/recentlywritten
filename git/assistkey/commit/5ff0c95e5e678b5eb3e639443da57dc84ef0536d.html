Let the user change a button from the Done step

The Done step has two buttons: Change what it does, and Change how you
press it. They go back to those steps with the button and the gesture
kept, so that the user can adjust a binding while he tests it. Back on
the Done step goes to the actions too.

Route.back holds the rule for Back as a pure function, with a test for
each branch. The step that follows a return from the action list now
runs only after the screen was really left for that list.
