Recent apps: a row of swipe cards in place of the list (0.0.5-alpha)

RecentsActivity now shows the recent apps as cards, like the Android switcher.
Swipe sideways through the cards, tap a card to open the app, swipe a card up
to close it. The cards are drawn for e-ink: black outlines on white, no fling,
and the row moves one card for each swipe with no animation.

With shell access the cards are the real tasks of the system. A swipe up runs
`am stack remove <task id>`, which the shell user may do. Where the shell is
root, each card shows the picture the system keeps of the task, read from
/data/system_ce/0/snapshots. Those files belong to `system`, so a plain shell
cannot read them, and the card then shows the app icon.

The task list parser now accepts both forms of a task line: `A=<uid>:<package>`
and `I=<package>/<class>`.

The list view is deleted; the cards replace it.
