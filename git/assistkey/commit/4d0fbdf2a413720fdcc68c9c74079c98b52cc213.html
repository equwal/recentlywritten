Fix Extra dim toggle; add a switch for the system Emergency SOS

Extra dim toggle. On now goes to the lowest level. Off gives the light back to
the brightness set in the system. Before, on used the level last in use, or a
middle level when there was none. ExtraDim.toggled is the rule, with regression
tests. The stored "last level" value is deleted.

The three light actions get their name from the payload and not from the stored
label, so a binding made by 0.0.6 shows the new name: Extra dim toggle, Extra
dim darker, Extra dim brighter.

Emergency SOS. Android starts Emergency SOS on five quick Power presses, which
collides with a 5-tap binding. The Power screen has a switch for it
(Settings.Secure emergency_gesture_enabled). The app never turns it off by
itself. The app writes the setting directly when it holds
WRITE_SECURE_SETTINGS, and through the shell otherwise. The switch shows only
where one of the two ways is open. Tested on the reader: with the value 0, five
presses are counted and no SOS starts.
