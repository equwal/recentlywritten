Add ready-made menus, a permissions screen and recents polish; tone down shell access (0.0.7-alpha)

Ready-made menus. The action list offers menus that bind in one tap:
Brightness (full build), Navigation, System, Sound and media, Page turning,
and Viwoods AI on Viwoods devices. Each is an ordinary menu after it is bound.

Brightness up and down. Two more light actions, for the system brightness. A
step is a quarter of the present value and at least 5, and stays in range;
tests cover every value from 0 to 255.

Permissions screen. Every grant the app can use, with its purpose and state.
"Set up what is missing" opens the grant screens one after the other. It
opens once by itself on the first run and can be run again at any time. A
permission dialog reports twice on return, as a result and as a resume, so a
second step close behind the first is dropped.

The accessibility disclosure is now one shared text. It names voice typing and
the app-in-front note, which the old text did not.

Recent apps. One swipe moves one card. A row of icons under the cards shows
every recent app and marks the one in the middle. The heading says which app
and its position. Each card that can be closed says "Swipe up to close", and
"Close all but <app>" sits beside "Close all".

Shell access and the extra-dim light move under Advanced, and shell access is
not counted as a missing permission. They serve the few devices with Shizuku
or root, and the app is complete without them.

Store listing: the title is "AssistKey: E-Ink Key Remap". No device maker is
named in the title, and the description has a not-affiliated line. A maker
name at the front of a title reads as an official app and can be removed as
impersonation. The checklist records the advice to price at US$4.99; the owner
has not decided.
