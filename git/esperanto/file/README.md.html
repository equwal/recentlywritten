1 # Esperanto morphological compression
2 
3 This is an experimental program to compress Esperanto language using its quality
4 _highly regular morphology_. Most NLP compression methods require an analytic
5 language (eg. English) to work, but this it different.
6 
7 *Warning: may not be functional at this point.* Pull requests appreciated.
8 
9 
10 ## Guts
11 There are two metrics that matter with the compression: the percent reduction in
12 size using just morphological compression, and the reduction when combined with
13 another NLP compression method.
