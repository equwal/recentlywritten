Add a feed to each link

A link can have the address of the RSS or Atom feed of its site, as a fourth field of its line. A line without a feed keeps the three fields of bm. bm reads only the first three fields.

The admin page takes a feed with a new link, and shows the feed of each link in a form that changes it. The import, and adding a URL that is a link already, give the feed to a link that has none. links.txt has the feed as the fourth field. The HTML list puts an rss link after each link with a feed, and shows the address without the scheme in place of the host, because many descriptions do not name the page.

Add the command 'sbm-webpublish merge', which adds the links of its input as the import does. Write the file with mode 0644, so that the service can read a file that root wrote with merge. Fix the import, which read the file two times after the change to mergeFrom.
