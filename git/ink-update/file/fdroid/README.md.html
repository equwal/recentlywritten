1 # How to submit Ink Update to F-Droid
2 
3 1. Tag the release `v0.1.0` and push the tag.
4 2. Fork `fdroid/fdroiddata` on GitLab, then clone your fork.
5 3. Copy `dev.equwal.inkupdate.yml` into `metadata/` of your clone.
6 4. Run `fdroid readmeta` and `fdroid lint dev.equwal.inkupdate` to check it.
7 5. Commit on a new branch and push it to your fork.
8 6. Open a merge request against `fdroid/fdroiddata`.
