12 * Description
13 This layer does wonderful things:
14 - Add keybindings to dispatch Quickurl (which is in vanilla Emacs), or to
15   navigate and dispatch the Quickurl list.
16 
17 * Install
18 To use this configuration layer, add it to your =~/.spacemacs=. You will need to
19 add =quickurl= to the existing =dotspacemacs-configuration-layers= list in this
20 file.
21 
22 * Key bindings
23 | Key Binding | Description                                                 |
24 |-------------+-------------------------------------------------------------|
25 | ~SPC Q l~   | List quickurls                                              |
26 | ~SPC Q Q~   | Expand quickurl abbrev at point                             |
27 | ~SPC Q i~   | Ask for which quickurl to insert                            |
28 | ~SPC Q e~   | Edit quickurls                                              |
29 | ~SPC Q b~   | Ask to browse some url from those stored (with completion). |
