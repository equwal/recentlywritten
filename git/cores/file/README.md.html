9 # INSTALLATION
10 
11 1) Add local packages to ASDF if needed in the `~/.sbclrc`.
12 ```cl
13 (pushnew  (merge-pathnames #p"common-lisp/" (user-homedir-pathname))
14             asdf:*central-registry*)
15 ```
16 2) Modify packages to load into the core in `config.lisp`. There are some examples.
17 ```cl
18 (defvar *quicklisp-packages*
19   '("BORDEAUX-THREADS")
20   "Load into core from quicklisp.")
21 ```
22 3) Generate the core. It goes to `.sbcl-core-libs`.
23 ```sh
24 sbcl --load "make.lisp"
25 ```
26 4) Add the core to your SBCL startup process. There multiple ways to do that.
27 
28 Modifying the environment variable.
29 ```sh
30 SBCL_HOME="$HOME/.sbcl-core-libs"
31 ```
32 The --core option in the IDE call to SBCL.
33 ```sh
34 sbcl --core "$HOME/.sbcl-core/libs"
35 ```
36 
37 # AFTER UPDATING SBCL
38 Just regenerate the core.
39 ```sh
40 sbcl --load make.lisp
41 ```
