Sell a 500-book pack

Add pack500: 500 credits for $174.99 ($0.35 a book, 30% below the
10-book pack). The owner chose to sell it against the advice of the
financial advocate: one such sale can hold the one CPU server for about
six weeks. So the pack text says how fast the server works.

The catalogue tests now expect three packs, and the check-out test runs
for pack500 too.
