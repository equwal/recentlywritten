Sell a 100-book pack, and state the real server speed

Add pack100: 100 credits for $39.99 ($0.40 a book, 20% below the
10-book pack). The financial advocate put this discount in the middle of
what credit packs give at ten times the volume. There is no 500-book
pack: one such sale holds the one CPU server for about six weeks.

The README and the pricing notes said that the server runs a large
speech model on a GPU, in minutes. It runs Whisper tiny on a CPU, one
book at a time: about 2 hours for a 10-hour book. The text now says so.

The tests check the catalogue, that a bigger pack costs less a book but
more in all, and that pack100 checks out at its price and credits 100
books.

+def test_bigger_packs_cost_less_a_book(client):
+    # A bigger pack must cost less a book, or nobody buys it. It must also cost
+    # more in all, or the smaller packs are pointless.
+    plans = client.get("/api/pricing").json()["plans"]
+    packs = sorted((p for p in plans if not p["recurring"]), key=lambda p: p["credits"])
+    assert [p["credits"] for p in packs] == [10, 100]
+    per_book = [p["price_cents"] / p["credits"] for p in packs]
+    assert all(small > big for small, big in zip(per_book, per_book[1:]))
+    totals = [p["price_cents"] for p in packs]
+    assert all(small < big for small, big in zip(totals, totals[1:]))
