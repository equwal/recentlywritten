Say that a job in the browser uses no credit

The note under the switch ended with the price of the server ("One
credit a book; you have 3 free."). It read as if the browser mode took a
credit, which it never does.

The browser mode now says "Uses no credit, and has no limit.", and the
price is a clause of the sentence about the server: "Turn this off to
have our server do the work instead, for one credit a book (you have 3)."
