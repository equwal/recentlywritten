Give a server job one more attempt when its worker vanishes

A burst worker can vanish in the middle of a job: a cloud takes a spot
machine back, or the machine fails. rq puts such a job back on its queue
when the job has retries left. Each job now has one retry, so it gets
two attempts at most. run_job never raises, so a book that fails in the
aligner is not tried again.
