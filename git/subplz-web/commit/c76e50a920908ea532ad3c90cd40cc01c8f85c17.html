Link the Subrep control panel with the email and a setup key

The Licence card of the Subrep desktop control panel asks for the email
that paid and a setup key. It sends the two to /refresh as "account" and
"refresh_key". The server now accepts the email of the account in place of
its id.

- /api/subrep/refresh finds the account by its email when "account" has an
  "@". A wrong email gets the same refusal as a wrong key.
- A licence has a "paid" claim: the end of the paid period, which the
  desktop app shows. "exp" stays the end of the token (31 days at most).
- /subrep.html shows the email and the setup key for the control panel,
  and the link command for the command line.
