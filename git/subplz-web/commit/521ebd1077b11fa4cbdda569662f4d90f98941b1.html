Use DeepInfra for cloud captions, and name the key after its job

The paid tier of Groq is not open to this account, and its free tier
allows 20 requests a minute for all users together. DeepInfra serves
whisper-large-v3-turbo for $0.0002 a minute ($0.012 an hour, against
about $0.08 at Groq), with pay as you go.

- The defaults are now the OpenAI-compatible route of DeepInfra and
  the model openai/whisper-large-v3-turbo. Any OpenAI-compatible
  transcription endpoint works with SUBPLZ_WEB_CAPTION_API_URL and
  SUBPLZ_WEB_CAPTION_MODEL.
- SUBPLZ_WEB_GROQ_API_KEY is now SUBPLZ_WEB_CAPTION_API_KEY. No server
  had the old name.

Tests: 17 caption tests pass; the full suite has 140 passed and the
one failure that main also has (test_vendor_files_may_be_kept).
