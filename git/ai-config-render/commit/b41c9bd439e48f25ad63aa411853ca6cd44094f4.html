Import local edits instead of overwriting them; add aicr watch

aicr records a hash of every owned file and block it writes. A target
that no longer matches was edited there: if the source is unchanged the
edit is copied back into the source; if both changed, the local copy is
saved as <source>.conflict-<machine>-<date> and the source wins. Text
matching an [import] deny pattern is never imported.

aicr watch polls the owned files and the source tree, waits for a burst
of changes to settle, renders, and runs an optional --exec command.
--remote-every pulls when the upstream branch moves. Backups are now one
rolling <file>.aicr-bak.

examples/service has a post-receive notify hook, systemd and runit
services, a Windows logon task, and a commit-and-push hook.
