12 == Install ==
13 Requirements: xclip, dmenu, make
14 1) Export the $BOOKMARKS variable containing the location of the
15 bookmarks. I like to use ~/.local/share/sbm to store my config.
16     mkdir -p ~/.local/share/sbm/
17     ~/.bashrc
18         export BOOKMARKS="~/.local/share/sbm/bookmarks"
19 2) define your tag choices in USERTAGS and export that too. The file syntax is:
20 
21     <tag><space><description><newline>
22 
23     See the included usertags file for an example.
24 
25     ~/.bashrc
26         export USERTAGS="~/.local/share/sbm/usertags"
27 
28 3) make install
29
