13 == Install ==
14 Requirements: xclip, dmenu, make
15 1) Export the $BOOKMARKS variable containing the location of the
16 bookmarks. I like to use ~/.local/share/sbm to store my config.
17     mkdir -p ~/.local/share/sbm/
18     ~/.bashrc
19         export BOOKMARKS="~/.local/share/sbm/bookmarks"
20 2) define your tag choices in USERTAGS and export that too. The file syntax is:
21 
22     <tag><space><description><newline>
23 
24     See the included usertags file for an example.
25 
26     ~/.bashrc
27         export USERTAGS="~/.local/share/sbm/usertags"
28 
29 3) make install

40 == Sync ==
41 bm-sync keeps the bookmark file the same on all your devices. It works
42 with bm on other computers, the sbm app for Android and the sbm add-on for
43 Firefox and Chrome. It needs curl. Like bm, it uses the file in $BOOKMARKS.
44 
45     bm-sync login        # once on each device: email and password
46     bm-sync              # sync now
47     bm-sync status       # the server and the time of the last sync
48     bm-sync logout       # sign out on this device
49 
50 After bm adds a bookmark, bm runs bm-sync in the background. The server
51 merges the changes of each device. When you add or delete a bookmark on
52 one device, sync adds or deletes it on the others. bm-sync keeps the
53 sign-in token in ~/.config/sbm/sync. Only you can read this file.
54 
55 By default, bm-sync uses the server https://sbm.subread.space. Create an
56 account there first. The server is free software
57 (https://github.com/equwal/sbm-sync), so you can run your own:
58 
59     bm-sync login https://sbm.example.org
60 
61 bm writes lines as "URL description | tags". The app and the add-on write
62 lines as "URL<tab>description<tab>tags", and bm-sync puts these lines in
63 your file. The file can hold lines in both formats. bm copies the URL of
64 both.
