bm-sync: keep the bookmark file the same on all devices

bm-sync sends $BOOKMARKS to an sbm-sync server with the version of the
last sync. The server merges the changes of each device and sends back
the result. bm-sync then writes the result to the file. Thus a bookmark
that you add or delete on one device goes to the others: computers with
bm, the sbm app for Android and the sbm add-on for Firefox and Chrome.

    bm-sync login    # email and password, once on each device
    bm-sync          # sync now

bm-sync is POSIX sh and needs curl. It uses the design of bm-sync in
equwal/sbm. curl gets the password through stdin and the token through
a file, so neither shows in ps. A lock directory keeps one sync at a
time. When bm changes the file during a request, bm-sync sends the file
again. bm-sync writes the file through cat, so a symlink stays a
symlink.

Two guards prevent data loss. An empty or missing file goes to the
server without a version, so the server deletes nothing. Before
bm-sync writes the file, it removes the version. If the write fails,
the next sync then deletes nothing.

bm add runs bm-sync -q in the background when bm-sync is on the PATH.
The app and the add-on write lines as URL<tab>description<tab>tags.
bm copy now takes the first field, which ends at a space or a tab.
Thus it copies the URL of lines in both formats.

make install, uninstall and dist include bm-sync. make install now
makes ${PREFIX}/bin. Before, cp made a file with the name bin when
the directory did not exist. make check runs test.sh. In test.sh,
stand-ins for curl, dmenu and xclip play the server, the menu and the
clipboard.

+#!/bin/sh
+
+# bm-sync: keep $BOOKMARKS the same on all your devices through an sbm-sync
+# server (https://github.com/equwal/sbm-sync). bm runs it after each add.
+#
+# bm-sync sends the file and the version of the last sync. The server merges
+# the changes into its copy. Then it sends back the result and its version.
+
+CONFIG=${SBM_SYNC_CONFIG:-${XDG_CONFIG_HOME:-$HOME/.config}/sbm/sync}
+SERVER=https://sbm.subread.space
+STATE=$BOOKMARKS.sync   # the version of the last sync
+LOCK=$BOOKMARKS.sync.lock
+quiet=
+
+usage () {
+    cat <<'EOF'
+usage: bm-sync [-q] [login [server] | logout | status]
+Without a command, bm-sync syncs $BOOKMARKS.
+  login   sign in and sync (default server: https://sbm.subread.space)
+  logout  sign out on this device
+  status  show the server and the time of the last sync
+  -q      print only errors
+EOF
+}
+
+die () {
+    printf 'bm-sync: %s\n' "$*" >&2
+    exit 1
+}
+
+say () {
+    [ -n "$quiet" ] || printf 'bm-sync: %s\n' "$*"
+}
+
+# setting <name>: the value of <name> in the config file.
+setting () {
+    sed -n "s/^$1=//p" "$CONFIG" 2>/dev/null | head -n 1
+}
+
+cleanup () {
+    rm -rf "$work"
+    [ -z "$locked" ] || rm -rf "$LOCK"
+}
+
+login () {
+    server=${1:-$SERVER}
+    server=${server%/}
+    printf 'email: ' >&2
+    read -r email || exit 1
+    printf 'password: ' >&2
+    stty -echo 2>/dev/null
+    IFS= read -r password
+    rc=$?
+    stty echo 2>/dev/null
+    printf '\n' >&2
+    [ $rc -eq 0 ] || exit 1
+
+    # curl gets the password through stdin and the token through a file.
+    # Other users can see command lines with ps.
+    code=$(printf '%s' "$password" | curl -sS -o "$work/out" -w '%{http_code}' \
+        --data-urlencode "email=$email" --data-urlencode 'password@-' \
+        -- "$server/api/login") || die "cannot reach $server"
+    [ "$code" = 200 ] || die "$(cat "$work/out")"
+
+    # The config file holds the token, so only you can read it.
+    mkdir -p "$(dirname "$CONFIG")" && : > "$CONFIG" && chmod 600 "$CONFIG" || exit 1
+    printf 'server=%s\ntoken=%s\n' "$server" "$(tr -d '\r\n' < "$work/out")" > "$CONFIG"
+    rm -f "$STATE"
+    say "signed in to $server"
+    sync
+}
+
+logout () {
+    if [ -e "$CONFIG" ]; then
+        printf 'Authorization: Bearer %s\n' "$(setting token)" > "$work/auth"
+        curl -sS -o /dev/null -X POST -H "@$work/auth" -- "$(setting server)/api/logout" \
+            2>/dev/null
+        rm -f "$CONFIG" "$STATE"
+    fi
+    say 'signed out'
+}
+
+status () {
+    if [ ! -e "$CONFIG" ]; then
+        echo 'not signed in: run bm-sync login'
+        return
+    fi
+    echo "server: $(setting server)"
+    if [ -e "$STATE" ]; then
+        echo "last sync: $(ls -l "$STATE" | awk '{ print $6, $7, $8 }')"
+    else
+        echo 'last sync: never'
+    fi
+}
+
+sync () {
+    [ -e "$CONFIG" ] || die 'not signed in: run bm-sync login'
+    server=$(setting server)
+    token=$(setting token)
+    [ -n "$server" ] && [ -n "$token" ] || die "$CONFIG is damaged: run bm-sync login"
+
+    # One sync at a time. A second bm-sync leaves a note and stops. The
+    # first bm-sync then syncs again.
+    if ! mkdir "$LOCK" 2>/dev/null; then
+        pid=$(cat "$LOCK/pid" 2>/dev/null)
+        if [ -n "$pid" ] && kill -0 "$pid" 2>/dev/null; then
+            : > "$LOCK/again"
+            say "bm-sync $pid syncs now, and then syncs again"
+            exit 0
+        fi
+        rm -rf "$LOCK"   # a killed bm-sync left the lock
+        mkdir "$LOCK" 2>/dev/null || die "cannot lock $LOCK"
+    fi
+    locked=1
+    echo $$ > "$LOCK/pid"
+
+    printf 'Authorization: Bearer %s\n' "$token" > "$work/auth"
+    : >> "$BOOKMARKS" || exit 1   # a new device has no file yet
+    tries=0
+    while :; do
+        rm -f "$LOCK/again"
+        cat "$BOOKMARKS" > "$work/sent" || die "cannot read $BOOKMARKS"
+        # An empty file with a version tells the server to delete all
+        # bookmarks. Without a version, the server deletes nothing.
+        [ -s "$work/sent" ] || rm -f "$STATE"
+        base=$(cat "$STATE" 2>/dev/null)
+        code=$(curl -sS --max-time 60 -o "$work/out" -D "$work/head" -w '%{http_code}' \
+            -H "@$work/auth" -H 'Content-Type: text/plain; charset=utf-8' \
+            --data-binary "@$work/sent" -- "$server/api/sync?base=$base") \
+            || die "cannot reach $server"
+        case $code in
+            200) ;;
+            401) die 'not signed in: run bm-sync login' ;;
+            *)   die "$(cat "$work/out")" ;;
+        esac
+        version=$(tr -d '\r' < "$work/head" | sed -n 's/^[Ss][Bb][Mm]-[Vv][Ee][Rr][Ss][Ii][Oo][Nn]: *//p')
+        [ -n "$version" ] || die 'the server gave no version'
+
+        # bm changed the file during the request: send the new file.
+        if ! cmp -s "$work/sent" "$BOOKMARKS"; then
+            tries=$((tries + 1))
+            [ $tries -lt 5 ] || die 'the file changes all the time: try again later'
+            continue
+        fi
+        if ! cmp -s "$work/out" "$BOOKMARKS"; then
+            # Forget the version first. If the write fails, the next sync
+            # then deletes nothing on the server.
+            rm -f "$STATE"
+            # Write through cat, not mv: a symlink stays a symlink.
+            cat "$work/out" > "$BOOKMARKS" || die "cannot write $BOOKMARKS"
+        fi
+        printf '%s\n' "$version" > "$STATE"
+        [ -e "$LOCK/again" ] || break
+    done
+    say "in sync: $(grep -c . "$BOOKMARKS") bookmarks"
+}
+
+while [ $# -gt 0 ]; do
+    case $1 in
+        -q) quiet=1 ;;
+        -h|--help) usage; exit 0 ;;
+        -*) usage >&2; exit 2 ;;
+        *)  break ;;
+    esac
+    shift
+done
+
+[ -n "$BOOKMARKS" ] || die 'BOOKMARKS is not set: set it to your bookmark file, as the README says'
+command -v curl >/dev/null 2>&1 || die 'curl is not installed'
+# mkdir fails when the directory exists. Thus bm-sync does not use a
+# directory that another user made.
+work=${TMPDIR:-/tmp}/bm-sync.$$
+mkdir -m 700 "$work" || die "cannot create $work"
+locked=
+trap cleanup EXIT
+trap 'exit 1' HUP INT TERM
+
+case ${1:-sync} in
+    login)  shift; login "$@" ;;
+    logout) logout ;;
+    status) status ;;
+    sync)   sync ;;
+    *)      usage >&2; exit 2 ;;
+esac
