Live preview in more places: terminals on a desktop, the app menu, bm-html

bm now uses fzf when it runs in a terminal, also when a display is
there. The fzf preview shows the page of the bookmark under the cursor,
and dmenu cannot show a preview. From a key of the window manager, with
no terminal, bm keeps dmenu. SBM_MENU=dmenu keeps dmenu in a terminal.

make install adds "sbm" to the app menu of a Linux desktop
(contrib/linux/sbm.desktop). It opens bm in a terminal, so with fzf and
its live preview, as the Windows and macOS apps do. The rpm and FreeBSD
file lists include it.

bm-html pages get the live preview of sbm Sync: in a wide window the
page of the highlighted bookmark shows on the right. The arrow keys and
the mouse move the highlight, and Enter opens it. A page loads only
when the user types or points, 300 ms after the highlight stops, in a
sandboxed frame without a referrer. On an https page an http bookmark
loads as https. A page in the frame cannot keep the focus. Without
script the page is the plain list, as before.
