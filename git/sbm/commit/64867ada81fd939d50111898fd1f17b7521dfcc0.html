bm: offer the tags of the tag file in the Ctrl-T menu

The Ctrl-T menu offered only the tags that bookmarks use. The default
tags of $USERTAGS were missing, but the tags that bm-import makes from
browser folders were there, because the imported bookmarks use them.
Now the menu offers the tags of $USERTAGS too.

The menu also took words from comment lines as tags, because cut -f3
passes a line without a tab through whole. It now skips comment lines.
