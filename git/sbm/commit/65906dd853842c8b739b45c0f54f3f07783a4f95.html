Split bm into small POSIX tools; browse, preview, web search

bm keeps the bookmark file and the menu: open, copy, add, edit, delete,
list, merge. The rest are filters over bookmark lines, installed à la
carte (TOOLS in config.mk):

  bm-import bookmarks.html | bm --merge     was --import
  bm --list | bm-check -                    was --check
  bm-html > bookmarks.html                  new: a searchable web page
  bm-migrate                                was --migrate; never
                                            overwrites an earlier .bak
  bm-title, bm-commit                       used by bm when installed

Plain "bm" browses. dmenu cannot bind keys or preview, so a second menu
shows the chosen bookmark in full and asks what to do; fzf gets a live
preview. Text that is no bookmark is opened as an address or searched on
the web, with engine keywords from an engines file.

POSIX sh and POSIX utilities only: noclobber for mktemp, a FIFO of
tokens for xargs -P, dd for head -c, awk srand() for date +%s.
make check: shellcheck -s sh and 159 scripted tests.

+#!/bin/sh
+
+# bm-check: report dead and permanently moved links.
+#
+#     bm-check                    the default bookmark file
+#     bm-check file ...           these files ("-" is stdin)
+#     bm --tag code --list | bm-check -
+#
+# Reads bookmark lines (only the first field matters, so a plain list of URLs
+# works too) and prints, for each link that is in trouble,
+#
+#     status<tab>url[<tab>new location]
+#
+# where status is the HTTP status, or 000 when there was no answer. 301 and
+# 308 are reported because the bookmark should be updated. Exits 1 when it
+# printed anything.
+
+probe='%{http_code} %{redirect_url}'
+
+check () {
+    res=$(curl -sI --max-time 10 -A 'Mozilla/5.0' -o /dev/null -w "$probe" \
+          -- "$1" 2>/dev/null)
+    case ${res%% *} in
+        403|405|000|'')
+            # Some servers refuse HEAD; ask for the first byte instead.
+            res=$(curl -s -r 0-0 --max-time 10 -A 'Mozilla/5.0' -o /dev/null \
+                  -w "$probe" -- "$1" 2>/dev/null)
+            ;;
+    esac
+    code=${res%% *}
+    case $code in
+        301|308) printf '%s\t%s\t%s\n' "$code" "$1" "${res#* }" ;;
+        2*|3*)   ;;
+        *)       printf '%s\t%s\n' "${code:-000}" "$1" ;;
+    esac
+}
+
+case ${1-} in
+    -h|--help) sed -n '3,16s/^# \{0,1\}//p' "$0"; exit 0 ;;
+esac
+
+command -v curl >/dev/null 2>&1 || { printf 'bm-check: needs curl\n' >&2; exit 1; }
+[ $# -gt 0 ] || set -- "${BOOKMARKS:-${XDG_DATA_HOME:-$HOME/.local/share}/sbm/bookmarks}"

+# FIFO as the semaphore: it starts out holding eight tokens, a probe takes one
+# before it starts and puts it back when it is done. Opening a FIFO blocks
+# until the other end is opened too, hence the helper that opens it for
+# writing while we open it for reading. Every report is one short line from
+# one printf, so concurrent probes do not garble each other.
+fifo=${TMPDIR:-/tmp}/bm-check.$$
+mkfifo -m 600 "$fifo" || { printf 'bm-check: cannot create %s\n' "$fifo" >&2; exit 1; }
