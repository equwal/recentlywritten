  being ignored, and are rejected before any action runs.

  to be exported. The README told people to export "~/..." in quotes,
  which the shell does not expand.

  in a description is no longer taken for the tag separator.

  old-format file only triggers a warning until then.

  sed -i, so symlinked bookmark files and their permissions survive.
