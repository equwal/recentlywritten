bm-import: read all profiles of a browser, on Linux, macOS and Windows

bm-import read only the Default profile, and only from ~/.config. Now a
browser name reads the Bookmarks file of every profile. bm-import looks
for the browser in ~/.config, in ~/Library/Application Support (macOS),
and in %LOCALAPPDATA% (Windows, through cygpath under Cygwin).

bm --merge skips the known bookmarks, so the same command again syncs
the new browser bookmarks into bm.
