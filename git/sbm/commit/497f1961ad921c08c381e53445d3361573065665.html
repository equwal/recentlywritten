Windows installer: Start menu entry, and bm-watch at each login

The installer makes a Start menu entry. Only the desktop shortcut has
the key Ctrl+Alt+Shift+F24, because Explorer can lose a key that two
shortcuts share. A Startup entry runs bm-watch in a hidden mintty at
each login, and the installer starts it at once, so the browser
bookmarks come into bm during the installation. The installer and the
uninstaller stop bm-watch before they change its files. The installer
warns when the jq package of Cygwin is missing.
