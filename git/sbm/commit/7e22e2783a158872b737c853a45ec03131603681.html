test: bm-sync in the tests never reaches the account of the user

bm starts bm-sync after each change when bm-sync is installed. The tests
set SBM_SYNC_CONFIG only in the bm-sync section, so the other tests
started the installed bm-sync with the config of the user. After a
sign-in, make check would have put test bookmarks into the real account.

The tests now set SBM_SYNC_CONFIG to a file in their work directory for
the whole run. A new test checks, with a stand-in bm-sync, that bm gives
it this config.
