sbm-setup stop: no error for a process that stops during the loop

A process can stop after the shell expands /proc/[0-9]*/cmdline and
before tr reads the file of the process. bm-watch does this when
"sbm-setup stop" stops its mintty. The shell then wrote "No such file
or directory", because 2>/dev/null came after the input redirection.
Put 2>/dev/null first.
