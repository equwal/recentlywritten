Releases ship the LICENSE

The AGPL-3.0 asks that each copy of the program comes with the licence.
make dist puts LICENSE in the tarball. The Windows installer installs it
to /usr/local/share/sbm, and its uninstaller removes it. The macOS app
has it in Contents/Resources.
