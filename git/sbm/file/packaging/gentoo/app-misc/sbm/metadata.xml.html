13 		sbm keeps bookmarks in one tab separated file: URL, description,
14 		tags. bm picks a bookmark with dmenu, or with fzf on a bare
15 		terminal, and opens it, copies it, edits it or deletes it. Text
16 		that is no bookmark is opened as an address or searched for on
17 		the web.
18 
19 		The rest are small filters that read and write bookmark lines:
20 		bm-import reads a browser's bookmarks, bm-check reports dead

22 		the old file format, bm-title fetches a page title and bm-commit
23 		keeps the file's history in git.
24
