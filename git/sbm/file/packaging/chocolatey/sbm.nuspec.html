26     <description><![CDATA[
27 sbm keeps bookmarks in one tab separated file: URL, description, tags.
28 `bm` picks one from a menu and opens it, copies it, edits it or deletes it.
29 Text that is no bookmark is opened as an address or searched for on the web.
30 
31 The other programs are small filters over bookmark lines: `bm-import`,
32 `bm-check`, `bm-html`, `bm-migrate`, `bm-title` and `bm-commit`.
33 
34 ### What this package does
35 
36 sbm is POSIX shell. This package does not port it to PowerShell. It installs
37 the scripts and generates `.cmd` shims that run them through the `sh.exe` that
38 comes with Git for Windows, which is why `git` is a dependency.
39 
40 ### What works on Windows
41 
42 * The menu is **fzf**. `bm` picks fzf when there is no X11 or Wayland
43   display, which is always the case here.
44 * Clipboard: the shims default `SBM_COPY` to `clip` and `SBM_PASTE` to
45   `powershell -NoProfile -Command Get-Clipboard` when you have not set them.
46 * Opening URLs: set `SBM_OPEN` yourself, for example
47 
48         setx SBM_OPEN "powershell -NoProfile -Command Start-Process"
49 
50 * `bm-title`, `bm-check`: need `curl`, which ships with Windows 10 1803 and
51   later, and with Git for Windows.
52 * `bm-import` of a Chromium JSON bookmark file needs `jq`
53   (`choco install jq`).
54 * `bm-commit` needs `git`, which is already a dependency.
55 
56 ### What does not work on Windows
57 
58 * **dmenu.** It is an X11 program. There is no dmenu here and none is
59   installed. Everything menu driven goes through fzf.
60 * `xclip`, `xsel`, `wl-clipboard`, `xdg-open`: X11 and Wayland programs,
61   replaced by the `SBM_COPY`, `SBM_PASTE` and `SBM_OPEN` settings above.
62 
63 Bookmarks live in `%LOCALAPPDATA%` terms under the Git Bash HOME:
64 `~/.local/share/sbm/bookmarks`. Set `BOOKMARKS` to move it.
65 ]]></description>
