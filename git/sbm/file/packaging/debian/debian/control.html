28 Description: bookmark manager made of POSIX sh scripts
29  sbm keeps bookmarks in one tab separated file: URL, description, tags.
30  Lines starting with # are ignored, so cut, grep, awk and an editor work on
31  it as well as the tools do.
32  .
33  bm picks a bookmark with dmenu, or with fzf on a bare terminal, and then
34  opens it, copies it, edits it or deletes it. Text that is no bookmark is
35  opened as an address or searched for on the web.
36  .
37  The rest are small filters that read and write bookmark lines:
38   * bm-import turns a browser's bookmarks into bookmark lines;
39   * bm-check reports dead and permanently moved links;
40   * bm-html writes the bookmarks as one self-contained web page;
41   * bm-migrate converts a file from the old sbm format;
42   * bm-title prints a page's title, which bm --add offers as a description;
43   * bm-commit keeps the bookmark file's history in git.
44  .
45  Everything is POSIX sh and POSIX utilities. Nothing is compiled.
