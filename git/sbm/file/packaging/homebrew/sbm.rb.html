12   # A menu is required: dmenu or fzf. Homebrew has no dmenu formula, and dmenu

17   # Optional runtime helpers are deliberately not dependencies:

20   #   jq    only for Chromium JSON bookmark files (bm-import)
21   # Homebrew dropped :optional and :recommended, so these are named in caveats.

29   def caveats
30     <<~EOS
31       sbm expects a menu, a clipboard command and an opener. On macOS:
32 
33         * The menu is fzf. dmenu is an X11 program; if you run XQuartz and
34           build dmenu yourself, set SBM_MENU=dmenu.
35         * bm does not auto-detect pbcopy/pbpaste/open, so set these yourself:
36 
37             export SBM_COPY=pbcopy
38             export SBM_PASTE=pbpaste
39             export SBM_OPEN=open
40 
41       Example tag and search-engine files are installed in
42 
43         #{pkgshare}/examples
44 
45       Copy them if you want them:
46 
47         mkdir -p ~/.local/share/sbm
48         cp #{pkgshare}/examples/usertags #{pkgshare}/examples/engines ~/.local/share/sbm/
49 
50       Optional programs: jq (bm-import of Chromium bookmark files).
51       curl and git come with macOS and the Command Line Tools.
52     EOS
