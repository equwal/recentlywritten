39 %description
40 sbm keeps bookmarks in one tab separated file: URL, description, tags. Lines
41 starting with # are ignored, so cut, grep, awk and an editor work on it as
42 well as the tools do.
43 
44 bm picks a bookmark with dmenu, or with fzf on a bare terminal, and then
45 opens it, copies it, edits it or deletes it. Text that is no bookmark is
46 opened as an address or searched for on the web.
47 
48 The rest are small filters that read and write bookmark lines: bm-import
49 turns a browser's bookmarks into bookmark lines, bm-check reports dead links,
50 bm-html writes a searchable web page, bm-migrate converts the old file
51 format, bm-title prints a page's title and bm-commit keeps the bookmark
52 file's history in git.
53 
54 Everything is POSIX sh and POSIX utilities. Nothing is compiled.
