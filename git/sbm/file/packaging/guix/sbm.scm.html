113     (description
114      "sbm keeps bookmarks in one tab separated file: URL, description, tags.
115 @command{bm} picks one with dmenu, or with fzf on a bare terminal, and then
116 opens it, copies it, edits it or deletes it.  Text that is no bookmark is
117 opened as an address or searched for on the web.
118 
119 The rest are small filters that read and write bookmark lines:
120 @command{bm-import} turns a browser's bookmarks into bookmark lines,
121 @command{bm-check} reports dead links, @command{bm-html} writes a searchable
122 web page, @command{bm-migrate} converts the old file format,
123 @command{bm-title} prints a page's title and @command{bm-commit} keeps the
124 bookmark file's history in git.
125 
126 Everything is POSIX sh and POSIX utilities.  Nothing is compiled.")
