README (8603 bytes)

1 Manage bookmarks with dmenu and a basic file.
2 
3 The file is Tab Separated Values, one bookmark per line:
4 
5     URL<tab>description<tab>tag tag tag
6 
7 For example:
8 
9     https://equwal.com	Spenser Truex's website.	users
10 
11 Lines starting with # are ignored. bm is one way to work with the file;
12 cut, grep, awk and your editor are others.
13 
14 == Design ==
15 bm owns the bookmark file and talks to the menu. Everything else is a small
16 filter that reads or writes bookmark lines, so the pieces combine like any
17 other Unix tools, and you install only the ones you use:
18 
19     bm          pick, open, copy, add, edit, delete, list, merge
20     bm-import   browser bookmarks        -> bookmark lines
21     bm-check    bookmark lines           -> the dead links among them
22     bm-html     bookmark lines           -> a searchable web page
23     bm-migrate  the old sbm file format  -> bookmark lines
24     bm-title    a URL                    -> the page's title
25     bm-commit   commit the bookmark file to git
26 
27     bm-import bookmarks.html | bm --merge
28     bm --tag code --list | bm-check -
29     bm --list | grep -i wiki | bm-html -t Wikis - > wikis.html
30 
31 Everything is POSIX sh and POSIX utilities: no bash, no mktemp, no GNU
32 options. make check runs shellcheck -s sh over all of it. Where the usual
33 tool is not in POSIX, the script says what stands in for it: noclobber for
34 mktemp, a FIFO of tokens for xargs -P, dd for head -c, awk's srand() for
35 date +%s.
36 
37 == Requirements ==
38 dmenu (or fzf), one of xclip, xsel or wl-clipboard, sh, awk, make.
39 curl for bm-title and bm-check, jq for bm-import of Chromium files, git for
40 bm-commit.
41 
42 == Install ==
43 Edit TOOLS in config.mk to choose what gets installed, then
44 
45     make install                        # to /usr/local/bin
46     make PREFIX="$HOME/.local" install
47 
48 == Setup ==
49 Nothing is required. Bookmarks are kept in ~/.local/share/sbm/bookmarks
50 ($XDG_DATA_HOME is honoured) and the file is created on first use.
51 
52 Tag choices are read from ~/.local/share/sbm/usertags:
53 
54     <tag><space>|<space><description><newline>
55 
56 Start from the included example, or from nothing: a tag typed into the tag
57 menu that is not in the file yet is added to it.
58 
59     mkdir -p ~/.local/share/sbm
60     cp usertags engines ~/.local/share/sbm/
61 
62 == Usage ==
63     bm                   browse (see below)
64     bm -o, --open        open a bookmark, an address, or a web search
65                          (-p, --plumb is the same)
66     bm -c, --copy        copy a bookmark's URL to the clipboard
67     bm --print           print a bookmark's URL
68     bm -a, --add [url]   add a bookmark
69     bm -e, --edit        open the file in $VISUAL/$EDITOR at a bookmark
70     bm -d, --delete      delete a bookmark
71     bm -l, --list        print the bookmarks
72     bm -m, --merge       add the bookmark lines on stdin, skipping known ones
73     -t, --tag TAG        restrict any of the above to one tag
74     -S, --sort ORDER     used (default), recent, url, desc or tag
75 
76 Bind "bm" and "bm -a" to keys in your window manager.
77 
78 == Browsing ==
79 Plain "bm" lists the bookmarks. Pick one and a second menu shows it in full
80 (dmenu cannot preview while you scroll, so this is its preview) and asks what
81 to do:
82 
83     open
84     copy
85     edit
86     delete
87       https://suckless.org/
88       software that sucks less
89       tags: code org
90       used: 12
91 
92 Closing the second menu goes back to the list, closing the list leaves.
93 [add] at the top of the list adds a bookmark.
94 
95 With fzf (no display, or SBM_MENU=fzf) it is one screen: the bookmark under
96 the cursor is previewed live, and keys do the rest.
97 
98     ENTER   open            ctrl-a  add            ctrl-t  filter by tag
99     ctrl-y  copy            ctrl-d  delete (asks)  ctrl-s  next sort order
100     ESC     leave           ctrl-e  edit
101 
102 == Web search ==
103 In the list, and in "bm -o", text that is not a bookmark is not wasted:
104 
105     suckless.org/dwm          one word with a dot or "://": opened as an address
106     posix sh printf           anything else: searched for on the web
107     w dynamic menu            first word is a keyword: that engine is used
108 
109 So one key gives you bookmarks first and the web behind them. The default
110 engine is DuckDuckGo; set another with SBM_SEARCH='https://.../?q=%s'.
111 Keywords are read from ~/.local/share/sbm/engines:
112 
113     <keyword><space>|<space><url with %s><newline>
114 
115 See the included engines file.
116 
117 == Adding ==
118 Without a url, bm offers the X11 primary selection, or the clipboard, when
119 it holds a URL. With bm-title installed the description defaults to the
120 page's title (curl, 3 second limit; SBM_FETCH=0 turns it off). In dmenu the
121 default is the one entry in the menu: Return accepts it, Shift-Return sends
122 exactly what you typed.
123 
124 Tags are chosen one at a time until "done" is picked or the menu is closed
125 (fzf: TAB marks, ENTER confirms). Typing a tag that does not exist creates it.
126 
127 A URL that is already bookmarked is refused (exit status 3). URLs are
128 compared without their scheme, a leading www. and trailing slashes.
129 
130 == Sorting ==
131     used     most opened or copied first, then by url (the default)
132     recent   most recently added first
133     url, desc, tag
134 
135 Set a default with SBM_SORT. Use counts live in "$BOOKMARKS.usage", so the
136 bookmark file itself stays a plain list.
137 
138 == A web page of your bookmarks ==
139     bm-html > ~/public_html/bookmarks.html
140 
141 One self-contained file: no server side, nothing loaded from elsewhere.
142 Bookmarks are listed under each of their tags, with the tags linked at the
143 top. A dozen lines of inline script add a filter box; without script the page
144 is still the complete list, and Ctrl-F works. page.html?q=words starts out
145 filtered, so the page can be a search keyword in your browser, or in bm:
146 
147     b | https://example.org/bookmarks.html?q=%s
148 
149 Links that would run script (javascript:, data:) are never written.
150 
151 == Importing ==
152     bm-import bookmarks.html | bm --merge     # the HTML export of any browser
153     bm-import vivaldi | bm --merge            # or chrome, brave, edge, chromium
154     bm-import path/to/Bookmarks | bm --merge  # a Chromium JSON file (needs jq)
155 
156 Folder names become tags ("Dev Tools" becomes dev-tools). bm --merge skips
157 what you already have, so importing twice adds nothing. Look before you
158 merge: bm-import prints plain bookmark lines.
159 
160 == Dead links ==
161     bm-check
162 
163 prints status<tab>url for links that fail, and status<tab>url<tab>new-url for
164 ones that moved for good. It exits 1 if it printed anything.
165 
166 == History and sync with git ==
167 With bm-commit installed, every change bm makes is committed, provided the
168 directory holding the bookmark file is a git repository of its own. It never
169 pushes or pulls.
170 
171     cd ~/.local/share/sbm && git init
172     printf '%s\n' '*.usage' '*.bak*' > .gitignore
173 
174 A file that merely sits inside a bigger repository (your dotfiles) is left
175 alone unless SBM_GIT=1. SBM_GIT=0 turns commits off.
176 
177 == Migrating from the old format ==
178 Earlier versions wrote "URL description | tag tag".
179 
180     bm-migrate                  # $BOOKMARKS, or the default file
181     bm-migrate -n file          # only show what it would become
182     bm-migrate - < old > new    # as a filter
183 
184 The original is kept as .bak, and an existing .bak is never overwritten.
185 
186 == Configuration ==
187 All through the environment, all optional.
188 
189     BOOKMARKS     bookmark file
190     USERTAGS      tag choices file
191     DMENULINES    lines shown by dmenu (default 15)
192     SBM_MENU      dmenu, fzf, or a custom command
193     SBM_FZF_OPTS  extra options for every fzf call
194     SBM_SORT      default sort order
195     SBM_SEARCH    default search engine, with %s for the query
196     SBM_ENGINES   search keywords file
197     SBM_COPY      command that reads the new clipboard contents from stdin
198     SBM_PASTE     command that writes the clipboard contents to stdout
199     SBM_OPEN      command that opens the URL given as its argument
200 
201 With a display bm uses dmenu; fzf is only used when dmenu is missing or
202 there is no X11 or Wayland display. A custom SBM_MENU is called with the
203 choices on stdin as one of:
204 
205     <command> pick  <prompt>     print the chosen line, or the typed text
206     <command> multi <prompt>     print every chosen line
207     <command> ask   <prompt>     print free text; stdin holds a default, if any
208 
209 Printing nothing means the user cancelled. test/fakemenu is a small example.
210
