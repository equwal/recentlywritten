3 # bm-html: print the bookmarks as one self-contained web page.
4 #
5 #     bm-html > ~/public_html/bookmarks.html
6 #     bm --tag code --list | bm-html -t 'Code' - > code.html
7 #
8 # Without a file the default bookmark file is read; "-" is stdin.
9 #
10 # The page lists the bookmarks under each of their tags, with links to the
11 # tags at the top. A few lines of script add a filter box; without script the
12 # page is still the complete list. page.html?q=words starts out filtered, so
13 # the page can serve as a search engine keyword in a browser, or in bm's own
14 # engines file:    b | https://example.org/bookmarks.html?q=%s
15
