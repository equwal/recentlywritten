ideamine 0.2.0: one /ideas command with shell verbs

/ideas now takes a verb first, as in a shell:
- ls [lane|-a] [here], cat N..., rm N..., done|start|reopen|drop N:
  the hook answers these with no model call. rm deletes ideas for good.
- go [N]: triages new ideas first, then builds. It does not ask
  questions. It takes a "maybe" idea when no "do" idea is left.
- all: Claude reads every idea, takes out the ideas that fit the
  current chat, and does them. The other ideas stay in the queue.
- sort: triages the inbox now and shows the queue.

/ideas go and /ideas sort replace /idea-go and /idea-triage. The CLI
uses the same verbs: cat replaces show, sort replaces triage, and rm
is new.

go now runs its subagent in the foreground. Before, the subagent ran
in the background, and its result came back in a later turn. The
permission for idea_update had ended then, so the idea stayed "doing".

Ideas come from any session, so the recorded folder can be wrong or
gone. idea_next now tells if the folder exists and lists the whole
queue. The skill tells Claude to judge which ideas fit the chat, and
where to build each one.

New MCP tool: idea_remove. idea_next takes triage=true, and idea_list
takes full=true.
