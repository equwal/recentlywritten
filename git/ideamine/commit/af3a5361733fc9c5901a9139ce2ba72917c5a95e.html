ideamine 0.3.0: a dashed name for each command, for the slash menu

The slash menu shows skills, not the verbs after /ideas. Thus each
verb is now a skill with its own name:

- /ideas-ls, /ideas-cat, /ideas-rm, /ideas-done, /ideas-reopen: the
  hook answers these with no model call.
- /ideas-go, /ideas-all, /ideas-sort: these call the model, as
  /ideas go, all, and sort did before.
- /ideas alone shows the queue. /ideas with words is a question.

The start and drop verbs are no longer slash commands. The CLI still
has them. The MCP prompts mirror the skills, and a test checks that
each skill has a prompt.
