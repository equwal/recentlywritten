1 # ideamine
2 
3 **An idea inbox for Claude Code.** Save ideas as fast as you have them. Claude sorts them out later.
4 
5 ```
6 > /idea let the scroller pause when the mouse hovers over a link
7   💡 Saved #43 · let the scroller pause when the mouse hovers over a link  (6 in inbox)
8 ```
9 
10 That line did not call the model. A hook answers `/idea` on your machine before any request goes to Claude, so saving an idea:
11 
12 - **costs 0 tokens.** `claude -p "/idea …"` reports 0 turns, 0 input tokens, 0 output tokens, $0.
13 - **does not interrupt the current task.** Claude never sees the idea, so it cannot get distracted by it.
14 - **works on any model, in any session, and when you are out of usage.** Nothing is sent, so there is nothing to rate-limit.
15 
16 Every session writes to one archive, `~/.ideamine/ideas.json`, whatever project or model it uses. When you are ready, Claude triages the pile. It decides which ideas are worth doing and picks the **cheapest model that can build each one**: Haiku for a typo, Sonnet for a feature, Opus for a redesign. Fable is only for the hardest problems.
17

23 claude plugin marketplace add equwal/ideamine

30 Or from inside a session: `/plugin marketplace add equwal/ideamine`, then `/plugin install ideamine@ideamine`. Start a new session to load it. Requires Node.js 18 or later. There are no dependencies to install. Tested on Claude Code 2.1.224 (CLI) and 2.1.275 (desktop app) on Windows.

34 ## Commands
35 
36 | Command | What it does | Calls the model? |
37 |---|---|---|
38 | `/idea <text>` | Save an idea. A pasted bulleted list saves one idea per bullet. `#tags` are recorded. | **No** |
39 | `/ideas` | Show the board: doing, do (best first), maybe, inbox | **No** |
40 | `/ideas #12` | Show one idea in full: brief, model, notes | **No** |
41 | `/ideas done 12 shipped it` | Quick edit. Also `drop`, `start`, `reopen` | **No** |
42 | `/ideas inbox` · `do` · `maybe` · `skip` · `done` · `all` · `here` | Filter the board. `here` = this project only | **No** |
43 | `/ideas <question>` | Ask about your ideas, e.g. "which ones fit in an hour?" | Yes, briefly |
44 | `/idea-triage` | Score the inbox and choose a model for each idea | Yes, briefly |
45 | `/idea-go [id]` | Build the top idea (or `#id`) with its recommended model | Yes, this is the build |
46 
47 In the plugin menu the commands also appear as `/ideamine:idea` and so on. Both forms work.
48 
49 Claude can also save ideas by itself. If you write "idea: dark mode for the popup" or "save that for later", it calls the `idea_add` tool and continues the current task.

51 ## Model routing
52 
53 `/idea-triage` gives each idea a verdict (`do`, `maybe`, `skip`), an impact from 1 to 5, a size from `xs` to `xl`, a one-line reason, and a short brief that an agent can act on without the original chat. It also picks the cheapest model that is likely to finish the idea in one pass. If a weaker model fails and has to retry, that costs more than using the right model once.
54 
55 | Model | $ in / out per 1M tokens | Gets ideas like |
56 |---|---|---|
57 | `haiku` (Haiku 4.5) | $1 / $5 | mechanical, fully specified, local work: typos, renames, config tweaks, boilerplate, small scripts |
58 | `sonnet` (Sonnet 5) | $2 / $10 | the default: ordinary features, bug fixes with a clear repro, tests, docs, contained refactors |
59 | `opus` (Opus 5) | $5 / $25 | ambiguous or cross-cutting work: architecture, hard debugging, performance, security |
60 | `fable` (Fable 5.1) | $10 / $50 | only the hardest long-horizon or research-grade problems |
61 
62 The triage does not run on your session's model. `/idea-triage` makes one tool call, and the MCP server hands the work to a separate, minimal `claude -p` run on Sonnet (see below). A session on Opus or Fable therefore pays the same few cents as a session on Haiku. If that CLI is not available, Claude does the triage itself.
63 
64 Recommendations are stored as aliases, so they stay valid when a newer model ships under the same name. `/idea-go` gives the build to a subagent on the recommended model. The subagent starts with a clean context, so the build does not also re-read your whole conversation. To override a recommendation, run `ideamine model 12 opus` or ask Claude.
65 
66 ## Headless triage
67 
68 ```bash
69 ideamine triage
70 ```
71 
72 `/idea-triage` uses this same engine. It is one `claude -p` call on your normal Claude Code login, with no tools, no MCP servers, no settings, a two-line system prompt, and a JSON schema for the output. Four ideas take about 1,700 input tokens, roughly two cents on Sonnet. A normal model turn in a setup with a few MCP servers can re-read tens of thousands of tokens. To keep the inbox sorted while you sleep, schedule the command with cron or Task Scheduler. `--model haiku` makes it cheaper, and `--dry-run` shows the exact prompt.

91 ## Other MCP clients
92 
93 The MCP server works without the plugin. For Claude Desktop, Cursor, or any stdio MCP client:
94

96 {
97   "mcpServers": {
98     "ideamine": { "command": "npx", "args": ["-y", "github:equwal/ideamine", "mcp"] }
99   }
100 }
101 ```

103 Tools: `idea_add`, `idea_list`, `idea_triage`, `idea_update`, `idea_next`. Outside the plugin, the slash commands are MCP prompts. Without the hook, saving goes through the model, which costs a few tokens.

105 ## Where your ideas live
106 
107 `~/.ideamine/ideas.json` is plain, readable JSON. Set `IDEAMINE_HOME` to move it, for example into a synced folder. Each write takes a lock and then replaces the file in one step, so many sessions can write at the same time without losing an idea. The previous version is kept as `ideas.json.bak`. If the file becomes damaged, ideamine stops and does not overwrite it. Nothing leaves your machine, except when you run triage or a build, which go through Claude as usual.
108 
109 | Variable | Default | Purpose |
110 |---|---|---|
111 | `IDEAMINE_HOME` | `~/.ideamine` | archive location |
112 | `IDEAMINE_TRIAGE_MODEL` | `sonnet` | model for `ideamine triage` |
113 | `IDEAMINE_CLAUDE_BIN` | `claude` | Claude Code executable |
114 | `IDEAMINE_SETTING_SOURCES` | *(empty)* | set to `user` if your login needs `settings.json` (e.g. `apiKeyHelper`) |

116 ## How it works
117 
118 ```
119 /idea …       ──► UserPromptSubmit hook ──► ~/.ideamine/ideas.json ──► "💡 Saved #43"   (model never called)
120 /ideas        ──► same hook, renders the board locally
121 
122 /idea-triage  ──► Claude ──► MCP idea_triage ──► claude -p (Sonnet, minimal context)
123                                               ──► verdict · impact · size · cheapest capable model · brief
124 /idea-go      ──► Claude ──► subagent on that model ──► builds it ──► idea_update: done
125 ```
126 
127 The plugin contains a Node MCP server with no dependencies, four skills (the slash commands), and one hook. The hook ignores every prompt except `/idea` and `/ideas`, and those end before any API call. The hook runs directly, not through a shell, and takes about 130 ms per prompt on Windows. The skills are user-only, so their descriptions add no tokens to your sessions. If the archive cannot be read, the hook lets the prompt through, so the `/idea` skill can still save it with the MCP tool. Your text is never dropped.
