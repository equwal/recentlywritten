Draw Latin and Cyrillic captions with Latin fonts before Japanese fonts

Where Noto Sans is not available (Brave, most Windows systems), the caption fell back to Yu Gothic. Its Cyrillic letters are full-width, so Russian lines had wide gaps. Roboto (loaded by YouTube) and Arial now come before Hiragino Sans and Yu Gothic. Japanese text still uses Yu Gothic.
