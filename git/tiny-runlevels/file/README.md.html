4 Using OpenRC runlevels to have lots of instances of simple (network)
5 programs like quark for multiple http serving locally or [ii](https://tools.suckless.org/ii/) (or [sic](https://tools.suckless.org/sic/))
6 for IRC server connections.
7 
8 To keep programs simple, they should not do the same process for
9 unrelated uses. It is much more complicated to configure and manage
10 multiple webservers in the same process (like how nginx does it) than
11 just one. Init systems are designed to manage processes, and should be
12 used instead. Do one thing etc. etc.
13 
14 This is how to use the OpenRC runlevels for quark and ii runlevels
15 as examples.
16

58 ## How To:
59 
60 OpenRC has its own commands for making the runlevels, but I find them
61 confusing. Let's just edit the files.
62 
63 ```sh
64 # make runlevel
65 mkdir /etc/runlevels/quark
66 # add services (as many as needed)
67 ln -s /etc/int.d/quark-whatever /etc/runlevels/quark
68 # add runlevel to parent
69 ln -s /etc/runlevels/default /etc/runlevels/quark
70 # Reload since openrc is in default
71 openrc default
72 ```
73 
74 That works, but what about for networked IRC on a custom networking runlevel? Just add it to the networking runlevel.
75 ```sh
76 # (first, make a network runlevel that contains default! Without default the system will crash, obviously.)
77 mkdir /etc/runlevels/net-wifi
78 ln -s /etc/runlevels/net-wifi /etc/runlevels/default
79 ln -s /etc/init.d/wpa_supplicant /etc/runlevels/net-wifi
80 # etc.
81 # Now add the irc-base to the network runlevel
82 mkdir /etc/runlevels/irc-base
83 ln -s /etc/init.d/liberachat irc-base
84 ln -s /etc/init.d/oftc irc-base
85 ln -s /etc/runlevels/irc-base /etc/runlevels/net-wifi
86 openrc net-wifi
87 ```

89 ## Tool: restart-runlevel
90 Openrc wants switch the whole stack `openrc runlevel` so I made a little
91 tool to just restart a specific runlevel. Nice for debugging.
92 
93 ```sh
94 #!/bin/bash
95 
96 for link in /etc/runlevels/${1}/*
97 do [[ -L "$link" && "$(readlink "$link")" == /etc/init.d/* ]] && \
98     rc-service "$(basename "$link")" restart
99 done
100 ```
