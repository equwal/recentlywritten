kernel.fs (5434 bytes)

1 \ kernel.fs -- the high-level half of the Forth kernel. kernel.lisp metacompiles this file
2 \ into flash: each : definition becomes a header plus a list of execution tokens. Control
3 \ words (if, begin, do, ...) and ['] [char] ." s" recurse are resolved by the metacompiler
4 \ here; the immediate words of the same names below compile code at run time on the chip.
5 \ Console protocol and word set follow Mecrisp-Stellaris, so lisp.fs loads unchanged.
