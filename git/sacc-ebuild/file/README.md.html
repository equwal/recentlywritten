1 Ebuild for portage, Gentoo's package manager.
2 
3 **Sacc doesn't compile** on Gentoo out of the box without such an overlay.
4 
5 Sacc is a client for the [gopher internet protocol](bitreich.org). It is hosted at
6 
7 git://bitreich.org/sacc
8 
9 and [mirrored on github](https://github.com/equwal/sacc).
10 
11 This currently defaults to the `tinfo` ncurses mode, rather than the `txt`
12 mode. There is a plan to support txt mode by default when the tinfo and
13 ncurses use flags are missing. The `txt` mode is still available when compiling
14 from source by editing `config.mk`.
15 
16 # INSTALLATION
17 ```
18 cd /var/db/repos/gentoo/net-misc/
19 git clone equwal.com:sacc-ebuild
20 mv sacc-ebuild sacc && cd sacc
21 ebuild ./sacc-1.01.ebuild manifest unpack compile install
22 ```
