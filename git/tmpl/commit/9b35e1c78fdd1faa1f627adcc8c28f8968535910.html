Add make check and a CI workflow

make check parses shell templates with sh -n and shellcheck, compiles
the C templates, reads the Lisp templates with sbcl when installed,
runs the Python tests, and confirms INDEX.md is current. The test
suite now checks that every template starts with a summary comment
and uses a reference parser for the snippet round trip; the old regex
misread an escaped backslash before a tab stop. The pushd template
exits the subshell when cd fails.

+    """
