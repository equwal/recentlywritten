Add summary comments and named placeholders

Every template now starts with a one-line summary comment. The
converter reads it as the snippet description. <+name+> is a named
placeholder; the converter emits it as ${n:name}. The Vim mapping
pattern matches both forms. git-config-branch and cl/class use
named placeholders as examples.

+# Conventions
+
+- The first line of a template is a one-line summary in the language's
+  comment syntax (`#`, `;;`, `//` or `<!-- -->`). Tools read it as the
+  description. A `#!` line may come before it.
+- `<++>` marks a spot to fill. `<+name+>` does the same and names the spot,
+  for example `<+remote+>`. The snippet converter turns the name into the
+  placeholder text. Use the plain form unless a name helps.
+
