## Mail Encryption

  

------------------------------------------------------------------------

### Instructions (from the <a href="https://www.gnu.org/software/emacs/manual/html_node/message/Security.html" class="external-link">Emacs Manual</a>):

1.  Install GnuPG.

2.  Create a key-pair for your own e-mail address.

3.  Distribute your public key, e.g., via upload to key servers.

4.  Import the public keys for the recipients to which you want to send  
    encrypted e-mails.

5.  Integrate with your mail client.
