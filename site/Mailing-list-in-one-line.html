# ==> mailing-list.sh <==
#!/bin/sh
while read email; do neomutt -H "$MESSAGEFILE" "$email" < /dev/null; done < /dev/stdin

Make an mbox email with neomutt of whatever.
Now run it.

cat list-of-emails.txt | mailing-list.sh email-file.mbox
